# Smart projects

**Available on Asana [*Starter*](https://asana.com/plan/starter), [*Advanced*](https://asana.com/plan/advanced), [*Enterprise*](https://asana.com/enterprise), and [*Enterprise+*](https://asana.com/enterprise) tiers, as well as [*legacy tiers*](https://asana.com/pricing-legacy) Premium, Business, and Legacy Enterprise.**

Smart projects enable users to quickly create a customized project by generating suggested descriptions, sections, and custom fields based on the project's name and purpose. Simply enter a project name, and smart projects will generate a detailed description, organize sections, and create relevant custom fields. Before finalizing the project, you will have the option to modify the name and description or regenerate the entire project if needed.

#### Using Asana AI for project creation:

1.  Click the **Create** button on the top left of your Asana instance and select **Project**
2.  Select **Blank Project**
3.  Enter the title of your project under **Project name**
4.  Select **Set up** **with Asana AI**
5.  Click **Generate preview**
6.  If you're happy with the preview, click **Create project**. If not, select **Retry**
