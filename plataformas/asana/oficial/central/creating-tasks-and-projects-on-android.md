# Creating tasks and projects on Android

Asana's Android app isn't just useful for keeping up to date with progress on the go. You can also create tasks and projects, edit their details, and even update project progress when you're away from your desk.

Creating a task

#### To create a task:

1.  Tap the **New task** button
2.  Add a task title
3.  Tap to add an assignee
4.  Add a due date
5.  Add your task to a [project](https://asana.com/guide/help/projects/basics "project")
6.  Add a description
7.  Add a [subtask](https://asana.com/guide/help/tasks/subtasks "subtask")
8.  Tap to add [collaborators](https://asana.com/guide/help/tasks/understanding-tasks#gl-collaborators "collaborators")
9.  Tap **Create**

 

> By default, tasks you create in My tasks will be private to you. Upon creating your task, privacy indicators will be visible, indicating if the task is private or public.

### View or edit a task's details

Task editing lets you include all of the necessary information needed within your tasks such as custom fields, description, projects, subtasks, and attachments. Having all relevant information within your tasks allows you to trust that everything is in the right place.

#### From the **task edit details** screen you can:

1.  Mark a task as complete, like a task or forward a task
2.  Tap the three dot icon to see more options
3.  Add a task title
4.  Edit the assignee or due date
5.  Multi-home the task to projects
6.  Add a task description
7.  Create subtasks within your task
8.  Add attachments
9.  Add an image, attachment, appreciation or link
10. Add collaborators to your task

Sorting and filtering your tasks

#### From your My tasks or projects, you can:

1.  Tap the **Filter** button
2.  Change your view
3.  Filter tasks and change the sorting option

## Creating a project

#### To create a project you can:

1.  Tap the **+ New project** button
2.  Add a project name
3.  Choose a team
4.  Choose the project's access
5.  Choose the default view
6.  Tap **Create**

## Edit a project

#### To edit a project:

1.  Tap on the three dot icon
2.  From here you'll see a list of details you can edit

## Updating your project status

#### To update your project’s progress:

1.  Tap the three dot icon
2.  Tap **View status**
3.  From here, you'll see a list of previous status updates
4.  Tap **New message**, to create a new status update
5.  Choose whether your project is **On Track**, **At Risk** or **Off Track**
6.  Add a subject and a description
7.  Tap **Send** when your status update is ready to be shared

## Project overview tab

The project overview tab allows you to track a project's progress easily from your Android device. By streamlining project information and key actions, the overview tab empowers you to stay productive and informed while on the go.

#### From the overview tab you can view:

1.  Project smart summaries
2.  Status updates
3.  Project owner and due date

### Project smart summary

Project smart summaries on the Asana Android app provide a quick, high-level overview of progress on a project, making it easier for team leads and project managers to stay informed. Tap on the summary to read the full details.
