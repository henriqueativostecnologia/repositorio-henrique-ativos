# Embedded media project view

**The embedded media project view is currently in Early Access and is not available to all users.**

The **Embedded media** project view lets you bring key documents, dashboards, and other media directly into your project so your team can work from one place. You add the view using a shareable link from a supported tool so teammates do not need to switch tabs to read or work in shared content.

Use embed media when a document, deck, or working spreadsheet is central to a project, such as a campaign brief, a design hub, or a reporting dashboard.

## What you can embed

You can embed most publicly accessible or permission based links from supported tools. This includes productivity tools like **Google Docs**, **Google Sheets**, and **Google Slides**; video tools like **Loom**, **YouTube**, and **Vimeo**; design and whiteboarding tools like **Figma**, **Canva**, **Miro**, **Mural**, and **Whimsical**; analytics tools like **Tableau** and **Looker**; and research tools like **Airtable** and **Dovetail**.

## Where you can embed media

To add an embedded media view, open your project and click the plus button next to your existing project views such as **List** or **Board**. Select **Embedded media**, paste a supported link such as a Google Doc, Loom video, or Tableau dashboard, then name the view and save it.

Asana creates an interactive embed inside your project using the link you provided.

## Work with embedded content in Asana

Once the view is set up, you can scroll, navigate, and interact with the embedded content inside Asana in a way that is similar to the original app. Any changes you make from the embedded view are saved back to the original file.

For supported tools such as Google Docs or Figma, you can edit directly in the embed when you have edit access in the source tool. If you only have view access in tools like Google Drive, Airtable, or Figma, Asana shows the file in view-only mode.

## Permissions and access

Embedding content in Asana does not change the file's permissions. Teammates still need the right access in the original tool in order to view or edit the embed.

If someone cannot see or edit the embedded content, check the sharing settings in the source tool first. Your Asana admin may also limit embeds from specific domains, depending on your organization's security policies.

## Troubleshooting

**The embed will not load**

- Check that the source tool allows embedding and that the share link is valid.

**Teammates see a no access message**

- Update the sharing settings in the original tool so the right people can open the link.

**The view appears blank or stuck**

- Make sure you are signed into the right account for tools like Google or Figma in your browser.

**The link stays a plain URL**

- The tool or domain may not be supported, or your admin may have disabled embeds.

## FAQs

**Can I add multiple embedded views to a project?**

- Yes, you can add more than one embedded media view to the same project.

**Do embeds create copies of my files?**

- No, embeds display the live file from the source tool.

**Can private files be embedded?**

- Yes, if you have access to the file you can embed it, but only teammates who also have access in the source tool can view or edit it.

**Is the embedded content searchable in Asana?**

- The content inside the embed is not searchable in Asana, but the project view name is searchable.
