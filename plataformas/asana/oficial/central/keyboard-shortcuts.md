# Keyboard shortcuts

Use keyboard shortcuts to speed up your workflow. The main keyboard shortcuts are shown below. Learn about [rich text formatting](https://help.asana.com/s/article/text-formatting-in-asana?language=en_US) in Asana.

It's important to note that some shortcuts may not work if you're using a keyboard with a non-English input. iPad users can hold down the command key to see all available shortcuts.

## Frequently asked questions

### Do keyboard shortcuts work the same on macOS and Windows?

Most Asana keyboard shortcuts use the same key combinations on both platforms, with the primary difference being that macOS uses the Command key (⌘) where Windows uses Ctrl.

### Can I use keyboard shortcuts with a non-English keyboard?

Some shortcuts may not work if you're using a keyboard with a non-English input, as noted in Asana's documentation.

### How do I see all available keyboard shortcuts in Asana?

Press ⌘/ on macOS or Ctrl-/ on Windows to display the complete list of keyboard shortcuts, or iPad users can hold down the command key to see all available shortcuts.

### What are the essential keyboard shortcuts for navigating Asana?

Use Tab-Z to go to My tasks, Tab-I to open your Inbox, Tab-H to access Home, and Tab-/ to search for projects, tags, people, or tasks.
