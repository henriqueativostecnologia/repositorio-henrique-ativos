# Apps settings

The Apps tab allows you to manage the integrations you've authorized to access your account.

#### To access **App settings**:

1.  From the sidebar, click on your profile photo
2.  Select **Settings** from the menu
3.  Select **Apps**

#### From the **Apps** tab, you can:

1.  Download the Asana desktop app
2.  Scan a QR code to download the Asana mobile app
3.  View and deauthorize any integrations you're currently using
4.  Activate any available integrations
5.  Access the developer console

From the developer console, you can create a new [personal access token](https://help.asana.com/s/article/app-management-and-integrations?language=en_US "personal access token") or register a new application.

> [Learn more about our API in our Developer's Guide](https://developers.asana.com/ "Learn more about our API in our Developer's Guide").
