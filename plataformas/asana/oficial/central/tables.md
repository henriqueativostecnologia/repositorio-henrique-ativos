# Tables

Tables help teams manage structured information alongside the work that depends on it. Use records for vendor lists, asset catalogs, property rosters, customer accounts, and other reference data, then connect that information to tasks, projects, portfolios and other tables. This keeps context in Asana and gives AI Teammates and automation workflows more useful information to work with.

## Access tables

To access tables, click **Knowledge** from the sidebar and click **Tables**. From here, you can create a new table or view existing ones.

## **Create a blank table**

To create a blank table:

1.  Click **Knowledge** on the sidebar
2.  Select **Tables**
3.  Click **Create table**
4.  Click **Add** and start adding records

Each table stores records. A record is one individual entry, such as a vendor, an asset, or a customer account.

Custom fields define the information each record stores. Use them for details such as owners, categories, or other attributes that help your team find and use the data consistently.

To create a custom field in a table:

1.  Click the **Customize** button
2.  Click **Fields**
3.  Click **+ Add**

To bring existing data into a table, read [Import data into tables](https://help.asana.com/s/article/import-data-into-tables?language=en_US).

## Create a table from projects

From your project, create a table to give your reference data a consistent home in Asana. Creating a table doesn’t change or delete your original project. 

1.  Navigate to the desired project
2.  Click the **drop-down** next to the project’s name
3.  Select **Create table from project**
4.  Choose the project details and task details to include in your table.
5.  Click **Create new table**

> Your original project remains unchanged unless you select **Archive original project** in step 4.

## Tables permissions

Tables uses Asana's existing permission model at the table and record level. Access controls also apply when one record references another, so people will not receive lookup information from records they cannot access. Access controls can also be set for specific people on an individual record level to manage permissions for each entry.

## Know when to use tables

Use tables for reference data such as vendor lists, asset catalogs, property rosters, and customer accounts.

Tables is not a CRM for managing sales pipelines, a BI warehouse, a SQL database, a formula-heavy spreadsheet, or a standalone automation platform.

Tables works best when teams need structured information that stays connected to Asana work.

Tables gives AI Teammates and Asana Dash more useful information to work with.
