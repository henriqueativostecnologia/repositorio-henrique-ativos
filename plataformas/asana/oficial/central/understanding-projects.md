# Understanding projects

Projects allow you to organize the tasks related to a specific initiative, goal, or big piece of work into various views, including list, board, timeline, and Gantt.

#### Related articles:

- [Project customization and views](https://help.asana.com/s/article/project-customization-and-views?language=en_US)
- [Project owner and members](https://help.asana.com/s/article/project-owner-and-members?language=en_US)
- [Project importing and exporting](https://help.asana.com/s/article/project-importing-and-exporting?language=en_US)

## Create a project

#### To create a new project:

1.  Click the **Quick add** button
2.  Select **Project**

A new screen will present you with 3 options: create a **Blank project**, **Use a template**, or **Import a** **spreadsheet**.

Click **Blank project** to start from scratch.

In organizations, you must belong to a [team](https://help.asana.com/s/article/team-basics?language=en_US "team") before you can create a project.

### Set up your new project

#### From the project details screen, you can:

1.  Enter a project name
2.  Select the team you wish to add the project to
3.  Set your project privacy settings
4.  Select a [list](https://asana.com/guide/help/views/list "list"), [board](https://asana.com/guide/help/views/boards "board"), [timeline](https://asana.com/guide/help/premium/timeline#gl-viewing-timeline "timeline"), or [calendar](https://asana.com/guide/help/views/calendar "calendar") layout
5.  Click C**reate project** once the details have been added

Your new project will load in the main pane and appear in the sidebar.

> In organizations, the create project button will auto-populate with the team highest in your sidebar. Click the **Team** field to manually select which team your project will be created in.

## Project actions

You can take many actions on your projects in Asana. [Search views](https://asana.com/guide/help/fundamentals/search#gl-search-views "Search Views") and [My tasks](https://asana.com/guide/help/fundamentals/my-tasks "My Tasks") will have variations of these actions.

#### Click the drop-down arrow to access the following options:

1.  Edit project details - modify the name, team, owner, due date, or description of your project
2.  Manage project permissions
3.  Set color & icon
4.  Copy project link
5.  Duplicate
6.  Save as template
7.  Add to Portfolio
8.  Import/Export
9.  Archive - archive the project
10. Delete project

> Favorite the project by clicking the star symbol beside the project name, adding it to your [sidebar](https://asana.com/guide/help/fundamentals/navigating-asana#gl-sidebar "sidebar") for easy access.

### Project name and description

A project's name and description provide context on what the project is and what it aims to achieve. When you open a project, the project name is displayed prominently in the [header](https://asana.com/guide/help/fundamentals/navigating-asana#gl-header "header").

#### To change a project's name and description:

1.  Click on the drop-down menu
2.  Select **Edit project details**

Project descriptions support [rich text](https://asana.com/guide/help/fundamentals/text#gl-rich-text "rich text") and emojis.

### Custom project icons

You can personalize your project by using custom project icons. Upload a JPG or a PNG to replace the default project icon. These custom icons will appear in your sidebar, home, portfolios, and team pages, making it easier to find your projects.

From the drop-down menu, click **Set color & icon** and go to the **Custom icon** tab to upload an image.

### Print a project

#### To print a project:

1.  Click the drop-down menu
2.  Click on **Export/Print**
3.  Select the **Print** option

Your printed copy will include:

- Task names and descriptions
- Subtask names and descriptions
- Section or column names
- Incomplete/complete checkbox
- Custom fields
- Task due dates

The printed version reflects the current view of your project or **My tasks**. If you want the printed version to be sorted or filtered, save the filtered or sorted view and then print.

This example shows a project where filters and sorting are active. Click **Save view** on the right before printing, in order for the printed version to only show the filtered and sorted tasks.

You can also use the print option to save your project as a PDF. Most [browsers](https://asana.com/guide/help/faq/connectivity#gl-browsers "browsers") will offer a "Save as PDF" option in their print dialog. Note that printing a project is currently not supported on the overview, timeline, workflow, dashboard, and Gantt view tabs.

## Browse projects

Find projects you've created or that have been shared with you with the project directory. The project directory allows you to see all the projects you have access to. You can search using the search bar in the directory or by using filters.

#### To access the project directory:

1.  Click the drop-down arrow next to **Projects ** in the sidebar
2.  Select **Browse projects**

## Duplicate a project

Duplicate a project to use it as a template for common workflows.

#### To duplicate a project:

1.  Click the drop-down menu next to the project's title
2.  Select **Duplicate**

Check your desired fields; these will be included in your new project. Click **Create New Project** once finished.

> For workflows you use all the time, consider using [project templates](https://asana.com/guide/help/projects/project-templates-2.0 "project templates") instead of duplicating projects one by one.

## Archive a project

Archiving projects allows you to focus on active projects. Only [project admins](https://help.asana.com/s/article/project-permissions?language=en_US) can archive a project.

### To archive a project:

1.  Click the drop-down menu
2.  Select **Archive**

Anyone with a link to the archived project can access the project quickly. You can also find it through **Search**.

Tasks in archived projects that are assigned to you will still show in your [My tasks](https://asana.com/guide/help/fundamentals/my-tasks "My tasks").

> Looking to mark a project as complete? We recommend [completing a project](https://asana.com/guide/help/projects/progress#gl-completing-project "completing a project") in the project status, as archiving a project will not update its status.

### Unarchive a project

You can always restore a project via the project header or the sidebar.

### To unarchive a project:

1.  Click the drop-down menu
2.  Select **Unarchive**
3.  Or click the restore button in the top right-hand corner

> Archived projects will never expire and do not get deleted.

## Delete a project

Deleting a project deletes it for everyone. Only delete projects that you are sure no one wants to keep. Only [project admins](https://help.asana.com/s/article/project-permissions?language=en_US) can delete projects.

> [Assigned tasks](https://help.asana.com/s/article/understanding-tasks?language=en_US "Assigned tasks") and [tasks that are associated with other projects](https://asana.com/guide/help/tasks/fields#gl-multi-home "tasks that are associated with other projects") will not get deleted.

### To delete a project:

1.  Click the drop-down menu
2.  Select **Delete project**

> All project members will receive an [email notification](https://asana.com/guide/help/email/email-from-asana "email notification") of the deletion and the person who deleted it will receive a recovery link. This link will expire after 30 days. Project deletion emails won't be sent if the project is less than one day old and has zero tasks in it.

## Move a project to another team

You can only move a project to teams that you're a [member](https://help.asana.com/s/article/project-owner-and-members?language=en_US) of.

#### To move a project to another team:

1.  Click the drop-down menu
2.  Select **Edit project details**
3.  Type the name of the destination team

### Move projects to another workspace or organization

Workspaces and organizations have hard barriers. To move a project to another space, you'll need to create a new project in your chosen workspace or organization and manually copy and paste task lists from the existing project to this new project.

Third-party tools like [this one](https://kothar.net/blog/organise_asana) may help you transfer or copy an Asana project to a different workspace. Asana isn't liable or responsible for third-party tools.

### Copy a project link

Copy the project URL to easily share with team members.

### To copy a project link:

1.  Click the drop-down menu
2.  Select **Copy project link**
