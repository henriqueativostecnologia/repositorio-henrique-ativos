# How to access the admin console

The admin console empowers all Asana admins and super admins with the administrative capabilities they need to champion Asana within their organizations.

The admin console offers a range of administrative capabilities, including insights into how the organization uses Asana, management of all members and teams, and control over security settings. Admins can access detailed metrics, manage user roles, and customize security settings.

The admin console requires a paid plan, but you can explore the admin console for free. Start a [free Asana trial](https://asana.com/create-account) today.

## Access the organization admin console

#### To access the admin console:

1.  Click on your profile photo
2.  Select **Admin Console** from the drop-down menu.

> [Team admins](https://help.asana.com/s/article/team-admin?language=en_US) cannot access the admin console.

## Insights tab

From the Insights tab, you can:

- Understand how your organization is using Asana through high-level metrics
- See recently added teammates
- View the most influential members in your organization (active members with the most invites sent, teams created, and projects shared in Asana)
- With Asana [Advanced](https://asana.com/plan/advanced) or [legacy tier Business](https://asana.com/pricing-legacy), you can view detailed engagement activity over time to spot trends in your organization's usage of Asana

Project count does not include archived projects or deleted projects.

Task count includes both complete and incomplete tasks, but not deleted tasks.

## Frequently asked questions

### How do I access the admin console in Asana?

Click on your profile photo, then select Admin Console from the drop-down menu.

### Who can access the admin console?

Only admins and super admins can access the admin console; team admins cannot access it.

### What information is available in the Insights tab?

The Insights tab displays high-level metrics about organization usage, recently added teammates, most influential members, and with Asana Advanced or legacy Business plans, detailed engagement activity over time to identify usage trends.

### Does the admin console require a paid plan?

The admin console requires a paid plan, but you can explore it for free by starting an Asana trial.
