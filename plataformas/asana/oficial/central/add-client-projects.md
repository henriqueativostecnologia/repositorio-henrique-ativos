# Add client projects

**To purchase Client Management, your organization must have an active Starter or Advanced base subscription. Client Management is not included in these plans by default.**

Use client projects when you want the work for a client and the client context to stay linked. You can add work from the client or connect an existing project from the project itself.

Client projects help you keep all of the work you do for a client connected to that client’s context. You can group regular Asana projects under a client so the work stays organized in one place.

## Add work from a client

1.  Open the client and go to the **Projects** tab.
2.  Select **Add work**.
3.  Choose **Add a project by name** to create a new project or add an existing one.

## Connect an existing project to a client

You can also start from a project and connect it to a client.

1.  Open any project.
2.  Click the drop-down next to the project's name.
3.  Select **Connect to client**.
4.  Type the name of the client you want to attach the project to.

**Note**: A client holds projects only. You cannot nest a portfolio under a client.

## Connect a project to a client from the Projects mode

1.  Navigate to **Projects** from the sidebar
2.  Click the field in the **Client** column
3.  Add a client
