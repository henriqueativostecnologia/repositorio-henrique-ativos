# Automation actions

**Automations are available on** **Asana [Starter](https://asana.com/plan/starter), [Advanced](https://asana.com/plan/advanced), [Enterprise](https://asana.com/enterprise), and [Enterprise+](https://asana.com/enterprise) tiers, as well as [legacy tiers](https://asana.com/pricing-legacy) Premium, Business, and Legacy Enterprise.**

**Visit our [pricing page](https://asana.com/pricing) for more information.**

[Automations](https://help.asana.com/hc/en-us/articles/14216757795227-Rules) allow you to streamline routine tasks and establish workflows with ease. For a automation to work, you need a **trigger** that activates the automation and an **action** that is performed automatically. This article will cover the various automation actions in more detail. For information on automation triggers, please refer to [this Help Center article](https://help.asana.com/hc/en-us/articles/23060756580891-Rule-triggers).

## What is an automation action?

An automation action is an automated activity performed when a automation's trigger event occurs. Automation actions allow you to streamline routine tasks and establish workflows by automatically taking specified actions like moving tasks, creating new tasks or subtasks, updating task details, and more.

## How to choose an automation action

 

To select a automation action:

1.  Navigate to **Customize** in the top-right corner of your project
2.  Click **Automations**
3.  Click **+ Add**, then **Start from scratch**
4.  Choose your desired triggers and conditions first if you prefer
5.  Next, click the **Add step** card to view the available actions
6.  Click **Publish** to save and activate the new automation

## Automation action examples

There are a variety of actions you can configure, for automations to perform automatically. Here are some common examples:

### Move task

This action moves a task to a specified project section when the automation is triggered. For example, you could create a automation to move tasks to an "Urgent" section when their custom field status changes to "Urgent".

### Change task field

This action can assign the task to a specific user when the automation runs. A common use case is automatically reassigning tasks when they move through project stages, or changing a task's due date based on an urgency custom field.

### Create new task

You can automatically generate tasks in the project with this action. This is useful for breaking down large tasks into step-by-step processes. When setting up the automation, you pre-define the task title, assignee, and other details.
