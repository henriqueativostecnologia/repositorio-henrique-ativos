# Divisions in paid organizations

**Available on Asana** [ **Enterprise**](https://asana.com/enterprise) **and** [ **Enterprise+**](https://asana.com/enterprise) **tiers.**

Divisions in paid orgs help you organize users into divisions, delegate administration, and control how paid licenses are assigned. These divisions are all under the same domain. Use them when you want central oversight for an organization while still letting division admins manage specific groups of users.

Admins and super admin will be able to govern each division and assign division admins that can manage users in that specific division. 

## What are divisions in paid organizations?

Divisions in paid orgs share a single paid Asana configuration, which gives organization admins centralized oversight while letting division admins manage a subset of users. Organization admins and super admins can access every division, while division admins can manage only the divisions they are assigned to.

You can use divisions to help with license assignment, user management, and cost attribution. 

> View-only users can also be assigned to a division and are converted to paid users when they are added.

## How to create a division

1.  Navigate to the **Divisions tab** in the admin console, 
2.  Click **Create division**.
3.  Enter a name for the division.
4.  Optionally, add division admins.
5.  Optionally, add users to the division.
6.  Click **Create division**.

After you create the division, you go to its divisional admin console.

## Set invite approvals

1.  On the division’s **Security tab**, click **Invited users**.
2.  Choose whether approval is **Required** or **Not required**.
3.  Click **Save changes**.

If approval is not required, invited users are automatically added to the division and assigned a license. If approval is required, invited users create requests that division admins, organization admins, and super admins can review.

## Manage users in divisions

You can assign users from the **Unassigned users** list. From the **Divisions** tab, click **Unassigned users**. You’ll then see a list view of unassigned users.

Use the **Division** field to move a user into a division. Users who are already in another division will not show up in this list.

## Remove users or delete a division

Admins can remove users from a division from either the organization or the division. When you remove a user from a division, you can also remove their license and make them view-only.

To delete a division, open the division dashboard, select the three dot icon, and click **Delete** **division**. You can choose to keep users licensed or remove them and make them view-only.

## Set default license behavior

Organization super admins and admins can set a default license for new signups and invited users. If a user is invited by a division with its own invite controls, the division’s setting takes priority.

Super admins and admins can access license controls through the admin console:

1.  Click your profile photo in the top-right corner
2.  Select **Admin console**
3.  Navigate to the **Security** tab
4.  Find the **New signups** or **Invited users** sections

 

## Division dashboard

The division dashboard shows the total number of divisions, users in divisions, unassigned users, and the list of divisions with their user counts and division admins. Organization admins and super admins can manage the full setup, while division admins can only manage the divisions they own.

## Frequently asked questions

### What happens when I require admin approval for invited users?

When this setting is enabled, users who are invited to join a division will not automatically receive a license. Instead, their request appears in the Requests queue where admins can review and approve or deny it. The user will not have access to paid features until their request is approved.

### Can I set different default licenses for new signups or invited users?

Yes. Admins can choose whether new signups automatically receive an Enterprise license or a View only license. View only users do not count toward paid seats.

### How do I know which users are unassigned?

The **Divisions** dashboard in the admin console shows a count of unassigned users. Click on this number to see the full list and assign users to divisions as needed.

### Can I change a user's division assignment later?

Yes. Admins can reassign users to different divisions at any time from the Users page in the admin console.
