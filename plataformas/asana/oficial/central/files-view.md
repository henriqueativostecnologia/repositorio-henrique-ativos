# Files view

Files view displays a gallery-style view of all the images, documents, and files [attached to tasks](https://asana.com/guide/help/tasks/comments#gl-attachments "attached to tasks") in a project or your My tasks.

**Like what you see? Get started with a free Asana trial today. [Try for free.](https://asana.com/create-account "Try for free")**

Click the task name below an attachment preview to view details of the task that the file is attached to.

Files view will only show attachments already added to tasks - you cannot upload new files without attaching them to a task first. Files will need to be removed manually from each task.

**Want to learn more? Check out all the [features of Asana project views](https://asana.com/features/project-management/project-views).**
