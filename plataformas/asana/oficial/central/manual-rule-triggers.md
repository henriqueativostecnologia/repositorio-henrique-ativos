# Manual automation triggers

Asana supports the ability to manually trigger automations, giving you more control over when your automations run. Instead of relying solely on pre-set conditions for an automation to run, manual triggers allow you to manually initiate automation actions, adapt to process changes, and ensure consistent data across your tasks and projects.

Manual automation triggers let you proactively move tasks from one workflow stage to another, without needing to wait for certain criteria to be met. This also removes any need to create inefficient workarounds to simply force an automation to run.

Manual automation triggers also allow you to apply automation actions to tasks which already inhabit a project, akin to running an automation "retroactively" to standardize data on existing tasks. This is particularly useful for situations where an automation usually fires whenever a task is added to a project, but can't be triggered by tasks already inside the project.

## Create a manual automation trigger

To create a manually triggered automation:

1.  Navigate to **Customize** in the top-right corner of your project.
2.  Click **Automations**.
3.  Click **+ Add**.
4.  Click **Start from scratch** to open the automation builder.
5.  Under **What starts this workflow?**, click **Manual**. 
6.  Next, choose a label for the manual trigger.
7.  Configure your desired automation actions.
8.  Click **Publish** when you are finished. The manual trigger must be named before the automation can be published.

## Manually triggering an automation

Once created, you can trigger your manual automation from two places:

### Project list view

1.  Right-click on a task and select **Run an automation** from the menu.
2.  Choose the label of the manual trigger to run the associated automation.

### Task pane

1.  Click the three-dot icon in the task header and select **Run an automation** from the menu.
2.  Choose the label of the manual trigger to run the associated automation.

### Portfolios

1.  Right-click on a project and select **Run an automation** from the menu.
2.  Choose the label of the manual trigger to run the associated automation.

## FAQ

### Can I set criteria for when the manual trigger option appears?

Not currently. The trigger will always show in the relevant menus if the automation exists in that project.

### How many tasks can I multi-select when running a manual automation?

You can multi-select up to 50 tasks at once when running a manual automation.

### How many manual automations can I add per project?

The limit is 50 automations per project, which is shared with all automation types.

### Will manual automations also run on subtasks?

No, manual automations do not currently run on subtasks.

### Who can view and run a manually triggered automation?

This depends on the role the user has in the project which contains the automation. Project admins and editors can view and run these automations via the manual trigger. Commenters and viewers cannot.
