# Task fields

This article will cover the different fields you’ll find within a task details pane. From marking tasks complete, adding assignees, setting due dates, to multi-homing tasks into projects.

#### Related articles

- [Tags](https://help.asana.com/s/article/tags?language=en_US)

## Task details pane

All task fields can be found and modified from the task details pane. Click on any task to reveal its details in the [task details pane](https://asana.com/guide/help/fundamentals/navigating-asana#gl-right-pane).

#### From the top of the task details pane, you can:

1.  Mark the task [complete or incomplete](https://help.asana.com/s/article/task-fields?language=en_US)
2.  [Like](https://asana.com/guide/help/tasks/fields#gl-likes "Like") the task
3.  Upload [files](https://asana.com/guide/help/tasks/comments#gl-attachments "files")
4.  Add [subtasks](https://asana.com/guide/help/tasks/subtasks "subtasks")
5.  Copy the task's URL
6.  View the task in full screen
7.  Access additional task options

 

 

#### Fill out a task's fields:

1.  Edit the task's name
2.  Add an [assignee](https://asana.com/guide/help/tasks/understanding-tasks#gl-assignee "assignee")
3.  Set a [due date](https://help.asana.com/s/article/scheduling-tasks-using-start-dates-due-dates-and-times?language=en_US?language=en_US#gl-due-date "due date")
4.  Add the task to a [project](https://asana.com/guide/help/tasks/fields#gl-multi-home "project")
5.  Add [task dependencies](https://asana.com/guide/help/tasks/dependencies "task dependencies")
6.  Add [tags](https://help.asana.com/s/article/tags?language=en_US "tags") and [custom fields](https://asana.com/guide/help/premium/custom-fields "custom fields")
7.  Add a [description](https://asana.com/guide/help/tasks/fields#gl-description "description") to give the task more context
8.  Post a [comment](https://asana.com/guide/help/tasks/comments "comment")
9.  Add or remove collaborators

## Mark tasks complete or incomplete

Mark a task complete to indicate that it's done.

 

#### You can mark a task complete by either:

1.  Clicking the check icon from the main pane
2.  Clicking the **Mark complete** button from the task details pane

You can mark a task incomplete if there is still work to be done by clicking the check mark or the **Completed** button.

> By default, only incomplete tasks will appear in your My tasks and projects. You can [filter to show completed tasks](https://help.asana.com/s/article/my-tasks?language=en_US).

## A task's associated projects

A task can belong to up to 20 different projects at any given time. You can see all projects a task belongs to in the **projects** field in the task details pane and the section it belongs to.

To add the task to another project, click **Add to projects**. To remove the task from a project, click the **x** icon next to the project's name.

You will see the task in every project it's multi-homed to. This is useful when a task is relevant to multiple projects.

> Please note, you will only see a task's associated projects if you have access to those projects. Learn more about [project permissions](https://help.asana.com/s/article/project-permissions?language=en_US).

The task will exist simultaneously in all of those projects. This will not duplicate the task - if you complete the task in one project, it will be completed in all projects it is associated with.

> Press `Tab+P` on your keyboard to quickly add the task to a project.

## Task description

Task descriptions allow you to describe, give directions, or add context to a task. The description field is in the task details pane.

To format the task description click the **+** icon to open the multi-select toolbar.

> Task descriptions support [rich text](https://asana.com/guide/help/fundamentals/text#gl-rich-text "rich text") and emojis.

## Likes

Use a like to quickly acknowledge, approve, or praise your teammate’s work.

Click the thumbs up icon to like a task.

> You can also like tasks via [inbox](https://asana.com/guide/help/fundamentals/inbox "inbox") notifications.

Once the task is liked, it will appear:

1.  Next to the task's name in the main pane
2.  At the top of the task details pane

> To un-like the task, simply click the thumbs up icon again.

You will see a like option for:

- Tasks
- Task comments
- Task attachments
- Task completion
