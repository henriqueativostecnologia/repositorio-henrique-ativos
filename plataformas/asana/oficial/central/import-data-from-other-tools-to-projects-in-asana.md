# Import data from other tools to projects in Asana

Move your workflow to Asana using data from projects in other work management tools.

Import data from spreadsheets and other work management tools into Asana with just a few clicks. Get started with a [free Asana trial](https://asana.com/create-account) today.

## CSV importer

The [CSV Importer](https://asana.com/guide/help/api/csv-importer "CSV Importer") allows you to create and update projects in Asana with information saved in CSV files exported from other tools. Simply download a CSV file with your project data and then upload it into Asana. After downloading your data into a CSV file, you can [name the columns in your spreadsheet to match fields in Asana](https://asana.com/guide/help/api/csv-importer#gl-tips).

> See [community tips](https://forum.asana.com/c/forum-en/integrations/9) on importing data and setting up integrations.

## How to import data from monday.com to a project in Asana

You can use the **CSV Importer** to move data to projects in Asana by exporting a CSV file from monday.com:

1.  Click the menu icon from a board
2.  Select the **Export to Excel** option
3.  Open the file that was downloaded and [save the primary sheet as a CSV file](https://asana.com/guide/help/api/importing-csv-from-other-tools#gl-google-sheets "save the primary sheet as a CSV file")
4.  Use the CSV Importer to [upload the CSV file](https://help.asana.com/s/article/preparing-data-for-csv-import?language=en_US#gl-import-csv) created to Asana

The data will be mapped in Asana based on the [names of the columns](https://help.asana.com/s/article/preparing-data-for-csv-import?language=en_US#gl-tips "names of the columns") in the CSV file. You can map specific information using [custom fields](https://help.asana.com/s/article/custom-fields?language=en_US "custom fields").

## How to import data from Trello to a project in Asana

You can use the **CSV Importer** to move data to projects in Asana by exporting a CSV file from Trello if you have a Trello Business Class subscription:

1.  Click the board menu from a board
2.  Under **More**, select the **Print and Export** option
3.  Select **Export as CSV**
4.  Use the CSV Importer to [upload the CSV file](https://help.asana.com/s/article/preparing-data-for-csv-import?language=en_US#gl-import-csv) created to Asana

You can use tools like the [Export for Trello](https://chrome.google.com/webstore/detail/export-for-trello/nhdelomnagopgaealggpgojkhcafhnin?hl=en-US "Export for Trello") chrome extension to get a CSV file if you do not have a Trello Business Class subscription.The data will be mapped in Asana based on the [names of the columns](https://help.asana.com/s/article/preparing-data-for-csv-import?language=en_US#gl-tips "names of the columns") in the CSV file. You can map specific information using [custom fields](https://help.asana.com/s/article/custom-fields?language=en_US "custom fields").

## How to import data from Smartsheet to a project in Asana

You can use the **CSV Importer** to move data to projects in Asana by exporting a CSV file from Smartsheet:

1.  Click on **File** to select **Export \> Export to Microsoft Excel** or **Google Sheets**
2.  Open the file that was downloaded and [save the primary sheet as a CSV file](https://asana.com/guide/help/api/importing-csv-from-other-tools#gl-google-sheets "save the primary sheet as a CSV file")
3.  Use the CSV Importer to [upload the CSV file](https://help.asana.com/s/article/preparing-data-for-csv-import?language=en_US#gl-import-csv) created to Asana

Before exporting the file, make sure that the sheet is formatted with column headers and rows of tasks.The data will be mapped in Asana based on the [names of the columns](https://help.asana.com/s/article/preparing-data-for-csv-import?language=en_US#gl-tips "names of the columns") in the CSV file.
