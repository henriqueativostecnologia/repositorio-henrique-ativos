# Automations integrations and widgets

**Available on Asana [Starter](https://asana.com/plan/starter), [Advanced](https://asana.com/plan/advanced), [Enterprise](https://asana.com/enterprise), and [Enterprise+](https://asana.com/enterprise) tiers, as well as [legacy tiers](https://asana.com/pricing-legacy) Premium, Business, and Legacy Enterprise.**

**Visit our [pricing page](https://asana.com/pricing) for more information.**

[Automations](https://asana.com/guide/help/premium/rules#gl-integrations "Rules") are an important part of many workflows, and so are integrations with third party services (e.g., Slack). You can use an automation to integrate your team's favorite tools into your work in Asana, and let automations do the heavy lifting automatically.

You can set specific triggers in your Asana projects, and trust automations to automate your workflow when your chosen criteria are met. For example, the [Slack + Asana](https://asana.com/apps/slack "Slack + Asana") automations integration allows you to send a message to a teammate or channel in Slack based on your chosen trigger, like task completion.

You can [create an automation](https://asana.com/guide/help/api/microsoft-teams#gl-custom-notifications "create a rule") which pings a specific channel in [Microsoft Teams](https://asana.com/apps/microsoft "Microsoft Teams") based on criteria such as a change in a custom field value. Or [create new issues](https://help.asana.com/s/article/asana-for-jira-cloud?language=en_US#gl-data-sync-workflows "create new issues") in [Jira Cloud](https://asana.com/apps/jiracloud "Jira Cloud") when a task is added to a particular project section. Additional automations integrations include [Gmail](https://asana.com/apps/google-gmail "Gmail") and [PagerDuty](https://asana.com/apps/pagerduty "PagerDuty"). Learn more about configuring automations integrations for PagerDuty [here](https://help.asana.com/s/article/rules-integrations-for-operations-and-support?language=en_US "here").

> Automations using integrations require proper [app management](https://asana.com/guide/help/premium/admin-console#sts=App%20management%20and%20integrations "app management") settings and user authentication with the third party services.

## Triggering actions within apps

There are three types of triggers for automations, and this is also true for triggering actions with automations integrations.

#### Task added type triggers

- Task added to a section
- Task added to this project

#### Task updated type trigger

- Based on approval status
- Based on completion status
- Based on assignee
- Based on due date
- Based on attachments added
- Based on comments added

#### Task timing type trigger

- Task is no longer blocked
- Due date is approaching
- Task is overdue
