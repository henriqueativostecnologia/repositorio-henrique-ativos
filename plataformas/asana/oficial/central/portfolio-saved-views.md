# Portfolio saved views

Portfolio saved views allow portfolio admins and editors to customize and save specific views of their portfolios. This feature enables users to quickly access tailored views with pre-set filters, sorting criteria, and layout preferences.

By saving these customized views as new tabs at the top of the portfolio, teams can access them quickly and focus on the most relevant portfolio information for their needs.

## Creating a portfolio saved view

To create a portfolio saved view:

1.  Apply sorts and filters to your portfolio.
2.  Click **Save view** to save this view as a default list tab for everyone.
3.  Click **+ Save as a new tab** to create a new tab for this customized view.
4.  From the three-dot menu, you can rename the tab, reorder tabs, remove tabs, or set them as a default tab.

## Views to try out

Set up multiple views by project status, to easily reference work that is **On track**, **At risk**, **Off track** or **Not started**.

Sort projects within your portfolio by a priority custom field to see work in priority order.

Use the dynamic filter **Just my work** and save as a new tab; every portfolio member will see the projects assigned to them when viewing this tab.

## Additional information

If you want to export the portfolio, the PDF export will apply to the active list view the user is viewing.

Users will not be able to add disabled tabs such as timeline tabs with over 250 items or timeline tabs with a nested portfolio.
