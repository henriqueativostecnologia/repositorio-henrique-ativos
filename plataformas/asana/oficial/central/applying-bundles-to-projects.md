# Applying bundles to projects

**Available on Asana [Enterprise](https://asana.com/enterprise "https://asana.com/enterprise") and [Enterprise+](https://asana.com/enterprise "https://asana.com/enterprise") tiers, as well as [legacy tier](https://asana.com/pricing-legacy "https://asana.com/pricing-legacy") Legacy Enterprise.**

**Visit our [pricing page](https://asana.com/pricing "https://asana.com/pricing") for more information.**

Bundles are any combination of rules, fields, sections, and task templates that can be applied across multiple projects at once.

This article will explain how to apply bundles to your projects.

## How to apply an existing bundle

 

#### To apply a bundle:

1.  Navigate to the **Customize** menu
2.  Click **+Add bundle**
3.  Explore the bundles gallery. Use the filter and search option at the top to search within the bundles gallery or select the relevant bundle and click **Add to project**.

 

All applied bundles will appear in the customize menu.

## Applying a bundle to multiple projects at once

You can apply a bundle to multiple projects using the **+ Add to projects** button.

#### To apply bundles to multiple projects:

1.  Select the bundle you want to apply
2.  Navigate to the **Dashboard** tab
3.  Click **+ Add bundle to projects** button and start adding the projects

## Remove a bundle from multiple projects at once

#### To remove a bundle from many projects at the same time:

1.  Select the bundle you want to remove
2.  Navigate to the **Dashboard** tab
3.  Hover over a project and click the checkbox on the left side
4.  Click the checkbox for any other projects you wish to remove the bundle from
5.  Click **Remove bundle** from the pop-up menu

## Applying bundles to projects in portfolios

You can apply a bundle to all the projects within a [portfolio](https://help.asana.com/s/article/portfolios-overview?language=en_US) at once using the **+ Add to my work** button from the bundle dashboard. This will allow you to apply the same bundle to multiple projects across the portfolio.

#### To apply a bundle to a portfolio:

1.  Navigate to a project, click **Customize**, and select **Bundles**
2.  Select the bundle you want to add to the portfolio
3.  Click the **Dashboard** tab
4.  Click **+Add to my work**
5.  Scroll down to find the portfolio or type the portfolio’s name
6.  Click **Add bundle to projects**

The projects will successfully add to all the projects in a portfolio except for the scenarios below:

- Nested portfolios. Bundles need to be added to nested portfolios independently.
- Private projects you don't have access to
- Projects that already have this bundle
- Projects you're a member of with the following permission levels: Commenter, Viewer
- Projects where only project admins have permission to customize the project
- A project that has hit the max limit for the number of bundles (5), rules (50), fields (100), or task templates (50) it can have
