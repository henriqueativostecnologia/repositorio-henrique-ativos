# ID custom fields

**Available on Asana** [**Starter**](https://asana.com/plan/starter)**,** [**Advanced**](https://asana.com/plan/advanced)**,** [**Enterprise**](https://asana.com/enterprise)**, and** [**Enterprise+**](https://asana.com/enterprise) **tiers, as well as** [**legacy tiers**](https://asana.com/pricing-legacy) **Premium, Business, and Legacy Enterprise.**

**Visit our** [**pricing page**](https://asana.com/pricing) **for more information.**

Task names with descriptions can be helpful but can also be long and hard to remember, especially if you are working on intake or ticketing tasks with similar names.

With ID custom fields, you can create unique and readable IDs for tasks. ID custom fields can be added to any project. When you add ID custom fields to a project, it will automatically generate incremental IDs for both existing and new tasks.

## Adding an ID custom field

To add an ID custom field:

1\. You can add an ID custom field from the **Customize** menu or by clicking the **+** button in the column header

2\. Select **ID** as the field type

3\. Create a custom prefix for your ID

4\. Click **Confirm**

5\. ID values will be generated for all existing and incoming tasks in the project

You can also reuse an existing prefix/field from the library.

ID custom fields can have prefixes that contain letters and numbers, up to 20 characters, and must be unique. All ID custom fields will be shared with your domain by default.

 

## Some important information about ID custom fields

- ID custom field values are immutable and unique to the entire domain
- Projects and tasks can have more than one ID custom field
- ID custom fields can be deleted and/or removed from a project if permissions allow. Removing an ID custom field from a project will not delete IDs from tasks in that project
- You can find tasks by ID using basic and advanced search and @mention a task in a comment or description using an ID
- ID custom fields are generated in the order that a task was added to a project, not the creation date of the task
