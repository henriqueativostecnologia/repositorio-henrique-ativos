# Project customization and views

This article details the essentials of project customization and the various [project views](https://help.asana.com/s/article/create-projects-in-asana?language=en_US) available to you. Use these to enhance your workflow and tailor your team’s projects for optimal efficiency and clarity.

## Project overview

[Project overview](https://help.asana.com/s/article/project-overview-tab?language=en_US) is the team's persistent hub to showcase a birds-eye view of the what, why and how of a project and drives easy understanding of its ongoing context. The overview sets the tone for how you and your team will work together on the project, and also is where the name, description as well as roles of project members are accessible.

## Project views

Everyone organizes their work differently; some like lists, others sticky notes that can be moved through different sections. Because everyone works differently, Asana has different project views available. Choose from [List](https://help.asana.com/s/article/list-view?language=en_US), [Board](https://help.asana.com/s/article/board-view?language=en_US), [Gantt](https://help.asana.com/s/article/gantt-view?language=en_US), [Timeline](https://help.asana.com/s/article/timeline?language=en_US), [Dashboard](https://help.asana.com/s/article/project-dashboards?language=en_US), [Messages](https://help.asana.com/s/article/messages?language=en_US), [Files](https://help.asana.com/s/article/files-view?language=en_US) and [Calendar](https://help.asana.com/s/article/calendar-view?language=en_US). This means you can choose the view that suits your work style and helps you visualize tasks more effectively. Tasks can be grouped differently across List and Board views. Check out [this article](https://help.asana.com/s/article/create-projects-in-asana?language=en_US) for more.

## Saved tabs

See what's most relevant for you and your team with saved tabs for projects. Saved tabs allows project admins and editors to create up to 50 tabs per project with multiple list, board, calendar, gantt view or timeline tabs.

 

As a project admin or editor you can apply filters and sorts to projects, as well as save the view as a new tab in your project.

#### To create a saved tab:

1.  Filter and sort your project to your liking
2.  Click **Save view** to save this view for everyone
3.  Click **+ Save as a new tab** to create a new tab for that specific view. From the three dot icon, you can rename, reorder, remove or set tabs as default.

You can use emojis as your tab icon, by starting the tab name with the emoji.

#### Some views to try:

- Set up multiple calendar views to see the projects schedule by month
- Set up a board view to show the progress for open tasks
- Reorder project views to put the most important or most commonly used view first
- Use the dynamic filter **Assignee is Me** and save it as a new tab; everyone will see the tasks assigned to themselves

> Non-task views (Overview, Workflow, Dashboard, Messages, Files) cannot be duplicated or renamed.

If your organization is currently on an [Enterprise](https://asana.com/enterprise), [Enterprise+](https://asana.com/enterprise) or [Legacy Enterprise](https://asana.com/pricing-legacy) plan, it’s possible that the project admin updated the project permissions to **Project Admins only**. This means the project editor can’t modify tabs in the project.

You can access saved tabs from your mobile on iOS.

## Project colors

If you have a lot of projects, but only a few are relevant or urgent to you, use the color feature to make those projects more visually distinct.

#### To change a project's color:

1.  Click the drop-down menu
2.  Select **Set color & icon**

## Sections

Sections allow you to divide and organize the tasks in your project. Sections can be used to create categories, workflow stages, priorities, and more. You can also use sections to trigger rules when tasks are moved into them.

For more detailed information, visit our article on [sections](https://help.asana.com/s/article/sections?language=en_US).

## Project schedules

**Available on Asana [Starter](https://asana.com/plan/starter), [Advanced](https://asana.com/plan/advanced), [Enterprise](https://asana.com/enterprise), and [Enterprise+](https://asana.com/enterprise) tiers.**

Project schedules allow you to set a working schedule for your project, helping you manage Service Level Agreements (SLA) for requests. For example, you can define working hours so tickets are paused during non-working hours.

> Project schedules will affect [tasks with dependencies](https://help.asana.com/s/article/task-dependencies?language=en_US) and timer custom fields.

#### To define a project’s schedule: 

1.  Click the drop-down next to the project's name
2.  Select **Edit project settings**
3.  Click **Scheduling**
4.  Set your timezone, work days, and hours
