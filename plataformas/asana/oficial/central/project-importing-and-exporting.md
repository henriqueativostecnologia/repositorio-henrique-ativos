# Project importing and exporting

This article covers how to import tasks to projects in Asana and how to export projects using JSON or CSV.

#### Related articles:

- [Understanding projects](https://help.asana.com/s/article/understanding-projects?language=en_US)
- [Project customization and views](https://help.asana.com/s/article/project-customization-and-views?language=en_US)
- [Project owner and members](https://help.asana.com/s/article/project-owner-and-members?language=en_US)

## Import a project to Asana

You can import tasks to a project in Asana using [CSV](https://help.asana.com/s/article/preparing-data-for-csv-import?language=en_US).

Select the project header drop-down menu next to your project‘s name, hover over **Import** then choose **CSV**.

Follow the instructions provided, choosing the project to which you'd like to add your CSV file and the organization it lives in.

To import tasks into an Asana project, you can copy and paste a list of task names into a project. It can be multi-selecting tasks or copying lines of text. Asana will automatically create a new task after each line break.

> Note that [our Support team](https://asana.com/support "our Support team") cannot offer assistance with third-party tools as they are not developed by Asana.

## Export a project

You can export your project to the text-based file formats JSON or CSV. 

Projects can be exported from Asana to maintain data backups, analyze project information in spreadsheet tools, share information with external stakeholders, meet documentation requirements, or integrate project data with other business systems. Sometimes work needs to be accessed or managed outside of Asana, whether for analysis, sharing, or using different tools.

> Aside from projects, you can also export a [Search View](https://help.asana.com/s/article/search-and-search-views?language=en_US "Search View") or your [My Tasks](https://help.asana.com/s/article/my-tasks?language=en_US "My Tasks").

### To export a project:

1.  Click the drop-down menu next to the project's title
2.  Hover over **Export/Print**
3.  Select your desired file type

Learn more about exporting projects [here](https://help.asana.com/s/article/privacy-and-security?language=en_US).

## Frequently asked questions

### What file formats can be used to export Asana projects?

You can export Asana projects to JSON or CSV file formats.

### Can you import tasks into Asana projects?

Yes, you can import tasks using CSV files or by copying and pasting a list of task names directly into a project—Asana automatically creates a new task after each line break.

### What can be exported from Asana besides projects?

Besides projects, you can export Search Views and My Tasks from Asana.

### Why would you export a project from Asana?

Projects can be exported to maintain data backups, analyze information in spreadsheet tools, share with external stakeholders, meet documentation requirements, or integrate data with other business systems.
