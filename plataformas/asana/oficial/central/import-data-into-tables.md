# Import data into tables

Bring data from an external tool or spreadsheet into an **Asana table** using a CSV file. Importing gives you a starting point for organizing your information in Asana without entering each item manually. There are several ways to get data into a table, and each one suits a different starting point.

## How to get data into a table

You can bring data in with a CSV file, create a table from an existing project, or use the Asana MCP server. Forms can also add records to a table as people submit them. For Unito or the Asana API, which are better suited to two-way sync and developer workflows, the steps are more involved, so this article covers the first three options.

Forms can also populate a table. To learn how to set this up, read [Forms in Asana](https://help.asana.com/s/article/forms?language=en_US).

## Prepare your CSV file

Export the information you want to bring into Asana as a CSV file. Export options vary by tool. Learn more on [how to export your data from other tools](https://help.asana.com/s/article/import-data-from-other-tools-to-projects-in-asana).

Before uploading, review the file to make sure it contains the information you want to import. Use clear column headings to help you identify the data during the import process.

## Import your data using a CSV file

1.  Open the table where you want to import your data.
2.  Click **Select a file to import**.
3.  Choose your CSV file to upload.
4.  Review the import preview and check how your columns map to the table’s fields.
5.  Select **Continue to table** to complete the import.

After importing, review the information in your table. Check that the values appear in the intended fields before you start working with the imported data.

## Create a table from projects

From your project, create a table to give your reference data a consistent home in Asana. Creating a table doesn’t change or delete your original project. 

1.  Navigate to the desired project
2.  Click the **drop-down** next to the project’s name
3.  Select **Create table from project**
4.  Choose the project details and task details to include in your table.
5.  Click **Create new table **

> Your original project remains unchanged unless you select Archive original project in step 4.

** **

 

Add additional custom fields to define the information each record stores. Use custom fields for details such as owners, categories, or other attributes that help your team find and use the data consistently.

## Import with MCP

Asana’s MCP integration works with tables, so you can create, read, and update tables and records from a connected AI tool. For example, you can share a CSV file with the AI tool and ask it to create a table from the data.

## Field mapping

Before you finish importing, you can review the import preview and change the field type for any column. For example, you can change a text column to a multi-select field so people can choose from a set of options.

1.  After you select your file, click **Make changes**.
2.  Click the header of the column you want to change.
3.  Select the field type you want, such as **Multi-select field**.
4.  Click **Continue to table**
