# How to convert a ticket to a project or task

Some requests need more coordination than a single ticket can provide. In **Asana Service Management**, converting a ticket to a project lets you organize the work into tasks and sections while keeping a reference to the original request.

## When to convert a ticket to a project

Choose a project when a request involves several steps, teams, or handoffs. Onboarding a group of employees or coordinating an infrastructure migration, for example, may benefit from a shared project plan.

Conversion resolves the original ticket when the project is created, not when the project work is finished. If the request needs to remain open while other work progresses, consider linked work instead of conversion.

## Before you begin

You need access to the ticket and permission to create projects in your organization. If you do not have permission to create projects, the project-creation option is not shown.

Decide who needs access to the project. The requester, queue admins, and other ticket editors are not automatically added as project members.

## How to convert a ticket to a project

1.  Open the ticket
2.  Click the three dot icon at the top-right corner
3.  Click **Convert to project**
4.  Review the project's access and sharing settings, then finish creating the project.

## What happens during conversion

When the project is created, Asana resolves the ticket and adds a comment linking to the project. The resolved ticket displays the linked project, and the project's description includes the source ticket number so you can identify the original request.

## Share the project with the right people

Having access to the ticket does not automatically give someone access to the project.

Check project membership before teammates begin work. Do not assume the requester or everyone in the queue can view the resulting project.

## How to convert a ticket to a task

Some tickets are individual work items that need to be tracked, assigned, and scheduled without requiring a full project plan. In this case, you can convert the ticket to a task.

To convert a ticket to a task:

1.  Open the ticket
2.  Click the three dot icon at the top-right corner
3.  Click **Convert to task**
4.  Fill out the task details
5.  Click **Convert to task**
