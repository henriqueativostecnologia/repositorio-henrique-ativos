# Management dashboard for project templates

The management dashboard for project templates provides a list of all projects created from a project template. Bundles, global fields, and custom project templates will have a dashboard showing the projects that are using the workflow, providing better visibility and tracking of projects instantiated from templates.

#### Related Articles

- [Project template](https://help.asana.com/s/article/project-templates?language=en_US)

 

### Benefits

1.  Gain visibility into all projects created from a specific project template
2.  Easily track and manage projects using the same workflow
3.  Improve data insights and reporting
4.  Streamline project management by understanding template usage

## Accessing the management dashboard

The dashboard can be found in the template gallery by clicking on the **Dashboard** tab. This tab displays a list of all projects that were created from a specific project template.

#### To access the dashboard:

1.  Navigate to your team’s template gallery in Asana as shown [here](https://help.asana.com/s/article/project-templates?language=en_US#gl-creating-project-from-existing)
2.  Click on the **Usage** tab
3.  View the list of projects created from each project template

The dashboard will display relevant information about each project, such as the project name, creation date, and key metrics defined in the template.

## Frequently asked questions

#### Can I customize the information displayed in the dashboard?

Currently, the dashboard displays a predefined set of project details which cannot be customized.

#### Will the dashboard show projects created before this feature was launched?

Yes, the dashboard will include all projects created from a project template, regardless of when they were created.

#### Can I access the dashboard from within a project?

No, the dashboard is only accessible from the template gallery. However, you can easily navigate to the gallery from any project created from a template.
