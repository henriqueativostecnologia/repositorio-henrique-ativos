# Asana: documentação oficial completa

Cópia integral (texto) da Central de Ajuda oficial do Asana, em inglês (versão original e mais completa), baixada em 10/11/2026 de https://help.asana.com (o antigo "Asana Guide", https://asana.com/guide, hoje redireciona para esta central).
Cada arquivo traz no topo o link de origem e a data; logo abaixo do título, em itálico, vem o resumo oficial do artigo quando existe. Imagens e vídeos não foram copiados; os links ficam no texto (vídeos aparecem como "Video: <link>").

**Como foi baixado:** a central é um site Salesforce que só monta a página com JavaScript. A lista de artigos veio do mapa do site público (https://help.asana.com/s/sitemap.xml) somado ao menu de tópicos da central; o texto de cada artigo veio da mesma interface pública que o navegador usa para exibir a página (sem login).

**Como usar:** procure o tema neste índice (Ctrl+F) ou peça ao Claude, que busca dentro dos arquivos. Para atualizar, peça ao Claude para baixar de novo.

Sem resumo, por decisão do Henrique: a fonte é sempre o texto oficial completo.
