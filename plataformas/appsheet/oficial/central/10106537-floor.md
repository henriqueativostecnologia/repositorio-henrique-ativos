# FLOOR()

Round down to nearest integer

Returns the nearest integer rounded down.

## Sample usage

`FLOOR(3.14)` returns `3`

`FLOOR(-3.14)` returns `-4`

`FLOOR(5)` returns `5`

## Syntax

**`FLOOR(`***`x`***`)`**

- *`x`* - Any numeric value.
