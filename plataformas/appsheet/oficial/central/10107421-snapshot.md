# SNAPSHOT()

Take a snapshot of a view

Returns an image (`Image` type) of the specified app view and embeds the image in a [Create a new file](https://support.google.com/appsheet/answer/11512511) or [Send an email](https://support.google.com/appsheet/answer/11447614) task.

## Sample usage

`<<SNAPSHOT(LINKTOVIEW("Map"))>>` creates a link to a view named `Map` in an app and uses the link to generate a screenshot in the document or email.

`<<SNAPSHOT(LINKTOVIEW("Histogram"))>> `creates a link to a view named `Histogram` in an app and uses the link to generate a screenshot in the document or email.

## Syntax

`SNAPSHOT(`*`deep-link)`*

- *`deep-link`* - Any [deep link](https://support.google.com/appsheet/answer/10106757).

## Notes

When adding `SNAPSHOT()` to an email body, you need to wrap it in an `<img>` tab. For example:
`<img src="&lt;&lt;SNAPSHOT(LINKTOVIEW(&quot;Chart&quot;))&gt;&gt;"/>`

When used in an HTML body, [variables must be HTML encoded](https://support.google.com/appsheet/answer/11575774#manually-create).

Per user account, you can snapshot a maximum of 2500 views per day at a rate of 10 per second (to prevent abuse).
