# EXTRACTHASHTAGS()

Extract list of hashtags within a textual value

Returns a list of `Text` values representing the hashtags within the textual value. Each hashtag will include its `#` sign at the front.

## Sample usage

`EXTRACTHASHTAGS("So, like, the new AppSheet EXTRACT formulas? They’re so totally awesome! #extract #appsheet #no-code #WowW #wHoA")`  returns `#extract, #appsheet, #no-code, #WowW, #wHoA` (list of values).

## Syntax

`EXTRACTHASHTAGS(`*`text-to-extract-from`*`)`

- *`text-to-extract-from`* - Any textual value.
