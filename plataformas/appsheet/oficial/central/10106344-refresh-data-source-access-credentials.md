# Refresh data source access credentials

If you have a data source connected to your AppSheet account from any of our [available data sources](https://support.google.com/appsheet/answer/10106309) and you made changes to the data source itself like **changing the password or user**; you'll need to refresh the connection from your AppSheet account as well in order for the apps to continue working.
 
To refresh data source access credentials:

1.  Sign in to [AppSheet](https://www.appsheet.com).
2.  Select your account from the account profile drop-down to go to the **My account** page.

    Access the My account page
     
3.  Select the **Sources** tab.
    You can view all of the data sources that are currently available for your use.
4.  Click the icon of the data source you want to refresh.
    **Note**: If it's a shared data source, the AppSheet account that originally set up the connection must be the one to refresh it.
5.  Step through the authorization flow to refresh your access credentials.
