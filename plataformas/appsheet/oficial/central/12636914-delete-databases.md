# Delete databases

Delete a database using the My Apps page or database editor.

- Before you delete a database, be sure to remove any related tables from existing apps. Otherwise, the apps may no longer execute as expected. See [Access the apps that are using a table](https://support.google.com/appsheet/answer/12728278).
- To delete an AppSheet database, you must be the [owner](https://support.google.com/appsheet/answer/12637319#database-permissions).

## Delete a database using the My Apps page

To delete a database using the My Apps page:

1.  [*Access the My Apps page*](https://support.google.com/appsheet/answer/12392972).
2.  Click **Databases** to view existing databases.
3.  Select **More**  Three-dot menu vertical  \> **Delete** for the database you want to delete.
4.  Confirm the delete operation when prompted.

## Delete a database using the database editor

To delete a database in the database editor:

1.  [Open the database in the database editor](https://support.google.com/appsheet/answer/12632559).
2.  Select **Settings**  Settings icon  **\> Delete database**.
3.  Confirm the delete operation when prompted.
