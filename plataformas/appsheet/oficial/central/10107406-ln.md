# LN()

Natural logarithm of a numeric value

Returns the [natural logarithm](https://en.wikipedia.org/wiki/Natural_logarithm) of *`x`*.

## Sample usage

`LN(3.14)` returns `1.14422279992016`

`LN(10)` returns `2.30258509299404`

## Syntax

`LN(`*`x`*`)`

- *`x`* - Any numeric type.
