# Turn on the AppSheet preview program

To gain access to the features in the AppSheet preview program, do the following:

1.  Open the app in the app editor.
2.  Go to **Settings ** Settings icon ** \> Views: General**
3.  Under **General**, turn on **Preview new features**.
4.  Save the app.

## If you are using the legacy editor

 To gain access to the app features provided in the AppSheet preview program, do the following:

1.  Open the app in the app editor.
2.  Select **UX \> Options**.
3.  Under **General**, turn on **Preview new features**. 
4.  Save the app.
