# USEREMAIL()

User's email address

Returns the email address (`Email` value) of the current signed-in user or blank if the user is not signed in.

## Syntax

`USEREMAIL()`

## Notes

The email address is only available for users that are signed in. See [Require sign-in: The Essentials](https://support.google.com/appsheet/answer/10104975).
