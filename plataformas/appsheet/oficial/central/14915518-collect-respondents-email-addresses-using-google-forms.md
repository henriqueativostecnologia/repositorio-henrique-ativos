# Collect respondents' email addresses using Google Forms

By default, a form built using Google Forms doesn't collect email addresses. This may be suitable for surveys where anonymous feedback is acceptable or preferred.

For scenarios where it is important to know the identity of the user submitting the form, app creators should turn on the collection of email addresses using one of the following form settings. For steps, see [Collect respondents' email addresses](https://support.google.com/docs/answer/139706?hl=en#zippy=%2Ccollect-respondents-email-addresses) in the Google Forms documentation.

+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| **Setting**                                                                   | **Description**                                                               |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| Verified                                                                      | Collect verified email addresses. Users must be signed in to a Google         |
|                                                                               | account.                                                                      |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| Responder input                                                               | Prompt users to manually input their email address in the form.               |
|                                                                               |                                                                               |
|                                                                               | Suitable for users who aren't signed in or don't use a Google account.        |
|                                                                               | However, there is no way to verify the email address that the users enters,   |
|                                                                               | so this is less suitable for an Enterprise environment.                       |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
