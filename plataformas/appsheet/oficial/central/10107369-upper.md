# UPPER()

Convert text to uppercase

Returns the text value with all lowercase letters changed to uppercase.

## Sample usage

`UPPER("AppSheet")` returns `APPSHEET`

## Syntax

`UPPER(`*`text`*`)`

- *`text`* - Any textual type.
