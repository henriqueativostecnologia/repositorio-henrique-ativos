# TEXT_ICON()

Icon from text

Returns an image showing the specified text in a gray square or circle.

## Sample usage

`TEXT_ICON([Name])` returns a `Thumbnail` or `Image` value that can be displayed in your app as follows:

Displays the results of the TEX_ICON() function as a square image.

## Syntax

`TEXT_ICON(`*`text`*`)`

- *`text`* - Any text or expression that you want to return as an image.

## Notes

If this expression and virtual column is set to type `Thumbnail`, only square images are supported in UX views. If set to type `Image`*,* squares and circles are supported.
