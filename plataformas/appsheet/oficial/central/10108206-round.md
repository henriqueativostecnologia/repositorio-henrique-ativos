# ROUND()

Nearest integer

Returns the integer that is nearest to *`x`*.

## Sample usage

`ROUND(3.14)` returns `3`

`ROUND(-3.14)` returns -`3`

`ROUND(98.6)` returns `99`

`ROUND(5)` returns `5`

## Syntax

**`ROUND(`***`x`***`)`**

- *`x`* - Any numeric value.
