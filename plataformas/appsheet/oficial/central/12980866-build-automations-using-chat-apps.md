# Build automations using Chat apps

Build automations using Chat apps to do the following:

- Trigger events based on Chat app interactions. Chat interactions can include interacting with a slash command in a Chat space, or adding or removing a Chat app in a Chat space. See [Events: The Essentials](https://support.google.com/appsheet/answer/11445188).
- Send messages and app views to Chat spaces based on Chat interactions. See [Send a Chat message from an automation](https://support.google.com/appsheet/answer/12981549).

See also:

- [Quick start: Send a Chat message from an automation](https://support.google.com/appsheet/answer/12994240) to get started with Chat messages.
- [Troubleshoot Chat messages](https://support.google.com/appsheet/answer/13265243) for troubleshooting tips

Before you can build automations for your Chat apps, you must [configure your Chat app with AppSheet](https://support.google.com/appsheet/answer/12849362).
