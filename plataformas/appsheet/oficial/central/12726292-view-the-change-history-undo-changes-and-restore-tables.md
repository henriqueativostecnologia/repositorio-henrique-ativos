# View the change history, undo changes, and restore tables

View the change history, undo changes, and restore tables as described in the following sections:

- [View and undo changes for the AppSheet database](#view-change-history-database)
- [View and undo changes for a specific row](#view-change-history-row)
- [Undo or redo the most recent changes](#undo-restore-last-change)
- [Restore a table](#restore-table)

You can view change history, undo changes to rows and columns, and restore tables for up to 30 days. 

## View and undo changes for the AppSheet database

To view and undo changes for the AppSheet database:

1.  [Open the database in the database editor](https://support.google.com/appsheet/answer/12632559).
2.  Do one of the following:
    - Select Settings  Settings icon ** \> View database history**.
    - Select a table tab and click Change history icon  in the edit toolbar. The change history for the selected table is displayed by default.

The Database history page displays.

AppSheet database change history

As highlighted, use the Database history page to:

- Select the table to view or restore in the left navigation
- Filter the history by change type (row changes, deleted rows, or deleted columns)
- View details of each change including:
  - Previous and current setting
  - User that made the change
  - Date and time of the change
- Expand the change details by clicking a row
- Undo a change by clicking  in the row
- [Restore a table](#restore-table)

## View and undo changes for a specific row

To view and undo changes for a specific row:

1.  [Open the database in the database editor](https://support.google.com/appsheet/answer/12632559).
2.  Select a table tab.
3.  Right-click on a row and select Change history icon ** See row history**.
    The Database history displays with data for the selected row.
    Database history for selected row
     
4.  Undo a change by clicking  in the row.

## Undo or redo the most recent changes

To undo or redo the most recent changes, click or   Restore icon  , respectively, in the edit toolbar.

Undo and redo buttons in AppSheet database edit toolbar

## Restore a table

You can view and restore tables for up to 30 days.

Restore a table that had been deleted. You need to restore a deleted table before you can view and undo any changes made to it.

To restore a table:

1.  [View the AppSheet database history](#view-change-history-database).
2.  Select a table under the **Deleted tables** section in the left navigation.
3.  Click **Restore table** in the banner.
4.  Click **Yes** to confirm the operation.

The table is restored and moved out from under the **Deleted Tables** section
