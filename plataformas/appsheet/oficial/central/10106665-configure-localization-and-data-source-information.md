# Configure localization and data source information

Configure [localization](#localization) and the [data source information](#data-source) for your app. See also [Configure table settings](https://support.google.com/appsheet/answer/10105821#configure-table).

## Configure localization for an app

Change your app's locale in the **Localization** section. For more information, see [Locale support in AppSheet](https://support.google.com/appsheet/answer/10106525).

Data locale field in table settings

## Configure data source information for an app

View and configure information about the source of the data used by the table in the **Storage** section. You can view the source path and the worksheet from which your table is generated, as well as the name of the source provider. You can modify these values, as required.
