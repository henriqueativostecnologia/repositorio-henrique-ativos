# Limitations and known issues

The following provides a list of limitations and known issues for the AppSheet Admin Console. 

- The AppSheet Admin Console refreshes usage data on a periodic basis, typically every 24 hours, meaning changes in app ownership, app usage, or account activity might be delayed by a day or later. As a result, the creation of an app or the usage reported in the AppSheet editor might not be immediately available in the AppSheet Admin Console. You can confirm the time the data was last updated in the top left corner of each page in the Admin Console.
- Due to delays with processing app usage details, at certain times the number of users on the [Apps detail page](https://support.google.com/appsheet/answer/15098215) might not match the total number of users shown on the [Apps page](https://support.google.com/appsheet/answer/14961200).
- The [Licenses page](https://support.google.com/appsheet/answer/14960110) reports the number of assigned licenses in the Google Admin Console, but it may take 24 hours or longer for recent changes to be reflected. Note that licenses used are based on the calendar month and will persist for that period, even if the user's license is unassigned in the Google Admin Console.
- The [My Team page](https://support.google.com/appsheet/answer/10104796) contains settings that haven't yet been migrated to the AppSheet Admin Console. In the future all functionality from the My Team page will be migrated to the Admin Console and there will be a single source of truth.
