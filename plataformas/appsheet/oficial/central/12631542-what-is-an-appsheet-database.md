# What is an AppSheet database?

An AppSheet database is a first-party, native data source for organizing and managing data powering AppSheet apps. An AppSheet database provides an easy and efficient way to build data models for any AppSheet app without needing to use an [*external data source*](https://support.google.com/appsheet/topic/10102124) solution such as cloud-based spreadsheets or databases.

Watch this video for an introduction to AppSheet databases.

Video: https://www.youtube.com/watch?v=nwDL7Jnulqw

The benefits of using the built-in AppSheet database include:

- Performance improvements for both app creator and app user as compared to other data sources
- Simple to use AppSheet database editor
- Seamless integration with the AppSheet app editor
- Compatible set of column data types
- No setup or configuration is required

AppSheet database editor showing database used in app editor

AppSheet databases are available for use by default. To disable the use of databases by your team, see [Disable AppSheet databases](https://support.google.com/appsheet/answer/12629371). See also [Restrictions, limits, and known issues](https://support.google.com/appsheet/answer/12653576).
