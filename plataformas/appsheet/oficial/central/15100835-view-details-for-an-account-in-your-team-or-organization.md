# View details for an account in your team or organization

To view details for an AppSheet Enterprise Plus account in your team or organization, [open the Accounts page](https://support.google.com/appsheet/answer/14951131#explore-users-page) and click the user name in the list. In addition, you can click the user name for an AppSheet account in your team or organization anywhere it appears in the Admin Console to view the account details.

**Notes**:

- You must have an AppSheet Enterprise Plus account to view account details.
- You can only view account details for AppSheet Enterprise Plus accounts.

The Account details page opens.

Account details page

The Account details page allows you to do the following:

- [View details for the account](#view-account-details)
- [View details for apps owned by the account](#view-apps-owned)
- [View details for apps used by the account](#view-apps-used)

In addition, you can [transfer ownership of the apps and AppSheet databases for the account](https://support.google.com/appsheet/answer/15098213), if necessary.

At the top of the Account details page, view the following details for the AppSheet account:

|                                                                               | membership](https://support.google.com/appsheet/answer/13964712).             |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| License                                                                       | Subscription license assigned to the AppSheet account. For more information,  |
|                                                                               | see [How to choose a                                                          |
|                                                                               | subscription](https://support.google.com/appsheet/answer/10105400).           |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| Licensing model                                                               | Licensing model used to provision the AppSheet Enterprise Plus license. Can   |
|                                                                               | be one of the following:                                                      |
|                                                                               |                                                                               |
|                                                                               | -   **Assigned licensing** when license is assigned in the Google Admin       |
|                                                                               |     console                                                                   |
|                                                                               | -   **Pooled licensing** when license is granted to users in a group or       |
|                                                                               |     organization when they sign in to AppSheet                                |
|                                                                               | -   **Team licensing** (legacy) when access is by customer's verified domain  |
|                                                                               |                                                                               |
|                                                                               | See [How AppSheet Enterprise Plus licenses are                                |
|                                                                               | provisioned](https://support.google.com/appsheet/answer/14101111).            |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| Auth provider                                                                 | Provider used to authenticate AppSheet sign-ins. See [Require sign-in: The    |
|                                                                               | Essentials](https://support.google.com/appsheet/answer/10104975).             |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| Last active                                                                   | Date of last sign-in to app or app editor by AppSheet account.                |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+

## View details for apps owned by the account

Under **Apps**, click **Owned** to view the following details for apps owned by the account:

+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| **App detail**                                                                | **Description**                                                               |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| App name                                                                      | App name.                                                                     |
|                                                                               |                                                                               |
|                                                                               | Click the app name to [view details for the                                   |
|                                                                               | app](https://support.google.com/appsheet/answer/14961200#view-app-details).   |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| Users                                                                         | Number of users, both internal and external to your team or organization,     |
|                                                                               | that have accessed the app in the last 30 days.                               |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| Status                                                                        | Series of icons that indicate the status of the app, including one or more of |
|                                                                               | the following:\                                                               |
|                                                                               | green check mark  - App is runnable                                           |
|                                                                               |                                                                               |
|                                                                               |  - App is not runnable                                                        |
|                                                                               |                                                                               |
|                                                                               |  - App is prototype                                                           |
|                                                                               |                                                                               |
|                                                                               | Status icon indicating app is deployed - App is deployed                      |
|                                                                               |                                                                               |
|                                                                               | Status icon indicating app is secure  - App is secure ([requires              |
|                                                                               | sign-in](https://support.google.com/appsheet/answer/10104975))                |
|                                                                               |                                                                               |
|                                                                               | Status icon indicating app is not secure  - App is not secure (doesn't        |
|                                                                               | require sign-in)                                                              |
|                                                                               |                                                                               |
|                                                                               |  - App is marked for personal use                                             |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| Last modified                                                                 | Date the app was last modified by app owner (this account) or co-author.      |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+

 

## View details for apps used by the account

Under **Apps**, click **Used** to view the following details for apps used by the account: 

+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| **App detail**                                                                | **Description**                                                               |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| App name                                                                      | App name.                                                                     |
|                                                                               |                                                                               |
|                                                                               | For apps owned by a member of your team or organization, you can click the    |
|                                                                               | app name to [view details for the                                             |
|                                                                               | app](https://support.google.com/appsheet/answer/14961200#view-app-details).   |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| App owner                                                                     | Owner of the app.                                                             |
|                                                                               |                                                                               |
|                                                                               | For app owners that are in your team or organization, you can click app owner |
|                                                                               | name to [view the details for the                                             |
|                                                                               | account](https://support.google.com/appsheet/answer/15100835).                |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| Auth provider                                                                 | Provider used to authenticate AppSheet sign-ins. See [Require sign-in: The    |
|                                                                               | Essentials](https://support.google.com/appsheet/answer/10104975).             |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| App type                                                                      | Type of app. Can be one of the following:                                     |
|                                                                               |                                                                               |
|                                                                               | -   **Internal** when the app belongs to the team or organization             |
|                                                                               | -   **External app** when a member of your team or organization uses an app   |
|                                                                               |     that doesn't belong to the team or organization                           |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| License required                                                              | Minimum license required to use the app based on                              |
|                                                                               | its [features](https://support.google.com/appsheet/answer/10105400#features). |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| Last access                                                                   | Date that this account last accessed the app.                                 |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
