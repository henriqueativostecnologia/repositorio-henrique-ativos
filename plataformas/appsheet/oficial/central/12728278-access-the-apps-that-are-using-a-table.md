# Access the apps that are using a table

To access the apps that are using a table:

1.  [Open the database in the database editor](https://support.google.com/appsheet/answer/12632559).
2.  Select the table tab.
3.  Click **Apps** in the tool panel.
    Any apps that are using the table are displayed. For example:

4.  For an existing app:
    - Click **AppSheet** to open it in the [*AppSheet app editor*](https://support.google.com/appsheet/answer/12290157)
    - Click **Preview** to preview the app in a desktop browser
5.  To create a new app, click **New AppSheet app**. 
    A new app is created using the selected table and opened in the app editor. See [*Explore the AppSheet app editor*](https://support.google.com/appsheet/answer/12290157). By default, the app is named: *tablename* App 

See also: [*Use databases in your app*](https://support.google.com/appsheet/answer/12631543)
