# Display referenced records

AppSheet displays [references](https://support.google.com/appsheet/answer/10106510) and reverse references as reference icons. When you click a reference icon, AppSheet displays the referenced record.

For example, the following Orders view provides a view of an `Orders` table grouped by `Customer`.

Orders view grouped by customer

Clicking the reference icon to the right of an Order displays the order details.

Order details

You can customize how referenced records are displayed. For example, you may want to see a chart, map, or other view. To do so:

1.  [Configure the view](https://support.google.com/appsheet/answer/10106688#configure-view) to display data in the format you wish.
2.  Set the **Position** setting to **ref**.

For example, the following Product Catalog sample shows multiple views, one as an image gallery and one as a chart.
