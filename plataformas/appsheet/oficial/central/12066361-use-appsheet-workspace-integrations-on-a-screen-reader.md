# Use AppSheet Workspace integrations on a screen reader

AppSheet Workspace Integrations (such as inside Sheets and Drive) are expected to have screen reader support.

### Accessibility functionality

Images should have descriptive text, the ability to use keyboard shortcuts similar to a standard website, and sufficiently descriptive text.

To move around, press **Tab** to select the different menu buttons and text and **Enter** to activate the button. In addition, you should be familiar with [how to edit spreadsheets with a screen reader](https://support.google.com/docs/answer/1632199) in order to prepare your sheet for use within AppSheet.

### How to set up a screen reader

See [Accessibility for Docs Editors](https://support.google.com/docs/answer/6282736).

### Reporting issues

If you think there is a bug related to accessibility, such as insufficiently descriptive text, report it to [AppSheet Support](https://www.appsheet.com/support/contact) and mention it as an Accessibility issue.
