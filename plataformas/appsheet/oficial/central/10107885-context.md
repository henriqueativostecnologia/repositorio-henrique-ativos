# CONTEXT()

Information about the running app

Returns contextual information about the running app based on the keyword option specified.

## Get started

Watch this video to get started using `CONTEXT()`.

Video: https://www.youtube.com/watch?v=rVw3LM-Fvoc

## Sample usage

`IN(CONTEXT("View"), LIST("Orders_Detail", "Orders_Form"))` returns a `Yes/No` value that answers the question, is the currently-displayed view named `Orders_Detail` or `Orders_Form`? This might be used in a [Show_If](https://support.google.com/appsheet/answer/10106628) [column constraint](https://support.google.com/appsheet/answer/10107681) to display a column only in specific views but hide it elsewhere. See also: [`IN()`](https://support.google.com/appsheet/answer/10107681), [`LIST()`](https://support.google.com/appsheet/answer/10107339)

`SWITCH(CONTEXT("Host"), "Device", "Tap below to:", "Browser", "Click below to:", "")` returns different directions depending on whether the app is running from the native app on a device or from a browser. This might be used to generate a display name for a gallery view of launchers. See also: [`SWITCH()`](https://support.google.com/appsheet/answer/10107700)

`CONTEXT("VIEWTYPE")="Detail"` returns `Yes` if the current view is of type Detail.

## Syntax

`CONTEXT(`*`option`*`)`

- *`option`* - Must be set to one of the keywords described in the following table.

The following table lists the keywords and their return values. 

**Note**: If an invalid option is provided, a null value is returned.

+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| **Keyword**                                                                   | **Return value**                                                              |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| `AppName`                                                                     | Unique name of the app, including account ID, as used in app URLs. For        |
|                                                                               | example, `MyApp-123456`.                                                      |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| `Device`                                                                      | [Universally unique identifier                                                |
|                                                                               | (UUID)](https://en.wikipedia.org/wiki/Universally_unique_identifier) of the   |
|                                                                               | device, intended to identify the mobile device running the native app. Used   |
|                                                                               | from a browser, the UUID is tied to the browser's local storage, not the      |
|                                                                               | device itself, and may change if the browser's cache is cleared. In the       |
|                                                                               | emulator of the app editor, the text `expression-assistant-device-id` is      |
|                                                                               | returned.                                                                     |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| `Host`                                                                        | Returns one of the following values:                                          |
|                                                                               |                                                                               |
|                                                                               | -   `Server` when the expression is evaluated remotely on the server. Remote  |
|                                                                               |     evaluation would include things like                                      |
|                                                                               |     [automation](https://support.google.com/appsheet/answer/11998993),        |
|                                                                               |     [security filters](https://support.google.com/appsheet/answer/10104488),  |
|                                                                               |     or [virtual columns](https://support.google.com/appsheet/answer/10106758) |
|                                                                               |     computed during sync.                                                     |
|                                                                               | -   `Browser` when the expression is evaluated locally within the app running |
|                                                                               |     in a web browser or the [app                                              |
|                                                                               |     preview](https://support.google.com/appsheet/answer/13684531) in the      |
|                                                                               |     editor                                                                    |
|                                                                               | -   `Device` when the expression is evaluated locally within the Android or   |
|                                                                               |     iOS AppSheet apps or [branded                                             |
|                                                                               |     apps](https://support.google.com/appsheet/answer/10105390).               |
|                                                                               |                                                                               |
|                                                                               | Local evaluation would include things like [column                            |
|                                                                               | constraints](https://support.google.com/appsheet/answer/10107948), [slice     |
|                                                                               | filters](https://support.google.com/appsheet/answer/10106308), and [virtual   |
|                                                                               | columns](https://support.google.com/appsheet/answer/10106758) updated during  |
|                                                                               | editing.                                                                      |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| `OwnerEmail`                                                                  | Email of the app owner.                                                       |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| `Table`                                                                       | Name of the table used by the current view.                                   |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| `View`                                                                        | Name of the [view](https://support.google.com/appsheet/answer/10106688)       |
|                                                                               | currently displayed to the user, or blank if no view is currently displayed   |
|                                                                               | (for example, in an automation)                                               |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| `ViewType`                                                                    | Type of the [view](https://support.google.com/appsheet/answer/10106688)       |
|                                                                               | currently displayed to the user, or blank if no view is currently displayed   |
|                                                                               | (for example, in an automation). For a list of valid view types, see [View    |
|                                                                               | types](https://support.google.com/appsheet/answer/10106772).                  |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+

## Notes

The `View` and `ViewType` options are:

- Not supported for [Chat apps](https://support.google.com/appsheet/answer/12860535) or [embedded app view emails](https://support.google.com/appsheet/answer/11511240) (dynamic emails).
- May not work as expected if used in [a virtual column's App formula expression](https://support.google.com/appsheet/answer/10106758). Except when editing a row (for example, in a form or with an action) and other limited circumstances, virtual column values are computed by the AppSheet server during a [sync](https://support.google.com/appsheet/answer/10108301).

In each case, the server is unaware of the view currently visible to the user, so cannot provide the view name or type.
