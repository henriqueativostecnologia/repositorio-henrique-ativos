# Allow app access as needed with AppSheet User Pass

AppSheet User Pass allows users of your AppSheet Enterprise Plus or Core apps to consume a license, as needed, if they don't have one or if their license is a lower tier than the app owner. User Pass licenses are available to the organization as a pool. Admins don't assign User Pass licenses to individual users in the Google Admin console. 

Example scenarios for when you might want to purchase User Pass licenses:

- You have a Core entitlement through your Workspace license and want to share apps with an external supplier
- You build an app for a specific use case and give front-line workers access to use the app (but not edit or build other apps)
- You have Enterprise Plus licenses for a few app creators and they need to share an Enterprise Plus app with Core entitled users

Learn more about User Pass licenses in the following sections:

- [How User Pass licenses are consumed](#how-consumed)
- [Purchase and manage User Pass licenses](#purchase-manage)

Admins shouldn't expect User Pass license users to be subject to [governance policies](https://support.google.com/appsheet/answer/11948767) or [team settings](https://support.google.com/appsheet/answer/11918568).

## How User Pass licenses are consumed

User Pass licenses are consumed when an eligible user accesses a unique app. That app user has unlimited access to the app for the month.

An eligible user can be one of the following:

- **External users**: Users external to your Google Workspace organization
- **Unauthenticated users**: Users that don't sign in to the app
- **Under-licensed users**: Users with a lower license tier than the app creator,  such as an AppSheet Core user that accesses an AppSheet Enterprise Plus app

App users can consume multiple User Pass licenses as needed. For example, if they access more than one app.

## Purchase and manage User Pass licenses

To purchase User Pass licenses, see [Purchase a subscription](https://support.google.com/appsheet/answer/15011908). The pool of User Pass licenses resets at the end of the calendar month; unused licenses aren't rolled over. You can [view User Pass license consumption](https://support.google.com/appsheet/answer/14960110) in the AppSheet Admin Console. 

When the number of consumed User Pass licenses nears the number of purchased licenses, you can [purchase more licenses](https://support.google.com/a/answer/33387). The additional licenses are added to your monthly payment plan with a minimum of 1-year commitment. 

When you purchase more licenses: 

- User Pass licenses are consumed one user at a time
- Your monthly charges will be based on the number of User Pass licenses you've purchased
- If you purchase additional User Pass licenses in the middle of the month, you will be charged on a prorated basis
