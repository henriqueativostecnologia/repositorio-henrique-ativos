# Edit the name and description of a database

The AppSheet database name and description are used for informational purposes only; they do not appear in the app.

To edit the name and description of an AppSheet database:

1.  [Open the database in the database editor](https://support.google.com/appsheet/answer/12632559).
2.  To edit the database name, click in the name and edit the contents. 
3.  To edit the database description:
    1.  Select **Settings**  Settings icon **\> Edit database description **adjacent to its name.
    2.  Edit the description.
    3.  Click **OK**.
