# LATLONG()

LatLong from components

Returns a `LatLong` value composed of latitude and longitude.

## Syntax

`LATLONG(`*`latitude`*`, `*`longitude`*`)`

- *`latitude`* - Any numeric type.
- *`longitude`* - Any numeric type.
