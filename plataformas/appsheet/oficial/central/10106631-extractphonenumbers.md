# EXTRACTPHONENUMBERS()

Extract list of phone numbers within a textual value

Returns a list of phone numbers (`Phone` values) within the textual value.

## Sample usage

`EXTRACTPHONENUMBERS("Call Jenny, 555-867-5309!")` returns `555-867-5309` (list of one item).

## Syntax

`EXTRACTPHONENUMBERS(`*`text-to-extract-from`*`)`

- *`text-to-extract-from`* - Any textual value.
