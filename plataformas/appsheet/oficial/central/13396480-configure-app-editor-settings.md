# Configure app editor settings

Configure the app editor settings to customize the default behavior.

To configure app editor settings:

1.  Select **Editor settings** from the account profile drop-down.

    Editor settings in account drop-down

    For more information about the My Apps page, see [Explore the My Apps page](https://support.google.com/appsheet/answer/12392972).

    ## If you are using the legacy editor

    Select **Manage \> Author \> Editor Settings**.

2.  Configure the settings for the app editor as summarized in the following table.

|                                                                               | or](https://support.google.com/appsheet/answer/12490168#switch-legacy-editor) |
|                                                                               | only. This setting has no impact when using the [improved app                 |
|                                                                               | editor](https://support.google.com/appsheet/answer/12490168);                 |
