# Set up email auto-completion for Email columns

Set up email auto-completion for `Email` columns in your app.

Email auto-completion is only available to Google Workspace users in the same Google Workspace organization as the app owner. 

The following figure shows the app user experience for an Email column that supports email auto-completion.

Email auto-completion

To set up email auto-completion:

1.  As a Google Workspace administrator:
    - Turn on Google Directory and check the **Enable contact sharing **box, as described in [Turn Directory on or off](https://support.google.com/a/answer/60218).
    - Make sure that all Workspace users have access to it.
2.  As an app creator:
    - Set `Email` as the Column type.
    - Make sure you are the owner of the app. If the app is shared with you by someone that is not in the same Google Workspace organization, email auto-completion will not be available.
