# About external user licensing

As of **April 10, 2025**, **AppSheet Enterprise Standard External User** and **AppSheet Enterprise Plus External User** licenses are no longer available for purchase. We’ve automatically upgraded your customer’s existing external user licenses to AppSheet Enterprise Plus at no additional cost for the remaining duration of your commitment. Going forward, you can [allow app access with AppSheet User Pass](https://support.google.com/appsheet/answer/15657053).

The [Licenses page](https://support.google.com/appsheet/answer/14960110#access-licenses-page) in the AppSheet Admin console lists the number of AppSheet licenses purchased, assigned, and used, and the app users to which licenses are assigned, by subscription.

All AppSheet app users require a license including users that are outside of your Google Workspace organization, both authenticated and unauthenticated. Specifically, app users require one of the following:

- The same license as the app owner
- An external user license

If you purchased **AppSheet Enterprise Standard External User**, your licenses have been upgraded to **AppSheet Enterprise Plus External User** automatically. Any external users will automatically consume the external user licenses that you have purchased.
