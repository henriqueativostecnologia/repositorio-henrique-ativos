# Display column headers in table views

To display column names in a table view in your app, when [configuring table view settings](https://support.google.com/appsheet/answer/10107387#table-view) turn on **Show column headers**. When turned on, your column widths will be expanded to accommodate the column name.

The **Show column headers** option is ignored for the following column types:

- `Address`
- `ChangeLocation`
- `Color`
- `Email`
- `File`
- `LatLong`
- `Phone`
- `Progress`
- `URL`
- `Yes/No`
