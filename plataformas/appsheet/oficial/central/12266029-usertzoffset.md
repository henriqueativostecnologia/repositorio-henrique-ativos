# USERTZOFFSET()

User's local time offset from UTC

Returns the number of minutes the user’s local time is offset from UTC.

## Sample usage

If `USERTZOFFSET()` returns:

- `-540`: Local time is 9 hours ahead of UTC
- `60`: Local time is 1 hour behind UTC

## Syntax

`USERTZOFFSET()`
