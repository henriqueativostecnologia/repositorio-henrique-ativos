# CEILING()

Round up to the nearest integer

Returns the nearest integer rounded up.

## Sample usage

`CEILING(3.14)` returns `4`

`CEILING(-3.14)` returns `-3`

`CEILING(5)` returns `5`

## Syntax

**`CEILING(`***`x`***`)`**

- *`x`* - Any numeric value.
