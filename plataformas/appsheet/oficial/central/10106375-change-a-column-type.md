# Change a column type

The column type impacts how AppSheet handles your data.

Based on your data, AppSheet configures a default type. You can customize the column type in the **Data \> Column** pane of the editor. For instance, if you have a column called **Name** of type `Text`, you can change it to be a `Name` column type.

1.  Open the app in the editor.

2.  Go to **Data**  and select the table you want to edit in the list.
    We've made some [improvements to the app editor](https://support.google.com/appsheet/answer/12490168).
    You are **opted in** **to the new editor** by default, but you can [switch back to the legacy editor](https://support.google.com/appsheet/answer/12490168) at any time.

     
    ## If you are using the legacy editor

    Go to **Data \> Columns** and expand the table you want to edit.

3.  Locate your **Column Name** and the corresponding **Column Type** you would like to change. In this example, for the **Name** column, **Type** was changed from **Text** to **Name**.

    Select Name in the Type drop-down for the Name column

4.  Save the app by selecting one of the following:

    - **Save** - Save the app.
    - **Save & verify data** - Save the app and verify that it is runnable based on external dependencies.
