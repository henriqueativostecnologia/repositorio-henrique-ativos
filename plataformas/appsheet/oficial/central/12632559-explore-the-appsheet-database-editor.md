# Explore the AppSheet database editor

Use the AppSheet database editor to edit and manage your AppSheet databases. 

To open a database in the database editor:

- Go to the **My Apps** page and [*create a database*](https://support.google.com/appsheet/answer/12635312).
- Go to the **My Apps** page, click **Databases** to view the list, then do **one** of the following:
  - Click a row to open the database in the current tab
  - Select **More**  **\> Edit in new tab** to open the database in a new tab
- Open an app that uses the database in the app editor, go to **Data** , select the table you want to view or edit in the list, and click **View data source**.
  We've made some [improvements to the app editor](https://support.google.com/appsheet/answer/12490168).
  You are **opted in** **to the new editor** by default, but you can [switch back to the legacy editor](https://support.google.com/appsheet/answer/12490168) at any time.

   
  ## If you are using the legacy editor

  Open an app that uses the database in the app editor, go to **Data \> Tables**, expand the database table, and click **Edit**.

As highlighted, use the database editor to perform the following tasks:

- Manage the database:
  - [Edit the name and description](https://support.google.com/appsheet/answer/12633164)
  - [Copy the database](https://support.google.com/appsheet/answer/12635312#copy-existing-database)
  - [Change the owner of the database](https://support.google.com/appsheet/answer/12637822)
  - [Delete the database](https://support.google.com/appsheet/answer/12636914)
- [Manage the tables in the database](https://support.google.com/appsheet/answer/12725680)
- Manage [columns](https://support.google.com/appsheet/answer/12726090) and [rows](https://support.google.com/appsheet/answer/12726386) in a table
- [Add a comment to a row](https://support.google.com/appsheet/answer/12726386#add-comment)
- [Access the apps that are using the table](https://support.google.com/appsheet/answer/12728278)
- [View the change history, undo changes, and restore tables](https://support.google.com/appsheet/answer/12726292), or undo and redo most recent edits
- [Configure and save the view configuration](https://support.google.com/appsheet/answer/12726685)
- [Share the database](https://support.google.com/appsheet/answer/12637319)
- Search the current table
