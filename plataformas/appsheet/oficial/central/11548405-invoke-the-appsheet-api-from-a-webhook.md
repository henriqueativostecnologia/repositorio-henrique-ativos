# Invoke the AppSheet API from a webhook

To invoke the AppSheet API from a webhook, when configuring the **Call a webhook** task set the **Preset** property to **AppSheet API**. Then configure the additional properties that are displayed based on your selection. For more information, see [Call a webhook from a bot](https://support.google.com/appsheet/answer/11511244).
