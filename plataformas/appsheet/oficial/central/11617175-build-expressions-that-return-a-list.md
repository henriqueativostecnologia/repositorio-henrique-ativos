# Build expressions that return a list

The following expressions return lists as their result:

- [`EXTRACT()`](https://support.google.com/appsheet/answer/10107889) - List of recognizable elements from textual value.
- [`EXTRACTDATES()`](https://support.google.com/appsheet/answer/10107402)` `- List of dates from textual value.
- [`EXTRACTDATETIMES()`](https://support.google.com/appsheet/answer/10108193) - List of date-times from textual value.
- [`EXTRACTDURATIONS()`](https://support.google.com/appsheet/answer/10107333) - List of durations from textual value.
- [`EXTRACTEMAILS()`](https://support.google.com/appsheet/answer/10107403) - List of email addresses from textual value.
- [`EXTRACTHASHTAGS()`](https://support.google.com/appsheet/answer/10107890) - List of hashtags from textual value.
- [`EXTRACTMENTIONS()`](https://support.google.com/appsheet/answer/10108195) - List of mentions from textual value.
- [`EXTRACTNUMBERS()`](https://support.google.com/appsheet/answer/10107677) - List of numeric values from textual value.
- [`EXTRACTPHONENUMBERS()`](https://support.google.com/appsheet/answer/10106631) - List of phone numbers from textual value.
- [`EXTRACTPRICES()`](https://support.google.com/appsheet/answer/10107891) - List of prices from textual value.
- [`EXTRACTTIMES()`](https://support.google.com/appsheet/answer/10107404) - List of times from textual value.
- [`FILTER()`](https://support.google.com/appsheet/answer/10108196) - List of select rows in table.
- [`INTERSECT()`](https://support.google.com/appsheet/answer/10107963) - List of items common to two lists.
- [`LIST()`](https://support.google.com/appsheet/answer/10107339) - New list of values.
- [`ORDERBY()`](https://support.google.com/appsheet/answer/10107362) - List of rows in custom order.
- [`REF_ROWS()`](https://support.google.com/appsheet/answer/10107364) - List of rows referencing this row.
- [`SELECT()`](https://support.google.com/appsheet/answer/10108207) - List of column values from select rows.
- [`SORT()`](https://support.google.com/appsheet/answer/10107698) - List of items in order.
- [`SPLIT()`](https://support.google.com/appsheet/answer/10107984) - List of elements from textual value.
- [`TOP()`](https://support.google.com/appsheet/answer/10107704) - List of initial items of list.
- [`UNIQUE()`](https://support.google.com/appsheet/answer/10107368) - List of items with duplicates removed.
