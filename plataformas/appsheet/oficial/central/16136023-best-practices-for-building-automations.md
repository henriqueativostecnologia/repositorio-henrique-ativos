# Best practices for building automations

Consider the following best practices when building automations.

- [Manage updates to row data by multiple bots](#update-row-data-multiple-bots)

See also [Best practices for using AI in automations](https://support.google.com/appsheet/answer/16052759).

## Manage updates to row data by multiple bots

When multiple bots update the same row in a data source, to avoid conflicts make sure that the bots run synchronously. Simultaneous updates to the same row in a data source might cause unexpected results.
