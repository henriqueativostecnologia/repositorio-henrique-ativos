# View types

AppSheet apps support the following view types.

|                                                                   |                                                                                                         |
|-------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------|
| **View Type**                                                     | **Description**                                                                                         |
| [Calendar](https://support.google.com/appsheet/answer/10106383)   | Displays data associated with dates and times in day, week, or month formats.                           |
| [Card](https://support.google.com/appsheet/answer/11908538)       | Displays content and actions in a single element.                                                       |
| [Chart](https://support.google.com/appsheet/answer/10107847)      | Displays data in a visual format (using histograms, donut charts, and so on).                           |
| [Dashboard](https://support.google.com/appsheet/answer/10106384)  | Shows multiple views in one place.                                                                      |
| [Deck](https://support.google.com/appsheet/answer/10106514)       | Shows information about each row in a "deck-of-cards" format including an image. Similar to table view. |
| [Detail](https://support.google.com/appsheet/answer/10106385)     | Shows details for a single record and provides navigation to access next and previous records.          |
| [Form](https://support.google.com/appsheet/answer/10107846)       | Captures information input by app users.                                                                |
| [Gallery](https://support.google.com/appsheet/answer/10106770)    | Showcases your data images.                                                                             |
| [Map](https://support.google.com/appsheet/answer/10106601)        | Displays addresses, XY, and LatLong columns on a map.                                                   |
| [Onboarding](https://support.google.com/appsheet/answer/11911809) | Provides a set of introductory pages for onboarding users.                                              |
| [Table](https://support.google.com/appsheet/answer/10106514)      | Summarizes data as a scrollable list of rows. Similar to deck view.                                     |
