# Configure app settings

Configure the settings for your app as summarized in the following table.

|               |                                                                                                                                                                                          |
|---------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Settings**  | **Description**                                                                                                                                                                          |
| Information   | Customize the information for app users and set app properties. See [Customize the About page](https://support.google.com/appsheet/answer/10106613).                                     |
| Theme & brand | Style your app by configuring the theme and brand, and font style and size. See [Style: The Essentials](https://support.google.com/appsheet/answer/10106612).                            |
| Data          | [View data relationships using Spec](https://support.google.com/appsheet/answer/12007354) and [configure data processing settings](https://support.google.com/appsheet/answer/11510515). |
| Views         | Configure general, view type, and localization settings. See [View settings: The Essentials](https://support.google.com/appsheet/answer/10107387).                                       |
| Performance   | Configure settings to improve sync performance. See [Offline and sync: The Essentials](https://support.google.com/appsheet/answer/10107724).                                             |
| Offline mode  | Configure settings to improve offline use. See [Offline and sync: The Essentials](https://support.google.com/appsheet/answer/10107724).                                                  |
| Integrations  | Configure settings for external AppSheet integrations. See [Integrate AppSheet with external services](https://support.google.com/appsheet/answer/10104999).                             |
