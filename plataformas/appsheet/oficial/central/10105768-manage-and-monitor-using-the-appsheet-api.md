# Manage and monitor using the AppSheet API

**Note**: This feature is supported for Enterprise plans only.

Manage and monitor using the AppSheet API:

- Manage table records, as follows:
  - [Add](https://support.google.com/appsheet/answer/10104797) table records
  - [Delete](https://support.google.com/appsheet/answer/10105399) table records
  - [Read](https://support.google.com/appsheet/answer/10105770) a table record
  - [Update](https://support.google.com/appsheet/answer/10105002) table records
- [Invoke an action](https://support.google.com/appsheet/answer/10104497) that you defined in AppSheet (limited to certain action types)
- [Monitor your team](https://support.google.com/appsheet/answer/11579594)
