# DOMAINOF()

Extract domain from an email address

Extract the domain from the specified email address.

## Sample usage

`DOMAINOF("abc@appsheet.com")` returns appsheet.com.

## Syntax

`DOMAINOF(`*`email`*`)`

- *`email`* - Email address (textual value) from which to extract the domain.
