# LOWER()

Convert text to lowercase.

Returns the provided text with all uppercase letters changed to lowercase.

## Sample usage

`LOWER("AppSheet")` returns `appsheet`

`LOWER("IBM")` returns `ibm`

## Syntax

`LOWER(`*`text`*`)`

- *`text`*` `- Any textual type.
