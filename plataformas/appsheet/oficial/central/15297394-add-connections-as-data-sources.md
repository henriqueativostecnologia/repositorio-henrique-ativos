# Add connections as data sources

This is a **preview release** of Integration Connectors with AppSheet. See [Track and manage feature releases](https://support.google.com/a/topic/1227580). Preview offerings are intended for use in test environments only. This feature is not recommended for use in production apps. For questions or assistance with this feature, contact [AppSheet Support](https://www.appsheet.com/Support/Contact).

Integration Connectors with AppSheet (preview) requires an **AppSheet Enterprise Plus** account.

Before you can add connections as data sources, the Google Cloud and AppSheet team admins need to [Set up Integration Connectors with AppSheet](https://support.google.com/appsheet/answer/16178778) for your AppSheet team. 

As a team admin, to add a connection as a data source do the following:

1.  Go to the **My account \> Sources** and click **+ New Data Source**.
2.  Select the **Use Integration Connectors** tab.
    **Note**: If you see the Get started page, you need to [set up your team to use Integration Connectors](#set-up-team).
3.  Enter the **Google Cloud project ID** that has the connection created by the Google Cloud admin that you want to use as a data source and click **Find**.
    The list of available connections is displayed.
4.  Select the connection and click **Add connection**.
    The connection is added as a data source.
5.  Optionally, you can [share the data source with your team](https://support.google.com/appsheet/answer/10104795#share-data-sources).

Enter the Google project ID, select the connection, and click Add connection
