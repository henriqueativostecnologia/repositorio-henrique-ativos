# Slice actions

When [configuring a slice](https://support.google.com/appsheet/answer/10106592#configure-slice), you choose which actions to include using the **Slice Actions** field, shown below. By default, it's set to Auto assign.

Slice Actions field showing custom action selections

 To modify the actions included in the slice, do one or more of the following:

- To add an action, click **Add **and select the action from the drop-down. Select **Auto assign** to let AppSheet select the slice actions.
- To reorder an action, click  alongside the action and drag it to the desired position.
- To delete an action, click  alongside the action.
