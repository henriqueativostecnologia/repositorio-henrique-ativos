# Use databases in your app

Use AppSheet databases in your app by doing one of the following:

- [Create an app from an existing database](#create-app-from-database)
- [Create an app from an existing table](#create-app-from-table)
- [Add an existing database to an app](#add-database-to-app)
- [Add a new table to an existing app](#add-new-table-to-app)

## Create an app from an existing database

To create a new app from an existing database:

1.  [*Access the My Apps page*](https://support.google.com/appsheet/answer/12392972).
2.  Click **Create \> App \> Start with existing data**.
3.  Enter an app name and select a category.
4.  Click **Choose your data**.
5.  Select **AppSheet database**.
6.  Select the database you want to use to create the app.
7.  Select the tables you want to add to the app or click **Select All**.
8.  Select the data changes allowed by users of the app for each table.

A new app is created using the selected tables from the existing database and opened in the app editor. See [*Explore the AppSheet app editor*](https://support.google.com/appsheet/answer/12290157).

## Create an app from an existing table

To create a new app from an existing table:

1.  [Open the database in the database editor](https://support.google.com/appsheet/answer/12632559).
2.  Click the table tab.
3.  Click **Apps** in the tool panel.
4.  Click **New AppSheet app**.

A new app is created using the selected table and opened in the app editor. See [*Explore the AppSheet app editor*](https://support.google.com/appsheet/answer/12290157). By default, the app is named: *tablename* App 

## Add an existing database to an app

To add an existing database to an app:

1.  Open the app in the app editor.
2.  Go to **Data \> Tables**.
3.  Click **+ New Table**.
    The Add data dialog displays.
4.  Select **AppSheet database**.
5.  Select the database that contains the tables you want to add.
6.  Select the tables you want to add to the app or click **Select All**.
7.  Select the data changes allowed by users of the app for each table. 
8.  Click **Add to app**.

The selected tables from the database are added to the app.

## Add a new table to an app

To add a new table to an app:

1.  Open the app in the app editor.
2.  Go to **Data \> Tables**.
3.  Click **+ New Table**.
4.  Select **AppSheet database**.
5.  Do one of the following:
    - Click **+ Create new database**, enter a name for the database and table, and click **Create database and table**.
    - Select the database, click **+ Create new table**, enter a name for the table, and click **Create table**.
6.  To open the database, click **Open in database editor** or close the dialog.

The AppSheet database is created and the table is added to the app.
