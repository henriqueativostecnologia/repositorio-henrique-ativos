# LINKTOPARENTVIEW()

Constructed deep link to parent view

Returns a [deep link](https://support.google.com/appsheet/answer/10106757) (`App` value) to the parent view. App users can click the link to return to the parent view (the same view the AppSheet back button would navigate you to).

`LINKTOPARENTVIEW()` is particularly useful in grouped actions.

## **Syntax**

`LINKTOPARENTVIEW()`
