# Control row sort order in a view

You can control the order in which a view's rows are displayed, except for Map and Chart views.

For an example, see the [How to sort](https://www.appsheet.com/templates/This-app-shows-how-to-sort-your-data-by-a-column?appGuidString=93d9f59e-80ce-4ff6-8344-08e81f8435ab) template.

To control sort order:

1.  Open the app in the editor.
2.  Go to **App** App icon ** \> Views** and click the view you want to edit in the View panel.
     We've made some [improvements to the app editor](https://support.google.com/appsheet/answer/12490168).
    You are **opted in** **to the new editor** by default, but you can [switch back to the legacy editor](https://support.google.com/appsheet/answer/12490168) at any time.

    ## If you are using the legacy editor

    Go to **UX \> Views** and expand the view you want to edit.
3.  In the **Sort by** field, click **Add** to add a column to sort by.
4.  Select **Ascending** (that is, AAA is shown before ZZZ) or **Descending** (that is, ZZZ is shown before AAA) order.
5.  Repeat to add additional columns to sort by.
6.  Save the app.
