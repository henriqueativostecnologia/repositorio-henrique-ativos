# Use buttons in your Drive toolbar

On your computer, when you select a Drive file or folder, buttons in the upper left corner allow you to take actions. If screen dimensions permit, a similar set of buttons emerge when you hover over a file or folder in list layout.

**Example:** You can use buttons to share or rename a file.

## Learn what button icons & symbols mean

- : Share the file or folder
- : Download the file or folder
- : Rename the file or folder
- Star : Add the file or folder to the “Starred” folder
- : Move a file to a different folder
- : Remove a file or folder
- : Find additional menu actions

**Tip:** To complete actions on multiple files or folders: 

1.  Click a file or folder you want to select.
2.  Press and hold **Command** (Mac) or **Ctrl** (Windows)  and then click on other files or folders you'd like to select
3.  Release **Command** (Mac) or **Ctrl** (Windows)** ** and then click a button from the toolbar.
