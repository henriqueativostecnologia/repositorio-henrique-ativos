# Learn about system requirements & browsers

This article has different instructions for each platform/version: Computer, Android phone & tablet, iPhone & iPad. All versions are copied below.

## Version: Computer

You can use Google Docs, Sheets, Slides, Vids, Forms, and Pics with a compatible browser and operating system.

### Learn about compatible browsers

**Important:** On your browser, make sure to turn on [cookies](https://support.google.com/accounts/answer/61416) and [JavaScript](https://support.google.com/chrome/answer/114662).

To get the best experience using Google Drive, Docs, Sheets, Slides, Vids, Forms, and Pics, update your browser to one of the two most recent versions.

Other browsers may work, but you might not be able to use all of the features.

### Learn about Drive for desktop compatibility

You can install and use [Drive for desktop](https://support.google.com/drive/answer/7329379) on these operating systems:

##### **Windows:**

- Requires Microsoft WebView2, which is usually included in Windows 11 and most Windows 10 devices. If it’s missing from your computer, our installer will automatically download and install it during setup.
  ### Install WebView2 manually

  If you need to install WebView2 manually:

  1.  Go to the official [Microsoft WebView2 download page](https://developer.microsoft.com/en-us/microsoft-edge/webview2/).
  2.  Under **Evergreen Standalone Installer**, click **Download**.
  3.  Open your **Downloads** folder and find the installer file.
  4.  Double-click the installer to run it and follow the on-screen instructions.
  5.  If Windows asks for administrator permission, click **Yes** or **Allow** to continue the installation.

  **Tip: **If you use an account through work or school and cannot install WebView2, contact your administrator for help.
- **64-bit**
  - Windows 10 and up
  - Windows Server 2016 and up
- **ARM64**
  - Windows 11 and up

[Learn how to check your Windows device version](https://support.microsoft.com/en-us/windows/find-information-about-your-windows-device-a66d52c8-3323-44fd-8f34-a9497bb935e1).

##### **Mac:**

- MacOS Ventura 13.0 or higher

##### **Linux:**

- The desktop version isn't available. Instead, you can use [Google Drive on the web](https://drive.google.com/).

 

Drive for desktop doesn't support:

- 32-bit Windows systems
- Operating systems in beta

### Learn what file systems are supported by Drive for desktop

**Important:** To edit Microsoft Office in real time, use Office 2010 and up.

Drive for desktop content cache supports these connected file systems:

- Apple File System (APFS) for macOS
- Hierarchical File System plus (HFS+) for macOS
- New Technology File System (NTFS) for Windows

Drive for desktop doesn't support network volumes like:

- Server Message Block (SMB)
- Network File System (NFS)

Drive for desktop creates a virtual Drive, which opens as a File Allocation Table (FAT) file system.

**Tip:** There's a file size limit for FAT. The largest possible file for a FAT32 drive is 4 GB.

## Version: Android phone & tablet

For Android devices, Google provides updates for the current and 2 previous versions. For example, when Android 11.0 is the most current release, Google also provides updates for Android 10.0 and Android 9.0.

### Verify your Android version

1.  On your Android phone or tablet, tap Settings Settings app and then **About phone** or **About tablet**.
2.  Under "Android Version," you can find which version you have.

[Learn how to check and update your Android version](https://support.google.com/android/answer/7680439).

### Download the Google Drive, Docs, Sheets, or Slides app

**Important:** To prevent errors, update your app to the latest version. [Learn how to update the Play Store and apps on Android](https://support.google.com/googleplay/answer/113412).

## Version: iPhone & iPad

Google provides app updates and support for iOS devices based on the following versions:

- The 3 most recent iOS major versions. For example, when iOS 26 is the most current release, Google also provides updates for iOS 25 and 24.
- Google Workspace app versions released within the last 2 years.

**Important:** If your OS or app version is no longer supported, you may be prompted to update to continue using supported features and receiving security updates.

### Verify your iOS version

1.  On your iPhone or iPad, open **Settings**.
2.  Tap **General** and then **About**.
3.  Next to "Version," check your iOS version.

### Download the Google Drive, Docs, Sheets, or Slides app

Download or update your app to the latest version:

- [Drive](https://itunes.apple.com/us/app/id507874739)

**Tip:** On your mobile device, you can use a web browser to access [Google Vids](http://vids.google.com). You can watch videos, but you can’t edit or add comments to videos on mobile.
