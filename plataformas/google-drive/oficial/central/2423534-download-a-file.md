# Download a file

This article has different instructions for each platform/version: Computer, Android phone & tablet, iPhone & iPad. All versions are copied below.

## Version: Computer

Download files from Google Drive with a computer, Android, or iOS device.

**Important:** If you try to download a suspicious file, you may get a warning message. Use caution if you download the file.

### Download a file

To download a file from Google Drive:

1.  Go to [drive.google.com](https://drive.google.com).
2.  Click a file to download.
    - To download multiple files, press **Command** (Mac) or **Ctrl** (Windows) and then click any other files.
3.  Right-click and then click **Download**.

**Tip**: You can't drag a file or folder directly to your desktop.

### Save a file to a different format

When you download a file, you have the option to save the file in a different format, such as:

- A PDF Document (.pdf)
- Microsoft Word (.docx)
- PowerPoint (.pptx)
- A JPEG file (.jpg)

1.  On your computer, go to [drive.google.com](https://drive.google.com/).
2.  Open the file in:
    - [Docs](https://docs.google.com/)
    - [Sheets](https://sheets.google.com/)
    - [Slides](https://slides.google.com/)
    - [Vids](https://docs.google.com/videos?usp=hc)
3.  Click **File** and then **Download.**
4.  From the list, select the desired file format.

[Learn how to convert Office and other file types into Docs, Sheets, or Slides.](https://support.google.com/docs/answer/6055139?co=GENIE.Platform%3DiOS&oco=1#zippy=%2Cdownload-office-files%2Cconvert-an-office-file)

### Fix problems downloading files

There are a few reasons you may have difficulty downloading files from Google Drive. Try the steps below to troubleshoot downloading issues.

1.  #### File Owner Settings: 

If you can't download a file, the owner may have disabled options to print, download, or copy for people with only comment or view access.

2.  #### Blocked Third-party cookies can prevent Drive Web downloads:

Drive Web uses third-party cookies to communicate with Google's secure download server. Blocking third-party cookies in Chrome will prevent you from downloading through Google Drive. If you want to block third-party cookies and still download from Drive, allow third-party cookies for just Drive.

1.  Type chrome://settings/cookies in the browser address bar and then press Enter.
2.  Under “See all site data and permissions,” scroll to the “Sites allowed to use third-party cookies” section.
3.  On the right, click Add.
4.  In the “Add a site” window, enter drive.google.com.
5.  Click Add.

It should say "Including third-party cookies on this site" below the site exception for drive.google.com. If it doesn't, click Trash to remove the site and then follow steps 2-5 above.

Under "Sites that can never use cookies," make sure there aren't any entries for googleusercontent.com, drive.google.com, or google.com. This prevents downloads from Google Drive. If you find these sites listed, click Menu and then Remove.

Tip: [*Learn more about changes to third-party cookie requirements in Google Drive*](https://workspaceupdates.googleblog.com/2023/10/upcoming-changes-to-third-party-cookies-in-google-drive.html).

3.  #### Extensions: 

Turn off all extensions and try to download. If you can download a file, turn the extensions on one at a time to identify any problems.

4.  #### "Too many users have viewed or downloaded this file recently" error:

This error occurs when a file receives high view or download volume over a short period. The restriction is temporary and typically resets within 24 hours. 

If you have view access to the file and need immediate access:

1.  On your computer, open Google Drive.
2.  Go to **Shared with me** and locate the file.
3.  Right-click the file and select **Make a copy**.
4.  Open **My Drive** to find the copied file.
5.  Right-click the new copy and select **Download**.

**Tips:** If you’re the file owner and need to share files to users without hitting temporary Drive limits:

- Share access directly with specific Google Groups rather than using public links.
- Use Google Cloud Storage or dedicated hosting solutions for large files (such as ZIP archives, media files, or installers) rather than public Google Drive links.

## Version: Android phone & tablet

Download files from Google Drive with a computer, Android, or iOS device.

**Important:** If you try to download a suspicious file, you may get a warning message. Use caution if you download the file.

### Download a file

1.  On your Android phone or tablet, open the [Google Drive app](https://play.google.com/store/apps/details?id=com.google.android.apps.docs).
2.  Next to the file's name, tap More More   and then  **Download**.

**Tip:** When Data Saver is turned on in your network settings, the download option isn’t available.

[Learn how to convert Office and other file types into Docs, Sheets, or Slides.](https://support.google.com/docs/answer/6055139?co=GENIE.Platform%3DiOS&oco=1#zippy=%2Cdownload-office-files%2Cconvert-an-office-file)

## Version: iPhone & iPad

Download files from Google Drive with a computer, Android, or iOS device.

**Important:** If you try to download a suspicious file, you may get a warning message. Use caution if you download the file.

### Download a file to a different app

1.  Open the [Google Drive](https://itunes.apple.com/us/app/google-drive-free-online-storage/id507874739) app.
2.  Next to to file you want to download, tap More More .
3.  Choose an option:
    - Tap **Download** Download documents to download the file to your device.
      - **Tip:** To find this option, you may need to scroll.
    - **Download the file to your phone**: tap **Open in** and then **Save to Files** and then Choose where you want to save the file and then **Save**.
    - **Open the file within another app**: tap **Open in** and then Choose the app you want to use.

[Learn how to convert Office and other file types into Docs, Sheets, or Slides.](https://support.google.com/docs/answer/6055139?co=GENIE.Platform%3DiOS&oco=1#zippy=%2Cdownload-office-files%2Cconvert-an-office-file)

### Save a photo or video to your camera roll

1.  Open the [Google Drive](https://itunes.apple.com/us/app/google-drive-free-online-storage/id507874739) app.
2.  Next to to file you want to download, tap More More .
3.  Tap **Send a copy**.
    - **Tip:** To find this option, you may need to scroll.
4.  Depending on your file, tap **Save image** or **Save video**.
