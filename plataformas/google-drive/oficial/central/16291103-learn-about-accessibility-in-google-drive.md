# Learn about accessibility in Google Drive

This article has different instructions for each platform/version: Computer, Android phone & tablet, iPhone & iPad. All versions are copied below.

## Version: Computer

You can use Google Drive for your files to:

- Store
- Sync
- Share
- Collaborate on them

Google Drive also contains features such as:

- Version history
- Search and organization
- Offline access
- Sharing
- Security
- Video player

We designed Google Drive and its suite of applications with accessibility in mind to ensure all users, including those with disabilities, can create, share, and collaborate effectively on files.

Key accessibility features include:

- Screen-reader compatibility
- Keyboard navigation
- Braille-display support
- High-contrast mode
- Color-blindness support
- Captioning

For best results, use the latest version of:

- Browser
- Operating system
- Assistive technology

Some accessibility features discussed in this article require specific local setup or configuration (like a physical keyboard for keyboard navigation) and might not be available in all locales.

### Vision

To interact with Google Drive with spoken feedback or Braille, use a screen reader. It describes Google Drive elements and content as you navigate and perform actions and tells you about alerts and notifications.

Additionally, Google Drive has shortcuts to:

- Create
- Move
- Share
- Search files

For more information:

- [Use Google Drive with a screen reader](https://support.google.com/drive/answer/12169158).
- [Keyboard shortcuts for Google Drive on the web](https://support.google.com/drive/answer/2563044).

To customize the appearance of Google Drive, you can:

- [Use Dark mode in Google Drive](https://support.google.com/drive/answer/9962935)
- [View & reorder your files and folders](https://support.google.com/drive/answer/2375177)
- Change the density of your Drive file list

For more information on low-vision assistance available on your platform, go to your platform’s [related resources](https://support.google.com/drive/answer/16291103#related_resource). Features include:

- Screen reading
- Screen magnification
- Text scaling
- Improve visibility of focus and cursor
- Screen resolution
- Color filtering and contrast customization
- Reading mode
- Select to speak

Drive also works with the latest version of these third-party assistive technologies for vision:

- [JAWS](https://www.freedomscientific.com/products/software/jaws/)
- [NVDA](https://www.nvaccess.org/about-nvda/)
- [ZoomText](https://www.freedomscientific.com/products/software/zoomtext/)

### Hearing

To make your video content accessible for people who are hearing impaired, add captions. Captions can:

- [Be automatically generated](https://support.google.com/drive/answer/1372218?hl=en&co=GENIE.Platform%3DDesktop&oco=1#zippy=%2Cautomatically-generated-captions)
- Be edited
- Be translated
- Independently added in multiple formats

[Learn how to add caption tracks to your video files](https://support.google.com/drive/answer/1372218).

For more information on routing platform audio to hearing aids, go to your platform’s [related resources](https://support.google.com/drive/answer/16291103#related_resource).

### Alternative input

You can use keyboard shortcuts to:

- Navigate files and views
- Select files
- Move or share files and folders
- Create new Workspace files
- Search your Drive and files shared with you

[Learn more about Google Drive keyboard shortcuts](https://support.google.com/drive/answer/2563044).

If you have a motor disorder or dexterity impairments, you can benefit from various platform features, like:

- Sticky keys
- Filter keys
- Bounce keys
- An on-screen keyboard, optionally with a switch device
- Mouse keys
- Eye or face tracking for mouse input
- Voice input for:
  - Command
  - Control
  - Dictation

To learn more about these features, go to the [related resources](https://support.google.com/drive/answer/16291103#related_resource).

### Cognition

Some people with processing disorders, distraction issues, or other cognitive challenges, need or want extensive hints, more information density, and attention grabbing UI to keep them on task. Others require a less complex UI with minimal distractions, which is why Google Drive provides settings and features to address these issues. Examples include:

- [Sort, reorder, and change the layout](https://support.google.com/drive/answer/2375177)
- [Toggle preview card](https://support.google.com/drive/answer/2375177)
- [Get summaries about recent files shared with you](https://support.google.com/drive/answer/6318501)
- [Configure Drive notifications](https://support.google.com/drive/answer/6318501)
- [Collaborate with Gemini in Google Drive](https://support.google.com/drive/answer/14356148)

Useful additional features include:

- An animation toggle
- Notification timeout and appearance
- Select to speak

To explore these features, go to the [related resources](https://support.google.com/drive/answer/16291103#related_resource).

Explore accessibility in our products on the [Google Accessibility site](https://accessibility.google/).

Google Drive also contains features such as:

We designed Google Drive and its suite of applications with accessibility in mind to ensure all users, including those with disabilities, can create, share, and collaborate effectively on files.

Key accessibility features include:

- Keyboard navigation

For best results, use the latest version of:

- Browser
- Operating system
- Assistive technology

Some accessibility features discussed in this article require specific local setup or configuration (like a physical keyboard for keyboard navigation) and might not be available in all locales.

### Vision

To interact with your device with touch and spoken feedback, [turn on Android’s TalkBack screen reader](https://support.google.com/accessibility/android/answer/6007100). As you perform actions, TalkBack describes Google Drive elements and content and informs you about alerts and notifications.

To customize the appearance of Google Drive, you can:

- [Use Dark mode in Google Drive](https://support.google.com/drive/answer/9962935)
- [View & reorder your files and folders](https://support.google.com/drive/answer/2375177)

If you need enhanced contrast or different colors, you can use:

- [High-contrast text](https://support.google.com/accessibility/android/answer/11183305#highcontrast)
- [Dark theme](https://support.google.com/accessibility/android/answer/6151800)
- [Color inversion](https://support.google.com/accessibility/android/answer/11183305#colorinversion)
- [Color correction](https://support.google.com/accessibility/android/answer/11183305#colorcorrection)

For more information on low-vision assistance available on your platform, refer to [Android Accessibility Help Center](https://support.google.com/accessibility/android). Features include:

- Screen magnification
- Text scaling
- Screen resolution
- Select to speak

### Hearing

While people who are hearing impaired can use Google Drive, Drive for Android plays video with optional caption tracks. To add caption tracks, you must upload them on your computer.

[Learn how to add caption tracks to your video files](https://support.google.com/drive/answer/1372218).

### Alternative input

If you configure an external keyboard to your device, you can use Google Drive shortcuts to navigate, select, and remove your files and folders.

[Learn more about Google Drive keyboard shortcuts](https://support.google.com/drive/answer/2563044).

For more information on platform settings for interaction and dexterity, refer to the [*Android Accessibility Help Center*](https://support.google.com/accessibility/android). Features include:

- [Adding a switch device](https://support.google.com/accessibility/answer/6301497) to navigate and interact with the Drive user interface with a switch device.
- Configuring Android’s [Voice Access](https://support.google.com/accessibility/android/answer/6151848) to navigate and interact by voice.
- Adding a Touchpad and cursor to the Assistant menu.
- Configuring touch sensitivity and duration settings.
- Adding a physical keyboard with Sticky keys, Slow keys, Bounce keys.

### Cognition

Some people with processing disorders, distraction issues, or other cognitive challenges, need or want extensive hints, more information density, and attention grabbing UI to keep them on task. Others require a less complex UI with minimal distractions, which is why Google Drive provides settings and features to address these issues. Examples include:

- [Sort, reorder, and change the layout](https://support.google.com/drive/answer/2375177)
- [Get summaries about recent files shared with you](https://support.google.com/drive/answer/6318501)
- [Configure Drive notifications](https://support.google.com/drive/answer/6318501)

To explore additional features that may be useful, go to [Android Accessibility Help Center](https://support.google.com/accessibility/android). Features include:

- An animation toggle
- Notification timeout and appearance
- Select to speak
