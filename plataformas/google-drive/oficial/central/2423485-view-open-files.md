# View & open files

With [Google Drive on the web](https://drive.google.com/), you can view things like videos, PDFs, Microsoft Office files, audio files, and photos.

**Important:** If you try to open a suspicious file, you may get a warning message. Use caution if you open the file.

## View a file

1.  Go to [drive.google.com](https://drive.google.com).
2.  Log into your Google account with your username and password.
    - [Learn how to recover your username or password.](https://support.google.com/drive/troubleshooter/2402620)
3.  Double-click a file.
4.  If you open a Google Doc, Sheet, Slides presentation, Form, or Drawing, it will open using that application.
5.  If you open a video, Microsoft Office file, audio file, or photo, it will open in Google Drive.
6.  If you open a shared Gemini chat, canvas, or generated media file, it will redirect and open the file within the Gemini web app. This applies to Workspace accounts using Drive on the web.

**Tip:** You can choose how PDF files open by default in Drive. You can:

- **Open PDFs in a new tab:** This opens the PDF file in a separate browser tab.
- **Open PDFs in preview mode in the same tab:** This displays the PDF directly in the Drive interface.

To set your preferred default behavior, go to your [Google Drive Settings](https://drive.google.com/corp/drive/settings).

## Open a file using a different app

You can open a file using web apps or apps installed on your computer. To open files with apps installed on your computer, you need the most recent version of [Google drive for desktop](https://support.google.com/drive/answer/7329379) and the [Application Launcher](https://chrome.google.com/webstore/detail/application-launcher-for/lmjegmlicamnimmfhcmpkclmigmmcbeh/) by Google.

1.  Go to [drive.google.com](https://drive.google.com).
2.  Log into your Google account with your username and password.
    - [Learn how to recover your username or password.](https://support.google.com/drive/troubleshooter/2402620)
3.  Right-click a file.
4.  Place your cursor over **Open with**.
5.  Choose an app.

Learn [how to set a default app](https://support.google.com/drive/answer/2523073) for opening certain file types.

## Open Microsoft Office files in web editors

**Important:** Admins for Business & Enterprise accounts must enable 'Microsoft Office for the Web' integration in the Admin Console.

You can open Microsoft Office documents directly in Microsoft's web-based editor applications. You can open files in the following ways:

- **Drive:**
  - Use the **Open with** context menu.
  - Select **Open with** from the file preview.
  - Double-click the file if it is your default app.
- **Editors:**
  - Select the **file extension chip** next to the name of the doc.
- **Gmail:**
  - Open from the attachment preview.
