# Get approvals on files in Google Drive

You can get approvals on your content in Google Drive. When your material is ready for review, you can lock the file and ask the recipient to approve the already drafted content. 

## Unlock a file

**Important: **When a file is locked, no one can edit it. If you unlock the file, it will cancel any in-progress approvals. Only the file owner or users with Edit permission to a file can unlock it. 

To unlock the file:

1.  On your computer, go to [Google Drive](https://drive.google.com/).
2.  Find the file you want to unlock.
3.  Right-click the file and click **Unlock**.
