# Keyboard shortcuts for Google Drive on the web

This article has different instructions for each platform/version: Computer, Android phone & tablet. All versions are copied below.

## Version: Computer

Use keyboard shortcuts in Google Drive to navigate, select, and edit.

**Note:** Some shortcuts might not work for all languages or keyboards.

Below, you'll find a list of keyboard shortcuts for Google Drive on the web.

To display the keyboard shortcut list in Google Drive, press Ctrl + / (Windows and Chrome OS) or command + / (Mac).
