# Switch from Microsoft Word to Google Docs

Learn the differences between Microsoft Word and Google Docs, and get best practices for collaboration at work or school.

## On this page

- [Comparison at a glance](#compare)
- [Related topics](#related)

#### What you'll need

15 minutes

 Google Workspace account**—[Don't have one? Start your 14-day trial today.](https://workspace.google.com/business/signup/welcome?utm_source=gwslearningcenter&utm_medium=support&utm_campaign=9310150)**

**Get Docs:** [Web (docs.google.com)](https://docs.google.com), [Android](https://play.google.com/store/apps/details?id=com.google.android.apps.docs.editors.docs), or [iOS](https://itunes.apple.com/us/app/google-docs-sync-edit-share/id842842640)

|                                                                               |                                                                               |
|                                                                               | 1.  From a document, click **File** \> **Email as attachment**.               |
|                                                                               | 2.  Under Attach as, choose the format (Word, PDF, etc.).                     |
|                                                                               | 3.  Enter the email address, subject, and message.                            |
|                                                                               | 4.  Click **Send**.                                                           |
|                                                                               |                                                                               |
|                                                                               |                                                                               |
|                                                                               |                                                                               |
|                                                                               | For more details, see [Work with Microsoft Office files](../answer/9308757).  |

|                                                                               | When you share a document, depending on their access, collaborators can edit  |

|                                                                               | -   To track changes, at the top right, click the Down arrow Down arrow .     |

| Access version history in SharePoint or OneDrive                              | #### Access version history in Docs                                           |
|                                                                               |                                                                               |

|                                                                               | 2.  Click **File** and then **Version history** and then **See version        |
|                                                                               |     history**.                                                                |
|                                                                               | 3.  Click a timestamp to see a previous version of the file. Below the        |
|                                                                               |     timestamp, you can review:                                                |
|                                                                               |     -   The names of people who edited the document.                          |
|                                                                               |     -    The color next to each person’s name. The edits they made appear in  |
|                                                                               |         that color.                                                           |
|                                                                               | 4.  (Optional) To revert to this version, click **Restore this version**.     |
|                                                                               |                                                                               |

|                                                                               |                                                                               |
|                                                                               | #### Make suggestions in a document                                           |
|                                                                               |                                                                               |
|                                                                               | +------+------------------------------------------------------------------+   |
|                                                                               | | 1\.  | At the top, make sure you’re in Suggesting mode .                |   |
|                                                                               | +------+------------------------------------------------------------------+   |
|                                                                               | | 2.   | To suggest an edit, start entering text where you think the edit |   |
|                                                                               | |      | should be made in the document. Your suggestions appear in a new |   |
|                                                                               | |      | color, and text you mark to delete or replace is crossed out     |   |
|                                                                               | |      | (but not actually deleted until the document owner approves the  |   |
|                                                                               | |      | suggestion).                                                     |   |
|                                                                               | +------+------------------------------------------------------------------+   |
|                                                                               | | 3.   | The document’s owner will receive an email with your             |   |
|                                                                               | |      | suggestions. When they click any suggestion, they can Accept or  |   |
|                                                                               | |      | Reject it.                                                       |   |
|                                                                               | +------+------------------------------------------------------------------+   |
|                                                                               |                                                                               |
|                                                                               | #### Add and assign comments in a document                                    |
|                                                                               |                                                                               |

|                                                                               |     or [Slides](https://slides.google.com), select the text you'd like to     |
|                                                                               |     comment on.                                                               |
|                                                                               | 2.  Click Add comment .                                                       |
|                                                                               | 3.  Enter your comment in the box.                                            |
|                                                                               | 4.  (Optional) To direct your task or comment to a specific person, enter a   |
|                                                                               |     plus sign (+) followed by their email address. You can add as many people |
|                                                                               |     as you want. Each person will get an email with your comment and a link   |
|                                                                               |     to the file.                                                              |
|                                                                               | 5.  (Optional) To assign the comment to a specific person, check the **Assign |
|                                                                               |     to** box.                                                                 |
|                                                                               | 6.  Click **Comment** or **Assign**.                                          |
|                                                                               |                                                                               |
|                                                                               | **Note**: If a file reaches the maximum number of comments, you can make a    |
|                                                                               | copy of the file without copying over any comments.                           |
