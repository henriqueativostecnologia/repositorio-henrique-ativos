# Add items with the @ menu

You can use the @ menu to link to people, files, and events, and add items to a Google Doc.

With the @ menu, you can add:

- [Smart chips](10710316) that show information and suggested actions for people, places, files, events.
- [Building blocks](https://support.google.com/docs/answer/10710316), including:
  - [Email drafts](https://support.google.com/docs/answer/11930385) and [meeting notes](https://support.google.com/docs/answer/11324079)
  - Custom building blocks
    - Custom building blocks aren't shareable. Only the building block creator can reuse the building block. Other users can copy the template and create their own custom building block.
- Other elements to your doc, including:
  - Dropdowns, checklists, numbered lists, and bulleted lists
  - Images, tables, and charts
  - Text headings and hyperlinks

## Use the @ menu

1.  On your computer, open a document in Google Docs.
2.  Type "@".
3.  Select from the list of suggestions.
    1.  **Tip**: To narrow your suggestions, you can type letters, numbers, or symbols after the "@". For example, to insert an email draft into your doc, type “@email” and press **Enter**.
