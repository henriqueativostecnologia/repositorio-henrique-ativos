# Draft calendar events from Google Docs

This feature is only available for eligible work or school accounts, and you’re not currently signed in. Learn more [about work and school accounts](https://workspace.google.com/).

[Sign in to your work account](https://www.google.com/accounts/Logout?continue=https://accounts.google.com/ServiceLogin?continue=https://support.google.com/drive/answer/2494822)

From your computer, you can use Google Docs to draft a calendar event draft and quickly send it to Google Calendar.

## Work with calendar event drafts on Google Docs

1.  On your computer, open a [Google Doc](https://docs.google.com/document/).
2.  At the top left, click **Insert** and then  **Building blocks** and then  **Calendar event draft**.
    - You can also type "@calendar event draft" in the doc and click **Enter**.
3.  To add people in the "Guests" field, type "@" and search your contacts, or type out email addresses.
4.  You can add an event title, start and end times, location, and description to the calendar event.
    - **Tip**: You can collaborate with others in your doc to write a calendar event draft. Learn more about how to [share access to your doc](https://support.google.com/docs/answer/2494822).

### Preview and create your calendar event draft in Google Calendar

1.  At the top left of the calendar event draft, click Send event draft to Calendar Send in Gmail .
2.  In the Calendar window, you can make additional changes to your event.
3.  When you are ready, click **Save**.
    - **Important**: The calendar event will be created from the account you are logged into.
