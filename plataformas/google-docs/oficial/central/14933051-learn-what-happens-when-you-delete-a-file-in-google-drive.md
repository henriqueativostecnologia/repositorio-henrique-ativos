# Learn what happens when you delete a file in Google Drive

When you move a file or folder to your trash, it remains there for 30 days.

- After 30 days, your files are deleted forever.
- If you manually empty your trash, the file is deleted forever.
- Items in your trash take up storage in Google Drive until they're deleted forever.

When you put a file in the trash: 

- If you're the owner of the file, others can continue to access it until the file is deleted forever.
- If you're not the owner, people can continue access the file, even if you empty your trash.

You can restore files that are still in your trash, and you may be able to recover files that have been deleted forever. [Learn how to recover a deleted file](https://support.google.com/drive/answer/1716222). 

If the file isn't deleted and you're having trouble locating it, you can search and find it in Google Drive. [Learn how to search & find a file](https://support.google.com/drive/answer/2375114).
