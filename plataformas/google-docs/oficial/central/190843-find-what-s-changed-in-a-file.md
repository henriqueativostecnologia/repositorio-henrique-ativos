# Find what's changed in a file

This article has different instructions for each platform/version: Computer, Android phone & tablet, iPhone & iPad. All versions are copied below.

## Version: Computer

Want advanced Google Workspace features for your business?

[Try Google Workspace today!](https://workspace.google.com/business/signup/welcome?utm_source=gwslearningcenter&utm_medium=support&utm_campaign=190843)

You can see changes that have been made to a document in Google Docs, Sheets, Slides, or Vids.

1.  On your computer, open a document, spreadsheet, presentation, or video.
2.  At the top right, hover over Last edit Version history to see who was the last person to update the file and when they last made changes.

**Tip:** If there is a blue dot on the Last edit Version history icon, that means someone updated the file since you last viewed it.

### Work with earlier versions of a file

**Important**:

- To browse earlier versions of a file, you need permission to edit that file.
- If you reach the version history limit in Google Vids, to continue your edits, make a new copy of your video. [Learn about Google Vids storage, object & version history limits](https://support.google.com/docs/answer/16286470).

### View an earlier version

1.  On your computer, open a document, spreadsheet, presentation, or video.
2.  At the top right, click Last edit Version history .
3.  Optional: By default, Google Sheets hides unmodified rows to make it easier to find changes within a sheet.
    - To display all rows, at the bottom right, click **Show unmodified rows**.
4.  Choose the latest version. You can find who updated the file and their changes.
5.  Optional: If you want to:
    - **Find grouped versions:** In the right panel, click Expand Down Arrow .
    - **Return to the original current version:** At the top left, click Back .

### Restore an earlier version

1.  On your computer, open a document, spreadsheet, presentation, or video.
2.  At the top right, click Last edit Version history .
3.  In the right panel, choose an earlier version.
4.  At the top, click **Restore this version** ** ** and then **Restore**.

**Tip:** When you restore an earlier version of a spreadsheet, it clears the cell-by-cell edit history for any changes made before the restore. If you need to track the cell edit history, make a copy of the spreadsheet instead.

### Copy an earlier version

You can make a copy and edit earlier versions of a file.

1.  On your computer, open a document, spreadsheet, presentation, or video.
2.  At the top right, click Last edit Version history .
3.  In the right panel, next to the version you want to copy, click More More ** ** and then **Make a copy**.
4.  Enter a name for your copy.
5.  Choose where to save the file.
    - To share the file with the same people, click **Share it with the same people**.
6.  Click **OK.**

### Create a named version

You can create a named version to track your version history and make sure your versions aren't merged.

1.  On your computer, open a document, spreadsheet, presentation, or video.
2.  At the top right, click Last edit Version history .
3.  Choose a previous version. You can find who updated the file and their changes.
4.  Click More More and then **Name this version**.
    - You can add up to 40 named versions per document.
    - You can add up to 15 names versions per spreadsheet.
    - To only show named versions, turn on Only show named versions Toggle on .

##### Manage and delete version history

As the file owner, you can manage your document's version history to remove historical content.

**Feature availability:** Deleting version history is available only for users with a personal Google Account.

**Important:** Deleting version history is permanent and cannot be undone.

#### Delete all versions

You can remove all versions of your document that have not been explicitly named.

1.  Open your Google Doc, Sheet, or Slide.
2.  At the top right, click Last edit Version history .
3.  In the version history panel on the top right, click More More .
4.  Select **Delete history** and then click **Delete forever**.

#### Delete older versions

You can remove all versions of your document that are older than a specific version and have not been explicitly named.

1.  Open your Google Doc, Sheet, or Slide.
2.  At the top right, click Last edit Version history .
3.  In the version history panel, select the version you want to keep as the latest version to be deleted.
4.  Click More More next to that version.
5.  Select **Delete this and older versions** and then click **Delete forever**.

### See who changed a part of a document in Google Docs

**Important:** This feature is available to only Google Workspace Business Standard, Business Plus, Enterprise Standard, Enterprise Plus, and Education Plus customers.

1.  On your computer, open a document at [docs.google.com](https://docs.google.com).
2.  Select part of the document and right-click and then **Show editors**.

##### See who changed a specific cell in Google Sheets

1.  On your computer, open a spreadsheet at [sheets.google.com](https://sheets.google.com).
2.  Right-click a cell and then **Show edit history**.

**Tip:** Some changes might not show up in the edit history. Some examples are:

- Added or deleted rows and columns
- Changes to the cell's format
- Changes made by formulas
- Changes made prior to restoring a past version of the spreadsheet.

### Unable to see a previous version of your file?

The revisions for your file may occasionally be merged.

**Important**: If you don't have permission to edit a file, you won't be able to see the version history.
