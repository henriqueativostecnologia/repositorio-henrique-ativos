# Compare documents in Google Docs

You can compare two documents in Google Docs to see their differences. This creates a third Google Doc that shows the differences as suggested edits.

## Compare two Google Docs

To compare two native Google Docs:

1.  On your computer, open the primary document in [Google Docs](https://docs.google.com/document/u/0/).
2.  At the top, click **Tools** and then **Compare documents**.
3.  (Optional) Customize your comparison options:
    - Attribute differences to: Enter the name or label for the suggested edits (defaults to your name).
    - Include comments: Check Include comments from the selected document to pull existing comments into the new comparison file.
4.  Select a document you want to compare against.
5.  Click **Compare**, then click **Open** to view the generated comparison document.

**Tip**: Changes to the document column layout and table column width won't be compared.

## Compare a Google Doc with a Microsoft Word (.docx) file

You can compare Google Docs files with Microsoft Word (.docx) files directly within Google Docs. You do not need to convert the Word file first.

1.  On your computer, open the primary document (.doc) in [Google Docs](https://docs.google.com/document/u/0/).
2.  At the top, click **Tools** and then **Compare documents.**
3.  In the dialog box, click **From Drive.**
4.  Select the Microsoft Word (.docx) file you want to compare against. The file must be stored in Google Drive.
5.  (Optional) Customize your comparison options:
    - Attribute differences to: Enter a name or label for the suggested edits. If left blank, it defaults to your name.
    - Include comments: Check Include comments from the selected document to pull existing comments into the new comparison file.
6.  Click **Compare**, then click **Open** to access the generated comparison document.

**Tip:** If you have the legacy “Office Editing for Docs, Sheets & Slides” Chrome extension installed, it may open Word files in a restricted viewer tab. To solve this: Open the file directly from [Google Drive](https://drive.google.com/) using Right-click and then Open with and then Google Docs.
