# Using Notion for issue tracking

## Notion makes it easy to build your own issue tracking system that fits your needs. In this video, we’ll show how you can create standardized tracking forms with templates, build custom views to follow progress, and use customized tags for better filtering and ownership.

- Notion can be used to build an effective issue tracking system, helping teams together to resolve customer issues.

  - Key practices include creating standardized forms with templates, building custom views to track issue progress, and using customized tags for easy filtering and prioritization.

  - These features ensure all necessary information is captured, tasks are tracked from triage to resolution, and high-priority tasks are appropriately managed.
