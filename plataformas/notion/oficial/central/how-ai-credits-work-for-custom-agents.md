# How AI credits work for Custom Agents

In this help doc

## Learn which type of credits a Custom Agent uses, who pays when you share one, and how workspace owners can fund an agent with Notion credits.

[Jump to FAQs](https://www.notion.com/help/how-ai-credits-work-for-custom-agents#faq)

------------------------------------------------------------------------

Business and Enterprise plans include two kinds of AI credits for each member: Standard credits and Select credits. By default, a [Custom Agent](https://www.notion.com/help/custom-agents) uses its owner’s Select credits, even when other people use it. A workspace admin can instead fund an agent with a monthly budget of [Notion credits](https://www.notion.com/help/category/notion-credits), and can set budgets and spending controls for each agent.

Learn more about [how Standard and Select credits work →](https://www.notion.com/help/manage-your-ai-credits)

## [Which credits a Custom Agent uses](https://www.notion.com/help/how-ai-credits-work-for-custom-agents#which-credits-a-custom-agent-uses)

A Custom Agent uses the owner’s [Select credits](https://www.notion.com/help/manage-your-ai-credits) first. Once the owner’s Select credits are used up, the agent can keep running on the workspace’s [Notion credits](https://www.notion.com/help/category/notion-credits), as long as an admin has allowed this and the workspace has credits available.

Admins can also [switch an agent to draw directly from the workspace’s Notion credits](https://www.notion.com/help/how-ai-credits-work-for-custom-agents#for-admins-fund-&-control-custom-agent-spending) from the start.

## [Who pays when you share an agent](https://www.notion.com/help/how-ai-credits-work-for-custom-agents#who-pays-when-you-share-an-agent)

A shared Custom Agent uses the owner’s [Select credits](https://www.notion.com/help/manage-your-ai-credits) by default. The owner can set a spending cap for each agent, so one agent can’t use up all their credits.

Workspace owners can also [switch an agent to draw directly from the workspace’s Notion credits](https://www.notion.com/help/how-ai-credits-work-for-custom-agents#for-admins-fund-&-control-custom-agent-spending) at any time.

## [What happens when a workspace has no Notion credits](https://www.notion.com/help/how-ai-credits-work-for-custom-agents#what-happens-when-a-workspace-has-no-notion-credits)

Workspace members can use a shared Custom Agent even if the workspace hasn’t bought any Notion credits. The agent runs on the owner’s [Select credits](https://www.notion.com/help/manage-your-ai-credits), up to any cap the owner has set.

If the Custom Agent owner’s Select credits run out and no [Notion credits](https://www.notion.com/help/category/notion-credits) are available, the agent will pause. It will start working again once the Select credits reset, or once the workspace has Notion credits to use.

## [How a Custom Agent uses credits](https://www.notion.com/help/how-ai-credits-work-for-custom-agents#how-a-custom-agent-uses-credits)

A Custom Agent uses credits in this order:

1.  The agent owner’s Select credits.

2.  The agent owner’s additional Notion credit allowance, if available.

3.  The workspace’s shared Notion credits, if available and a workspace owner allows their use.

Workspace owners can also [switch an agent to draw directly from the workspace’s Notion credits](https://www.notion.com/help/how-ai-credits-work-for-custom-agents#for-admins-fund-&-control-custom-agent-spending) at any time, bypassing the agent owner’s Select credits and additional allowances.

**Using Custom Agents on your phone**

On the mobile app, you can only use Custom Agents you own. Agents that other people share with you are available on desktop or the web, not on your mobile device.

You also can't create a Custom Agent on mobile. To build a new agent, open Notion on desktop or the web. Once it's set up, you can chat with it from your phone.

## [Ask a workspace owner to fund your Custom Agent](https://www.notion.com/help/how-ai-credits-work-for-custom-agents#ask-a-workspace-owner-to-fund-your-custom-agent)

If you own a Custom Agent, you can ask a workspace owner to fund it with Notion credits.

1.  Open the Custom Agent.

2.  In the top corner, select `Credits` to see the agent’s credit usage.

3.  Next to `Credit source`, select `Owner allowance` → `Request workspace credits`.

Enter the monthly budget you recommend. The workspace owner will review your request and approve or deny it. The agent will use workspace credits only after a workspace owner approves the request.

## [For owners: fund & control Custom Agent spending](https://www.notion.com/help/how-ai-credits-work-for-custom-agents#for-owners-fund-&-control-custom-agent-spending)

Workspace owners can:

- Fund any Custom Agent with a monthly budget of Notion credits.

- Switch an agent’s funding to Notion credits, so it doesn’t use the agent owner’s Select credits.

- Set or adjust each agent’s budget and spending controls.

- Set a Notion credit limit for a member, which caps how many Notion credits that person’s agents can spend.

If you’re a workspace owner, you can bypass a member’s credit pool and fund a Custom Agent directly with Notion credits. We recommend this path for Custom Agents your entire workspace uses:

1.  Open the Custom Agent.

2.  In the top corner, select `Credits` to see the agent’s credit usage.

3.  Next to `Credit source`, select `Owner allowance` → `Workspace budget`.

If you're a workspace owner on a Business or Enterprise plan, you can set a credit limit and pause a Custom Agent even if it isn't shared with you, including a private agent built by someone else.

## FAQs

Who pays for a Custom Agent I share with my team?

You do, by default. A Custom Agent uses its owner's [Select credits](https://www.notion.com/help/manage-your-ai-credits), even when other workspace members use it. A workspace owner can switch it to run on your workspace's [Notion credits](https://www.notion.com/help/category/notion-credits) instead.

What happens when my Select credits run out?

If you have a [Notion credit](https://www.notion.com/help/category/notion-credits) limit your agent keeps running on your workspace's Notion credits until you reach that limit.

If you don't have a limit, your agent moves straight to Notion credits. If no Notion credits are available, the agent pauses until your [Select credits](https://www.notion.com/help/manage-your-ai-credits) reset or your workspace has credits to use.

What happens to my Custom Agents created before November 2, 2026?

Existing Custom Agents created before November 2, 2026, will continue to draw from shared workspace credits.

Why did all my Custom Agents stop at once?

You may have reached your [Notion credit](https://www.notion.com/help/category/notion-credits) limit, which caps how many of your workspace's Notion credits you can spend. Once you hit this limit, none of your agents can run until it resets or a workspace owner raises it. You can ask a workspace owner for a higher limit.

Can I set a budget for a single Custom Agent?

Yes. You can set a spending cap for each agent, so one agent can't use up all your credits.
