# Use Google Chat keyboard shortcuts

This article has different instructions for each platform/version: Computer, Android phone & tablet. All versions are copied below.

## Version: Computer

You can use keyboard shortcuts in Google Chat on Android, Chrome OS, macOS, and Windows. To access shortcuts in Chat, type **?** anytime, except when you enter text in a field.

### Use keyboard shortcuts in Chat

**Important:** To make the shortcuts “/,” “h then c,” “h then r,” and “q” available, enable keyboard shortcuts in the “?” dialog.

### Use keyboard shortcuts to navigate around Chat

##### Navigate around chat

- To go to a conversation or space, use the **Up** and **Down arrows**. To open a conversation or space, press **Enter**.
- By default, the focus is on the message or conversation box. To read messages in a 1:1 conversation or space, press **Esc** to exit the box, then to go through the messages, use the **Up arrow**.

Legacy Spaces always have 2 levels:

- Level one is the list of conversations.
- Level 2 is messages within a conversation.

Current Spaces can have 2 levels:

- Level one is the main conversation.
- Any message in the main conversation can start a thread at the second level.

**Tips:**

- To move through the level, use the **Up** and **Down arrows**.
- To change the level, use the **Left** and **Right arrows**.
  - This may start a thread if one doesn't already exist.

##### Start a conversation

1.  Select an option:
    - On Chrome OS and Microsoft Windows, press **Ctrl** + **Shift** + **k** or 'q' when not editing.
    - On macOS, press **Command** + **Shift** + **k **or 'q' when not editing.
2.  To move through the suggestions:
    - Enter the username.
    - Use the **Up** and **Down arrows**, then press **Enter**.
3.  Enter your message.
4.  To send your message, press **Enter.**

##### Create or find a space

1.  Select an option:
    - On Chrome OS and Windows, press **Ctrl** + **o**.
    - On macOS, press **Command** + **o**.
2.  To create a space, enter the name.
3.  Press **Tab** and then ** Enter**.
4.  To find and join a space:
    - To move through the list of spaces, use the **Up** and **Down arrows**.
    - Press **Tab** to highlight or “Preview” and then **Enter**.

##### Start a new conversation or message in a space

1.  Select an option:
    - On Chrome OS and Windows, press **Ctrl** + **s**. 
    - On macOS, press **Command** + **s**.
2.  Focus moves to the main reply box.
    - In a legacy Space, this is a new topic.
3.  Enter your message.
4.  Press **Enter**.

## Version: Android phone & tablet

You can use keyboard shortcuts in Google Chat on Android, Chrome OS, macOS, and Windows. To access shortcuts in Chat, type **?** anytime, except when you enter text in a field.

### Use keyboard shortcuts in Chat

To use keyboard shortcuts on Android, connect an external keyboard to your device.

|                                                                                  |                                                     |
|----------------------------------------------------------------------------------|-----------------------------------------------------|
| **Shortcut**                                                                     | **Android**                                         |
| Open Shortcut Help Page                                                          | **?**                                               |

| Focus main reply box                                                             | **Ctrl** + **s**                                    |
