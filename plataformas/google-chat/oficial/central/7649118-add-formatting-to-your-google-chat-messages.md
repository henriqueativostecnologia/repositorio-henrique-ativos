# Add formatting to your Google Chat messages

This article has different instructions for each platform/version: Computer, Android phone & tablet, iPhone & iPad. All versions are copied below.

## Version: Computer

To change the appearance of your Chat messages, you can use the format menu, use markdown formatting, or add block quotes.

### Format Google Chat messages

1.  On your computer, open [Google Chat](https://chat.google.com/) or [Gmail](https://mail.google.com/mail/u/0/#chat/home).
    - **In Gmail:** On the left, click **Chat**.

2.  Go to a conversation.

3.  Enter a message.

4.  Highlight the text you want to format.

5.  Click Format or select one of the formatting options on the floating toolbar.

6.  Select an option:

    - **To strikethrough:** Click Strikethrough Strikethrough .
    - **To bold:** Click Bold Bold .
    - **To italicize:** Click Italic Italic .
    - **To underline:** Click Underline Underline .
    - **To change the text color:** Click Text color Color text .
    - **To add a bullet point before the text:** Click Bulleted list Bulleted list .
    - **To highlight a text or citation:** Click Block quote .
    - **To insert a link:**
      1.  Click Insert link Insert link .
      2.  Enter the link.
    - **To add inline code:** Click Code .
    - **To add multi-line code block:** Click Code block .

    **Tip:** You can also use markdown formatting to add styling to your messages. [Learn more about how to use markdown formatting in Google Chat](https://support.google.com/chat/answer/7649118#use-markdown-formatting-desktop).

7.  Click Send .

**Tip:** To remove a text format, highlight the text and repeat steps 5 and 6.

### Use markdown formatting in Google Chat

You can use markdown formatting to add styling to your messages using special characters.

1.  On your computer, open [Google Chat](https://chat.google.com/).
2.  As you type your message, add characters to update the formatting of your text:

|                       |                      |
|-----------------------|----------------------|
| **Format option**     | **Markdown example** |
| Bold                  | \*Text\*             |
| Italicize             | \_Text\_             |
| Strikethrough         | ~Text~               |
| Inline code block     | \`Text\`             |
| Multi-line code block | \`\`\`Text\`\`\`     |
| Block quote           | \>Text               |
| Bullet                | \- Text or \* Text   |

**Tips:**

- An inline code block wraps the text.
- After a multi-line code block is sent, you can use a toggle to turn the line wrapping on or off.
- You can choose to have live markdown on or off. If you turn off live markdown, after you send the message, the text converts to the format.

##### Turn live markdown on or off in Google Chat

1.  On your computer, open [Gmail](https://mail.google.com/).
2.  At the top right, click Settings and then **See all settings**.
3.  At the top, click **Chat and Meet** and then **Manage chat settings**.
4.  On the left, click **Message & Media**.
5.  Turn **Live Markdown** on or off.

##### Turn live markdown on or off in Chat for Gmail

1.  On your computer, open [Google Chat](https://chat.google.com/).
2.  At the top right, click Settings .
3.  On the left, click **Message & Media**.
4.  Turn **Live Markdown** on or off.
5.  If you turn off this setting, you can include special characters in the text. After you send the message, the text converts to the format.

### Add block quotes

To highlight key text or citations in your Chat messages, use block quotes.

1.  On your computer, open [Google Chat](https://chat.google.com/app/home) or [Gmail](https://mail.google.com/mail/u/0/#chat/home).
    - **In Gmail:** On the left, click **Chat**.
2.  Go to a conversation.
3.  Enter a message.
4.  To format the text, highlight it.
5.  To use a block quote, click Formatting options and then Block quote and then enter a message.
    - Or, you can:
      1.  Enter a message.
      2.  Highlight the text you want to format.
      3.  Click Formatting options and then Block quote .
6.  Click Send .

## Version: Android phone & tablet

2.  Go to a conversation.
3.  Enter a message.
4.  On the left, tap Action menu Add and then Format Color text .
5.  Select an option:
    - **To strikethrough:** Tap Strikethrough Strikethrough .
    - **To bold:** Tap Bold Bold .
    - **To italicize:** Tap Italic Italic .
    - **To underline:** Tap Underline Underline .

      1.  Tap Insert link Insert link .
      2.  Enter the link.
    - **To add inline code:** Tap Code .
    - **To add multi-line code block:** Tap Code block .
6.  Tap Send .

**Tip:** To quickly add or remove text format, touch and hold the text, then tap **Format**.
