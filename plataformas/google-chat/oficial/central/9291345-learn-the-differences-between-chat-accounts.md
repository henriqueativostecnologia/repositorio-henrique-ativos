# Learn the differences between Chat accounts

You can use Google Chat with a personal Google Account or a paid Google Workspace account. The available features for Google Chat depend on the type of account you use to sign in.

|                                      | Paid Google Workspace account | Personal account |
|--------------------------------------|-------------------------------|------------------|
| Pin or unpin a space or conversation | **✔**                         | **✔**            |
| Send and react with emojis           | **✔**                         | **✔**            |
| Start a direct message               | **✔**                         | **✔**            |
| Create a space                       | **✔**                         | **✔**            |
| Message an app                       | **✔**                         | **✔**            |
| Set up webhooks in messages          | **✔**                         |                  |
| Edit messages                        | **✔**                         | **✔**            |
| Delete messages                      | **✔**                         | **✔**            |
