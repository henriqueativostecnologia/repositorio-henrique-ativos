# Use the Jira app in Google Chat

This article has different instructions for each platform/version: Computer, Android phone & tablet, iPhone & iPad. All versions are copied below.

## Version: Computer

Use the Jira app in Chat to get messages about updates to your Jira Software projects. The app sends messages from Jira to Chat.

### Before you begin

- You need permission to install apps from your Google Workspace administrator.
- Add the app to Chat. [Learn how to find apps and add them to Chat](https://support.google.com/chat/answer/7655820).
- Install the Chat Jira plugin from the [Atlassian Marketplace](https://marketplace.atlassian.com/search?product=jira). Your Jira admin may need to approve this.

### Set up the Jira app in Chat

1.  Open [Chat](https://chat.google.com).
2.  Open a direct message with the app or go to a space with the app.
    - After installation, you get a welcome message and a card that prompts you to connect to Jira.
    - If you connect in a direct message for personal notifications, notifications are automatically enabled when you connect the app. You can set up which issues you receive updates on, such as issues that you:
      - Report
      - Watch
      - Are the assignee on
      - Are mentioned in
    - These notifications apply across one or more Jira sites.
3.  Click **Connect**.
    - If you already set up Jira, the app uses the site from the previous connection.
    - After you connect the app to Jira, you can:
      - **In a direct message:** Select the projects from where you want to receive personal notifications.
      - **In a space:** Select projects quickly to subscribe to issues.
    - After a successful connection, you’ll receive a confirmation message and a list of connected Jira sites or projects. To edit filters or change these settings, click **Edit notification settings**.
4.  Enter the project names to receive notifications.
5.  Optional: You can use the multi-select search to enter the projects.
6.  Click **Save**.
7.  Optional: To edit notifications, click **Edit notification settings**.

**Tip:** You need to set up notifications in each space where you add the app. The app sends notifications to all spaces where it's a member.

### Update Jira app notification settings

Jira app notifications are displayed with styled formatting in Chat. This includes elements such as headers, lists, code blocks, checklists, quotes, and links. If a notification includes a table, it will be displayed as structured plain text.

You can manage your personal-notification settings within the Jira app's direct message.

#### Manage personal filters

To select the types of personal updates you want to receive:

1.  On your computer, open a direct message with the Jira app.
2.  If prompted, to open the settings dialogue, select **Edit notification settings**.
    - Or, you can type: `/jira_settings`. Then, press **Enter**.
3.  Select or deselect the types of personal updates you want to receive on issues:
    - You’re watching
    - You’ve reported
    - You’re the assignee on
    - You’re mentioned in
    - Ignore changes made by myself (on by default)
4.  Optional: You can also manage connected Jira sites from this page.
5.  Click **Save**.

#### Filter notifications by project (single-connected site)

When you have only one Jira site connected, you can filter your personal notifications to specific projects.

To locate the project-filtering options in the settings dialogue:

1.  On your computer, open a direct message with the Jira app.
2.  If prompted, to open the settings dialogue, click **Edit notification settings**.
    - Or, you can type: `/jira_settings`. Then, press **Enter**.
3.  In “Send updates from only these projects,” select the specific projects you want to filter for.
4.  Click **Save**.

**Tip:** The default interface provides “All Projects.”

#### Filter notifications by project (multiple-connected sites)

When you have multiple Jira sites connected, you can filter your personal notifications by project for each site.

To locate the project-filtering options for each connected site in the settings dialogue:

1.  On your computer, open a direct message with the Jira app.
2.  If prompted, to open the settings dialogue, select **Edit notification settings**.
    - Or, you can type: `/jira_settings`. Then, press **Enter**.
3.  To receive notifications for a site, in “Send updates from only these projects,” select specific projects.
4.  Optional: Repeat for other connected sites as needed.
5.  Click **Save**.

**Tip:** Each Jira site provides an option like “sitename: All Projects.”

### Use Jira app commands in Chat

**Important:** To get available commands, enter: `/`

You can use these slash commands in a direct message or space with the Jira app in Chat:

- `/jira_connect`: Connects the Jira app to your Jira site.
- `/jira_create`: Creates a new issue.
- `/jira_view [issue_id]`: Provides the specified Jira issue info.
- `/jira_disconnect`: Disconnects the Jira app or this space from your Jira site.
- `/jira_help`: Displays the help message.
- `/jira_feedback`: Sends feedback about the Jira app.
- `/jira_subscriptions`: Shows settings to manage subscriptions for Jira projects with specific filters.
- `/jira_settings`: Shows settings for personal notifications and space subscriptions.

You can also use the “Create issue” and “Settings” buttons for quick access to related actions.

### Change app settings

1.  Open [Chat](https://chat.google.com).
2.  Open a direct message with the app or go to a space with the app.
3.  Type `/jira_settings` and press **Enter**. The settings page opens.
4.  Change the settings as needed.
5.  Click **Save**.

### Delete app settings

1.  Open [Chat](https://chat.google.com).
2.  Open a direct message with the app or go to a space with the app.
3.  To delete the configuration, enter delete config. In spaces, enter `/jira_settings`.

**Note:** Removing the app from a space deletes the app settings. Removing the app from a direct message only pauses notifications. To fully disconnect and revoke your Jira credentials, you need to run the `/jira_disconnect` command.
