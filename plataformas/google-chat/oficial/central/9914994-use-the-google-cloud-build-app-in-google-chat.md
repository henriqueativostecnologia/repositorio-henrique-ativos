# Use the Google Cloud Build app in Google Chat

This article has different instructions for each platform/version: Computer, Android phone & tablet, iPhone & iPad. All versions are copied below.

## Version: Computer

Use the Google Cloud Build app in Chat to get notifications about your Cloud Build projects.

### Before you begin

Enable the Cloud Build API for any project where you want to use the Cloud Build app. Learn more about [Cloud Build](https://cloud.google.com/cloud-build/docs).

- You need a Google Cloud Platform account.
- You need permission to install apps from your Google Workspace administrator.
- Add the app to Chat. [Learn how to find apps and add them to Chat](https://support.google.com/chat/answer/7655820).

### Set up the Cloud Build app notifications

**Tip:** You need to set up notifications in each space where you add the app. The app sends notifications to all spaces where it's a member.

1.  Open [Google Chat](https://chat.google.com).
2.  Choose an option:
    - Open a direct message with the app and enter **settings**.
    - Go to a space with the app and enter **@Cloud Build settings** or **/Cloud Build settings**.
3.  The current settings for the app opens.
4.  Click **Edit Settings**.
5.  Sign in to your Cloud Build account.
    - The Cloud Build app configuration window opens and loads the Cloud projects that are available to you.
6.  Enter the name of a Cloud project.
    - You can find a list of triggers.
7.  Select a Cloud Build trigger from the list.
8.  From the **Thread messages by** menu, choose an option:
    - **No threads**
    - **Project**
    - **Trigger**.
9.  Select the states for which you want to send Chat notifications.
10. Click **Save**.
11. Optional: To configure another project and trigger notification, click **Add**.

### Change app settings

In spaces, only the person who configured the app can change the settings.

1.  Open [Google Chat](https://chat.google.com).
2.  Choose an option:
    - Open a direct message with the app and enter **settings**.
    - Go to a space with the app and enter **@Cloud Build settings** or **/Cloud Build settings**.
3.  The current settings for the app opens.
4.  Click **Edit Settings**.
5.  Sign in to your Cloud Build account.
    - The Cloud Build app configuration window opens.
6.  Click Edit and change the settings as needed.
7.  Click **Save**.

Once the app is removed from a space, the app settings get deleted.

- To get a list of all available commands, enter **@Cloud Build help** or **/Cloud Build help**.
- To find the currently configured notifications, enter **@Cloud Build settings** or **/Cloud Build settings**.
- To send feedback about the app, enter **@Cloud Build feedback** ***feedback text*** or ***/*****Cloud Build feedback** ***feedback text***.
