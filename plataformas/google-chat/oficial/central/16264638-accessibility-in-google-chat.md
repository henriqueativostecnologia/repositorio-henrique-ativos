# Accessibility in Google Chat

This article has different instructions for each platform/version: Computer, Android phone & tablet, iPhone & iPad. All versions are copied below.

## Version: Computer

### Overview

You can use Google Chat with platform accessibility features and technologies, such as screen readers. It has several built-in accessibility features, like:

- Keyboard shortcuts
- Suggested replies
- Spelling and grammar correction

For best results, use the latest version of:

- Chat
- Browser
- Operating system
- Assistive technology

### Vision

To interact with Chat with spoken feedback or Braille, use a screen reader to:

- Describe Chat elements and content as you navigate.
- Perform actions.
- Inform you about alerts and notifications.

Additionally, Chat has shortcuts to:

- Navigate.
- Search.
- Reply to messages.
- Announce recent messages in a conversation.

For more information:

- [*Learn how to use Google Chat with a screen reader*](https://support.google.com/hangoutschat/answer/7652236).
- [*Learn how to use Google Chat keyboard shortcuts*](https://support.google.com/chat/answer/7649271).

To customize the appearance of Chat, you have multiple options.

- [Learn how to update appearance in Google Chat](https://support.google.com/chat/answer/9951283).
- [*Learn how to create & organize sections in Google Chat*](https://support.google.com/chat/answer/16059854).

For more information on low vision assistance available on your platform, refer to your platform’s [*related resources*](#related_resources). Features include:

- Screen reader
- Screen magnification
- Text scaling
- Improve visibility of focus and cursor
- Screen resolution
- Color filter and contrast customization
- Reading mode
- Select to speak

In addition to the platform features listed above, Chat also works with the latest version of these third-party assistive technologies for vision:

- [*JAWS*](https://www.freedomscientific.com/products/software/jaws/)
- [*NVDA*](https://www.nvaccess.org/about-nvda/)
- [*ZoomText*](https://www.freedomscientific.com/products/software/zoomtext/)

### Hearing

While most chat conversations don’t include audio, it’s possible to [*start a video meeting or call someone*](https://support.google.com/chat/answer/7653283). If you’re in a video meeting or a call, to follow the conversation, turn on captions.

1.  In a video or audio call, click More options and then **Settings**.
2.  Select **Captions** and then **Live captions**.
    - Or, to send text instead of speaking, select **In call messages**.

**Tips:**

- If all meeting participants understand sign language, there’s no need for captions or in call messages.

&nbsp;

- If someone sends a voice message instead of text, in the message, you can view a transcript. [*Learn how to send a voice message or view a transcript*](https://support.google.com/chat/answer/14763931).

For more information on routing platform audio to hearing aids, refer to your platform’s [*related resources*](#related_resources).

### Alternative input

You can use several powerful and useful shortcuts in Chat to:

- Open a conversation.
- Reply to a conversation.
- Navigate to the sections for direct messages, spaces, and threads.

For a list of shortcuts, visit [*Use Google Chat keyboard shortcuts*](https://support.google.com/chat/answer/7649271).

If you want to reduce your keyboard input, you can:

- [*Send a voice message*](https://support.google.com/chat/answer/14763931).
- [*Send a video message*](https://support.google.com/chat/answer/15399735).
- [*Start a video meeting or call someone*](https://support.google.com/chat/answer/7653283).

These optional smart features can improve the efficiency of all Chat users and help those who need to minimize mouse or keyboard input:

- [*Smart Compose*](https://support.google.com/chat/answer/13568047)
- [*Smart Reply*](https://support.google.com/chat/answer/7654374)
- Auto-correct

Chat supports platform features that can be helpful for those with motor disabilities or dexterity impairments:

- Sticky keys, Filter keys, and Bounce keys
- An on-screen keyboard, optionally with a switch device
- Mouse keys
- Eye or face tracking for mouse input
- Voice input for:
  - Command
  - Control
  - Dictation

For more information on these features, refer to your platform’s [*related resources*](#related_resources).

### Voice

While most Chat conversations don’t include audio, it’s possible to [*start a video meeting or call someone*](https://support.google.com/chat/answer/7653283). If that happens, you can participate when you send:

- Reactions
- “In call messages”
  - To send, click More options and then **In call messages**.

If you use an electrolarynx, we recommend you turn off the noise cancellation.

1.  In a video or audio call, click More options and then Settings .
2.  Turn off **Noise cancellation**.

### Cognition

Some people with processing disorders, distraction issues, or other cognitive challenges, need or want extensive hints, more information density, and attention grabbing UI to keep them on task. Others require a less complex UI with minimal distractions. Which is why Google Chat provides settings and features to address these issues with toggles to turn individual features on or off. Examples include:

- [*UI density*](https://support.google.com/chat/answer/15571501) adjustment
- [*Create & organize sections*](https://support.google.com/chat/answer/16059854)
- Animation on/off/use system settings
- Optional autocorrect
- Optional [*Smart compose*](https://support.google.com/chat/answer/13568047) that can learn from you
- [*Conversation summaries*](https://support.google.com/chat/answer/12918975)
- [*Configure desktop notifications*](https://support.google.com/chat/answer/7655718)

Additional features that can be useful include:

- Animation toggle
- Notification timeout and appearance
- Select to speak

To explore these features, refer to your platform’s [*related resources*](#related_resources).

Explore accessibility in our products on the [Google Accessibility site](https://accessibility.google/).
