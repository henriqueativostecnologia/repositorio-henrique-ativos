# Install the Google Chat standalone app

For a simple way to use Google Chat, install the Google Chat standalone app in your Chrome Browser. This provides a streamlined Chat experience and is a [Progressive Web Application (PWA)](https://support.google.com/chrome/answer/9658361) that you can open from your desktop.

**Important:** There’s no Google Chat Chrome extension. For a similar experience, install the app.

## Check system requirements

To install the Chat standalone app, make sure:

- Your device is running [Google Chrome 73 or up](https://www.google.com/chrome/).
  - Chrome doesn’t need to be your default browser, but it does need to be open to use the Chat standalone app.
- You can install Chrome extensions and apps on your computer.
  - If you can't complete the installation and you use a work or school account, contact your [Google Workspace administrator](https://support.google.com/accounts/answer/6208960).

## Install the standalone app on your computer

1.  Sign in to [chat.google.com](https://chat.google.com/).
2.  To install the app on your computer, try one of these methods:
    - At the top right of Google Chrome, in the URL bar, click Install and then **Install**.
    - At the top right of Google Chrome, click More and then **Install Google Chat**.

**Tip:**

- If you already created a Google Chrome shortcut to [chat.google.com](https://chat.google.com), the app automatically installs. You won't have the option to manually install the app.

## Open the standalone app

Once installed, you can open the standalone app from your desktop:

- In ChromeOS, go to the Launcher and then **Chat**.
- In Windows, click **Start** and then **Chat**.
- In MacOS, go to the Applications folder and then **Chat**.
- In a Chrome browser, in the address bar, enter chrome://apps and click **Google Chat**.

## Open the standalone app automatically at startup

**Important:** These steps don't work on Chrome OS.

1.  On your computer, open Chrome.
2.  In the address bar, enter chrome://apps.
3.  Right-click on the Chat standalone app .
4.  Select **Launch at startup**.

## Uninstall the Chat standalone app

#### Uninstall the standalone app on Mac, Windows, or Linux

1.  On your computer, open Chrome.
2.  In the address bar, enter chrome://apps.
3.  Right-click on the Chat standalone app .
4.  Select **Uninstall** and then **Remove**.

#### Uninstall the standalone app on Chrome OS

1.  On your computer, open Launcher .
2.  In the search bar, search for Google Chat.
3.  In the search results, right-click on the Chat standalone app .
4.  Click **Remove from Chrome** and then **Remove**.
