# Accessibility in Google Calendar

This article has different instructions for each platform/version: Computer, Android phone & tablet, iPhone & iPad. All versions are copied below.

## Version: Computer

You can access Google Calendar on any device. It’s part of the Google Workspace suite of productivity tools, like Gmail, Google Meet, Google Docs, and more.

You can use Calendar to:

- Create and manage events
- Set reminders
- Share your Calendar with others

You can use Calendar with platform accessibility features and tools and market leading accessibility technologies such as screen readers. There are several built-in accessibility features in Calendar, like keyboard shortcuts and multiple view options.

For the best experience, use the latest version of your:

- Browser
- Operating system
- Assistive technology

Some accessibility features discussed in this article require specific local setup or configuration and might not be available in all locales.

### Vision

To interact with Calendar with spoken feedback or Braille, use a screen reader. It describes Calendar elements and content as you navigate and perform actions. A screen reader can also tell you about alerts and notifications.

You can use keyboard shortcuts to:

- Navigate
- Change the view
- Create an event
- Open settings
- Search

If you use the screen reader, you can use shortcuts to quickly announce specific details of an open event without navigation. For more information, go to:

- [Use keyboard shortcuts in Google Calendar](https://support.google.com/calendar/answer/37034)
- [Use Google Calendar with a screen reader](https://support.google.com/calendar/answer/6101541)

You have multiple options to customize the appearance of Calendar:

- [Use Dark theme in Calendar](https://support.google.com/calendar/answer/15240542)
- [View your day, week, or month](https://support.google.com/calendar/answer/6110849)
- [Use color labels to track Calendar entries](https://support.google.com/calendar/answer/12377581)
- [Change event color set & density in Google Calendar](https://support.google.com/calendar/answer/15619910)

For more information on low vision assistance available on your device, go to the [*related resources*](#related_resources.). Features include:

- Screen reading
- Screen magnification
- Text scaling
- Improve visibility of focus and cursor
- Screen resolution
- Color filtering and contrast customization
- Reading mode
- Select to speak

In addition to the platform features listed above, Calendar also works with the latest version of these third-party assistive technologies for vision:

- [JAWS](https://www.freedomscientific.com/products/software/jaws/)
- [NVDA](https://www.nvaccess.org/about-nvda/)
- [ZoomText](https://www.freedomscientific.com/products/software/zoomtext/)

### Hearing

Google Calendar can generally be used without hearing, but you should [modify notifications](https://support.google.com/calendar/answer/37242) to ensure that reminders are delivered in a way you can perceive. For additional notification options, go to [*related resources*](#related_resources.).

### Alternative input

You can use keyboard shortcuts to:

- Move around the Calendar
- Change your Calendar view
- Create or make changes to an event
- Search for an event

[Learn how to use keyboard shortcuts in Google Calendar](https://support.google.com/calendar/answer/37034).

To minimize your mouse or keyboard input, you can use these features (you may need to enable in [Calendar settings](https://support.google.com/calendar/answer/6084644)):

- Options to manage invitations in Calendar which includes automatically adding invitations. [Learn how to manage invitations in Calendar](https://support.google.com/calendar/answer/13159188).
- Right-click menu.
- Join scheduled meetings.
- Get directions to event locations.

If you have motor disorder or dexterity impairments, you can benefit from various platform features, like:

- Add a physical keyboard with:
  - Sticky keys
  - Filter keys
  - Bounce keys
- An on-screen keyboard, optionally with a switch device
- Mouse keys
- Eye or face tracking for mouse input
- Voice input for:
  - Command
  - Control
  - Dictation

To know more about these features, go to the [*related resources*](#related_resources.).

### Cognition

Users with cognitive challenges like processing orders or distraction issues have different requirements, some need extensive hints and attention-grabbing UI to stay on task, while others need minimal distractions.

To meet these requirements, Calendar provides settings and features with toggles to turn individual features on or off. [Learn how to change Google Calendar settings](https://support.google.com/calendar/answer/6084644).

These features include:

- [Change the number of days shown on your calendar](https://support.google.com/calendar/answer/6110849)
- [Use color labels for multiple calendars](https://support.google.com/calendar/answer/12377581)
- [Change event color set and density](https://support.google.com/calendar/answer/15619910)
- [Configure notifications](https://support.google.com/calendar/answer/37242)
- Options to [personalize your Calendar](https://support.google.com/a/users/answer/9323423)

**Tip:** To automatically add trip itineraries and reservations to your Calendar, [learn how to manage your events from Gmail](https://support.google.com/calendar/answer/6084018).

Additional features that can be useful include:

- Toggling animation
- Notification timeout and appearance
- Select to speak

To explore these features, go to the [*related resources*](#related_resources.) for your platform.

Explore accessibility in our products on the [Google Accessibility site](https://accessibility.google/).

## Version: Android phone & tablet

You can access Google Calendar on any device. It’s part of the Google Workspace suite of productivity tools, like Gmail, Google Meet, Google Docs, and more.

- Create and manage events
- Set reminders
- Share your Calendar with others

- Browser
- Operating system
- Assistive technology

Some accessibility features discussed in this article require specific local setup or configuration and might not be available in all locales.

### Vision

To interact with your device with touch and spoken feedback, turn on [TalkBack](https://support.google.com/accessibility/android/answer/6007100). As you navigate and perform actions, TalkBack describes Calendar elements and content. It also informs you about alerts and notifications.

To learn how to customize the appearance of Calendar, go to:

- [Use Dark theme in Calendar](https://support.google.com/calendar/answer/15240542)
- [View your day, week, or month](https://support.google.com/calendar/answer/6110849)
- [Use color labels to track Calendar entries](https://support.google.com/calendar/answer/12377581)

To adjust contrast or colors, use Android features, like:

- [High-contrast text](https://support.google.com/accessibility/android/answer/11183305#use_high_contrast)
- [Dark theme](https://support.google.com/accessibility/android/answer/6151800)
- [Color inversion](https://support.google.com/accessibility/android/answer/11183305#use_color_inversion)
- [Color correction](https://support.google.com/accessibility/android/answer/11183305#use_color_correction)

For more info on low vision assistance on Android, go to [Android Accessibility Help Center](https://support.google.com/accessibility/android). Features include:

- Screen magnification
- Text scaling
- Screen resolution
- Select to speak

### Hearing

Google Calendar can generally be used without hearing, but you should [modify notifications](https://support.google.com/calendar/answer/37242) to ensure that reminders are delivered in a way you can perceive. For additional notification options, go to related resources.

### Alternative input

If you attach a keyboard to your device, you can use Calendar shortcuts to:

- Change your Calendar view.
- Create or make changes to an event.
- Search for an event.

[Learn how to use keyboard shortcuts in Google Calendar](https://support.google.com/calendar/answer/37034).

To minimize your interactions, enable these features and change these [Calendar settings](https://support.google.com/calendar/answer/6084644):

- [Manage invitations in Calendar](https://support.google.com/calendar/answer/13159188)
- Join scheduled meetings
- Get directions to event locations

These Android features for interaction and dexterity may be useful:

- To navigate and interact with the Calendar using a switch device, [set up Switch Access](https://support.google.com/accessibility/answer/6301497).
- To navigate and interact by voice, [set up Voice Access](https://support.google.com/accessibility/android/answer/6151848).
- Add a touchpad and cursor to the “Assistant” menu.
- Configure touch sensitivity and duration settings.
- Add a physical keyboard with:
  - Sticky keys
  - Slow keys
  - Bounce keys

For more information on platform settings for interaction and dexterity, go to [Android Accessibility Help Center](https://support.google.com/accessibility/android).

### Cognition

Users with cognitive challenges like processing orders or distraction issues have different requirements, some need extensive hints and attention-grabbing UI to stay on task, while others need minimal distractions.

To meet these requirements, Calendar provides settings and features with toggles to turn individual features on or off. [Learn how to change Google Calendar settings](https://support.google.com/calendar/answer/6084644).

You can also go to:

- [View your day, week, or month](https://support.google.com/calendar/answer/6110849)
- [Use color labels to track Calendar entries](https://support.google.com/calendar/answer/12377581)
- [Modify Google Calendar notifications](https://support.google.com/calendar/answer/37242)

**Tip:** To automatically add trip itineraries and reservations to your Calendar, [learn how to manage your events from Gmail](https://support.google.com/calendar/answer/6084018).

To explore additional platform features, go to [Android Accessibility Help Center](https://support.google.com/accessibility/android).

Additional features that can be useful include:

- Toggling animation
- Notification timeout and appearance
- Select to speak
