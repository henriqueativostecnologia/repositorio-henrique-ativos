# Learn about supported browsers for Google Calendar

**Important:** If you’re redirected to this help page from [calendar.google.com](https://calendar.google.com), download a supported browser or the Calendar app for Android, iPhone, or iPad.

When you open Google Calendar in a browser, make sure the browser is supported and up-to-date. If you have the latest version of your browser, you get the latest Calendar features, and improved security and performance.

## Download a supported browser

**Important:** To use Calendar in your browser, turn on JavaScript and cookies.

To download a supported browser, select it from the list:

- [Google Chrome](http://www.google.com/chrome/)
- [Firefox](https://www.mozilla.org/firefox/new/)
- [Safari](http://www.apple.com/safari/)
- [Microsoft Edge](http://www.microsoft.com/microsoft-edge)

If you use Calendar on an older or unsupported browser:

- Some features might not work.
- The application might not open.

For example, on an unsupported browser, you can find your calendars but not update them.

## Open Calendar in your browser

1.  On your device, open a supported browser.
2.  Go to [calendar.google.com](http://calendar.google.com/).
3.  Sign in to your Google Account.

## Learn about browser updates

**Important:** Offline access and accessibility tools for Calendar aren’t supported in Firefox, Safari, and Microsoft Edge.

- **Google Chrome**
  - You can use Calendar with the latest version of Chrome.
  - Usually, Chrome updates automatically when a new version is out.
  - If you don't have the latest version, [update Chrome](https://support.google.com/chrome/answer/95414).
- **Firefox, Safari, and Microsoft Edge**
  - You can use Calendar with the current and previous versions of Firefox, Safari, and Microsoft Edge.
  - With each new browser update, Calendar supports the latest version and stops support for the third most recent version.

## Use Calendar in a mobile browser

On most phones and tablets, you can use Calendar in a mobile browser. If you get an error:

- On your phone, download a different browser.
- On your browser, make sure to turn on cookies.
- Install the Calendar app instead.
