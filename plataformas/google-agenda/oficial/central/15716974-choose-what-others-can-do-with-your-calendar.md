# Choose what others can do with your calendar

This article has different instructions for each platform/version: Computer, Android phone & tablet, iPhone & iPad. All versions are copied below.

## Version: Computer

**Important**: If you have a work or school account, your administrator can limit sharing or turn off permission settings. If you can’t select a setting for your calendar, [contact your administrator](https://support.google.com/a/answer/6208960).

After you share your calendar, you can set up permissions to control how others interact with your shared calendar. You can set permissions in Google Calendar for:

- All events and tasks with start and end times on your calendar.
- Specific people and groups.

### Learn about Google Calendar access permissions

+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| **Permission**                                                                | **Definition**                                                                |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| **See only free/busy (hide details)**                                         | People can only find out when you're busy on your calendar. They can’t find   |
|                                                                               | the names or details about events or tasks on your calendar.                  |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| **See event details**                                                         | People can find all details, like event names, times, places, and             |
|                                                                               | descriptions.                                                                 |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| **Make changes (see private events as free/busy)**                            | People can edit non-private events, but can't edit private events.            |
|                                                                               |                                                                               |
|                                                                               | If a private event is “Busy,” it shows up as a busy block on your calendar    |
|                                                                               | with no event details.                                                        |
|                                                                               |                                                                               |
|                                                                               | If a private event is “Free,” it does not appear on your calendar.            |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| **Make changes and see event details**                                        | People can edit events on your calendar and find who else it’s shared with.   |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| **Make changes and manage sharing**                                           | People have full control of events or tasks with start and end time on your   |
|                                                                               | calendar and can share your calendar with others.                             |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+

Broader calendar permissions take priority if there is a conflict in permission settings. For example:

- You make your calendar public and set the permission to **See event details**.
- Then, you share your calendar with someone else and set their permission to **See only free/busy (hide details)**.
- Since the calendar is public, anyone can find details about events on your calendar, including the person that has **See only free/busy (hide details)** access to your calendar.

### Change permissions for your calendar

**Important**: The access permissions you choose for your calendar controls the behavior of visibility settings for individual events and tasks. [Learn how to change event and task visibility on your calendar](https://support.google.com/calendar/answer/34580).

1.  On your computer, open [Google Calendar](https://calendar.google.com/).
2.  On the left, find the “My calendars” section.
    - If you can’t find all your calendars, click **My calendars**.
3.  To the right of the calendar, click More and then **Settings and sharing**.
4.  On the left, click **Access permissions for events**.
5.  Next to “Make available to public” or “Make available for {company name},” click the drop-down menu Dropdown .
6.  In the menu, select the permission.

### Change permissions for specific people or groups

1.  On your computer, open [Google Calendar](https://calendar.google.com/).
2.  On the left side of Calendar, click **My calendars**.
3.  To the right of the calendar, click More and then **Settings and sharing**.
4.  On the left, click **Shared with**.
5.  Next to the person or group, click the drop-down menu Dropdown .
6.  In the menu, select the permission.

### Learn how permissions affect what others can do on your calendar

Use the table below to check how your primary calendar’s permissions affect what others can do on your calendar.

| What others can do                                                                                 | See free/busy   | See event details | Make changes (see private events as free/busy) | Make changes and see event details | Make changes and manage sharing |
|----------------------------------------------------------------------------------------------------|-----------------|-------------------|------------------------------------------------|------------------------------------|---------------------------------|
| **View the calendar's time zone**                                                                  | blue check mark | blue check mark   | blue check mark                                | blue check mark                    | blue check mark                 |
| **Subscribe to email alerts** (for future events, creations, changes, cancellations, or responses) |                 | blue check mark   | blue check mark                                | blue check mark                    | blue check mark                 |
| **See guest lists** (for events without "See guest list" permission)                               |                 |                   | blue check mark \*                             | blue check mark                    | blue check mark                 |
| **View sharing settings**                                                                          |                 |                   | blue check mark                                | blue check mark                    | blue check mark                 |
| **Restore or permanently delete items from your trash**                                            |                 |                   | blue check mark \*                             | blue check mark                    | blue check mark                 |
| **Create or edit events on your calendar**                                                         |                 |                   | blue check mark \*                             | blue check mark                    | blue check mark                 |
| **Update some details for tasks with time blocks** (for example, “Do not disturb”)                 |                 |                   | blue check mark \*                             | blue check mark                    | blue check mark                 |
| **Permanently delete the calendar**                                                                |                 |                   |                                                |                                    | blue check mark                 |
| **Create tasks on your calendar**                                                                  |                 |                   |                                                |                                    |                                 |

\* As long as the event or task is not private.
