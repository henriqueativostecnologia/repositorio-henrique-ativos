# COLUMNS

Returns the number of columns in a specified array or range.

### Sample Usage

`COLUMNS(A9:W62)`

`COLUMNS({1,2,3,4,5})`

### Syntax

`COLUMNS(range)`

- `range` - The range whose column count will be returned

### See Also

[`ROWS`](https://support.google.com/docs/answer/3093382): Returns the number of rows in a specified array or range.

[`ROW`](https://support.google.com/docs/answer/3093316): Returns the row number of a specified cell.

[`COLUMN`](https://support.google.com/docs/answer/3093373): Returns the column number of a specified cell, with \`A=1\`.
