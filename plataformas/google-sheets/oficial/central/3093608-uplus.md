# UPLUS

Returns a specified number, unchanged.

### Sample Usage

`UPLUS(-4)`

`UPLUS(A2)`

### Syntax

`UPLUS(value)`

- `value` - The number to return.

### See Also

[`UNARY_PERCENT`](https://support.google.com/docs/answer/3093982): Returns a value interpreted as a percentage; that is, \`UNARY_PERCENT(100)\` equals \`1\`.

[`UMINUS`](https://support.google.com/docs/answer/3093606): Returns a number with the sign reversed.
