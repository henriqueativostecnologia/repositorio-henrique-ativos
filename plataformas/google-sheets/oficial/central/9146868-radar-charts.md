# Radar charts

Use a radar chart to evaluate different choices based on multiple variables. Radar charts show one or more variables in a two-dimensional graph, with one spoke for each variable. For example, you could evaluate the quality, price, flexibility, and response time of 3 different suppliers.

[Learn how to add & edit a chart](https://support.google.com/docs/answer/63824).

## How to format your data

- **First column**: Enter a label for each row. Labels from the first column show up outside the circ**le.**
- **First row (Optional)**: In the first row of each column, enter a category name. Entries in the first row show up as labels in the legend.
- **Other columns**: For each column, enter numeric data. You can also add a category name (optional).

## Customize a radar chart

1.  On your computer, open a spreadsheet in [Google Sheets](https://docs.google.com/spreadsheets/u/0/).
2.  Double-click the chart you want to change.
3.  At the right, click **Customize**.
4.  Choose an option:
    - [Chart style](https://support.google.com/docs/answer/63824): Change how the chart looks.
    - Radar: Show range gridlines.
    - [Chart & axis titles](https://support.google.com/docs/answer/9085334): Edit or format title text.
    - Series: Change how the lines and points look.
    - [Legend](https://support.google.com/docs/answer/63824): Change legend position and text.
    - [Vertical axis](https://support.google.com/docs/answer/9085334): Edit or format axis text, set min or max value, or log scale.
    - [Gridlines](https://support.google.com/docs/answer/63824): Add and edit gridlines.
