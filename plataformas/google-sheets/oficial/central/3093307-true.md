# TRUE

Returns the logical value \`TRUE\`.

### Sample Usage

`TRUE()`

### Syntax

`TRUE()`

### Notes

- In most cases, Google Sheets will automatically convert the `TRUE` literal to the logical `TRUE` value, equivalent to this function.

### See Also

[`NOT`](https://support.google.com/docs/answer/3093305): Returns the opposite of a logical value - \`NOT(TRUE)\` returns \`FALSE\`; \`NOT(FALSE)\` returns \`TRUE\`.

[`FALSE`](https://support.google.com/docs/answer/3093302): Returns the logical value \`FALSE\`.
