# UPPER function

Converts a specified string to uppercase.

### Sample Usage

`UPPER("lorem ipsum")`

`UPPER(A2)`

### Syntax

`UPPER(text)`

- `text` - The string to convert to uppercase.

### See Also

[`PROPER`](https://support.google.com/docs/answer/3094133): Capitalizes each word in a specified string.

[`LOWER`](https://support.google.com/docs/answer/3094083): Converts a specified string to lowercase.
