# VALUE

Converts a string in any of the date, time or number formats that Google Sheets understands into a number.

### Sample Usage

`VALUE("123")`

`VALUE("7/20/1969")`

`VALUE("12:00:00")`

### Syntax

`VALUE(text)`

- `text` - The string containing the value to be converted.

### Notes

- `VALUE` returns a pure number even if the argument to the function was interpreted as a date. For example, `=VALUE("01/01/2012")` by default will be displayed as 40909.
- When strings can’t be converted, the function will display an error.

### See Also

[`TEXT`](https://support.google.com/docs/answer/3094139): Converts a number into text according to a specified format.

[`N`](https://support.google.com/docs/answer/3093357): Returns the argument provided as a number.
