# LOWER

Converts a specified string to lowercase.

### Sample Usage

`LOWER("LOREM IPSUM")`

`LOWER(A2)`

### Syntax

`LOWER(text)`

- `text` - The string to convert to lowercase.

### See Also

[`UPPER`](https://support.google.com/docs/answer/3094219): Converts a specified string to uppercase.

[`PROPER`](https://support.google.com/docs/answer/3094133): Capitalizes each word in a specified string.
