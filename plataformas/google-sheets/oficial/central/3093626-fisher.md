# FISHER

Returns the Fisher transformation of a specified value.

### Sample Usage

`FISHER(0.962)`

`FISHER(A2)`

### Syntax

`FISHER(value)`

- `value` - The value for which to calculate the Fisher transformation.

### See Also

[`PEARSON`](https://support.google.com/docs/answer/3094092): Calculates r, the Pearson product-moment correlation coefficient of a dataset.

[`FISHERINV`](https://support.google.com/docs/answer/3093998): Returns the inverse Fisher transformation of a specified value.

[`CORREL`](https://support.google.com/docs/answer/3093990): Calculates r, the Pearson product-moment correlation coefficient of a dataset.
