# UNARY_PERCENT

Returns a value interpreted as a percentage; that is, \`UNARY_PERCENT(100)\` equals \`1\`.

### Sample Usage

`UNARY_PERCENT(A2)`

`UNARY_PERCENT(93)`

### Syntax

`UNARY_PERCENT(percentage)`

- `percentage` - The value to interpret as a percentage.

### Notes

- `UNARY_PERCENT` is roughly equivalent to the inverse of `TO_PERCENT`.

### See Also

[`TO_PERCENT`](https://support.google.com/docs/answer/3094284): Converts a provided number to a percentage.
