# UMINUS

Returns a number with the sign reversed.

### Sample Usage

`UMINUS(-4)`

`UMINUS(A2)`

### Syntax

`UMINUS(value)`

- `value` - The number to have its sign reversed. Equivalently, the number to multiply by `-1`.

### See Also

[`UPLUS`](https://support.google.com/docs/answer/3093608): Returns a specified number, unchanged.

[`UNARY_PERCENT`](https://support.google.com/docs/answer/3093982): Returns a value interpreted as a percentage; that is, \`UNARY_PERCENT(100)\` equals \`1\`.
