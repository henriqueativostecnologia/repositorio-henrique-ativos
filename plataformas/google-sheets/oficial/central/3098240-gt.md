# GT

Returns \`TRUE\` if the first argument is strictly greater than the second, and \`FALSE\` otherwise. Equivalent to the \`\>\` operator.

### Sample Usage

`GT(A2,A3)`

`GT(2,3)`

### Syntax

`GT(value1, value2)`

- `value1` - The value to test as being greater than `value2`.

- `value2` - The second value.

### See Also

[`NE`](https://support.google.com/docs/answer/3093981): Returns "TRUE" if two specified values are not equal and "FALSE" otherwise. Equivalent to the "\<\>" operator.

[`LTE`](https://support.google.com/docs/answer/3093976): Returns \`TRUE\` if the first argument is less than or equal to the second, and \`FALSE\` otherwise. Equivalent to the \`\<=\` operator.

[`LT`](https://support.google.com/docs/answer/3093596): Returns \`TRUE\` if the first argument is strictly less than the second, and \`FALSE\` otherwise. Equivalent to the \`\<\` operator.

[`GTE`](https://support.google.com/docs/answer/3093975): Returns \`TRUE\` if the first argument is greater than or equal to the second, and \`FALSE\` otherwise. Equivalent to the \`\>=\` operator.

[`EQ`](https://support.google.com/docs/answer/3093593): Returns "TRUE" if two specified values are equal and "FALSE" otherwise. Equivalent to the "=" operator.
