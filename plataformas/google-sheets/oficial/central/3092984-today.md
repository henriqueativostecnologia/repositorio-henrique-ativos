# TODAY

Returns the current date as a date value.

### Sample Usage

`TODAY()`

### Syntax

`TODAY()`

### Notes

- Note that `TODAY` is a volatile function and can hurt spreadsheet performance.

- `TODAY` provides the current date with no time component. To create a date with the current time, use [`NOW`](https://support.google.com/docs/answer/3092981).

- `TODAY` will always represent the current date the last time the spreadsheet was recalculated, rather than remaining at the date when it was first entered.

### See Also

[`NOW`](https://support.google.com/docs/answer/3092981): Returns the current date and time as a date value.

[`DATEVALUE`](https://support.google.com/docs/answer/3093039): Converts a provided date string in a known format to a date value.

[`DATE`](https://support.google.com/docs/answer/3092969): Converts a year, month, and day into a date.

### Examples

Returns the current computer system date.
