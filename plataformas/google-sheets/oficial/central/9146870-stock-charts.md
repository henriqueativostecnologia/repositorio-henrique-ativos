# Stock charts

Use a stock chart to show the low, high, opening, and closing values of a security for a specific period. For example, get the fluctuation in stock prices each day.

You can also use stock charts, like high-low-close (HLC) or open-high-low-close (OHLC) charts, to visualize stock prices, scientific data, or other time-series data.

[Learn how to add & edit a chart](https://support.google.com/docs/answer/63824).

Candlestick chart

## Format OHLC chart data

An open-high-low-close (OHLC) chart displays the opening, high, low and closing values of a security for a specific period. To format an OHLC chart, follow the guidance below:

- **First column:** Enter a label for the X axis.
- **Second column** **(Opening value):** Enter a number for the opening or initial value . This value is one vertical border of the candle.
- **Third column** **(High value):** Enter a number for the high or maximum value. This value is the top of the candle’s center line.
- **Fourth column** **(Low value):** Enter a number for the minimum value. This value is the base of the candle’s center line.
- **Fifth column** **(Close value):** Enter a number for the minimum value. This value is the second vertical border of the candle.
- **Rows**: Each row represents a single candlestick marker.

**Note**: If the value of the third column is less than the value of the fourth column, the candle will be filled. Otherwise, it'll be hollow.

## Format HLC chart data

A high-low-close chart displays the high, low, and closing values of a security for a specific period. To format an HLC chart, follow the guidance below:

- **First column:** Enter a label for the X axis.
- **Second column (High value):** Enter a number for the high or maximum value. This value is the top of the center line.
- **Third column (Low value):** Enter a number for the low or minimum value. This value is the base of the center line.
- **Fourth column (Close value):** Enter a number for the closing or final value. This value is the tick mark across the vertical High-Low range line.
- **Rows:** Each row represents a single HLC marker.
