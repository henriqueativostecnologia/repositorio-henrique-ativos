# Types of charts & graphs in Google Sheets

Want advanced Google Workspace features for your business?

[Try Google Workspace today!](https://workspace.google.com/business/signup/welcome?utm_source=gwslearningcenter&utm_medium=support&utm_campaign=190718)

[Learn how to add a chart to your spreadsheet](https://support.google.com/docs/answer/63824).

## Line chart   Line

Use a line chart to look at trends or data over a time period. [Learn more about line charts](https://support.google.com/docs/answer/9142593).

## Combo chart   Combo

Use a combo chart to show each data series as a different marker type, like a column, line, or area line. [Learn more about combo charts](https://support.google.com/docs/answer/18180907).

## Area chart   Area

Use an area chart to track one or more data series graphically, like changes in value between categories of data. [Learn more about area charts](https://support.google.com/docs/answer/9142677).

**Related charts**: Stacked area chart, 100% stacked area chart, Stepped area chart, Stacked stepped area chart, 100% stacked stepped area chart

## Column chart   Column

Use a column chart to show one or more categories, or groups, of data, especially if each category has subcategories. [Learn more about column charts](https://support.google.com/docs/answer/9142824).

**Related charts**: Stacked column chart, 100% stacked column chart

## Bar chart   Bar

Use a bar chart to show the difference between the data points for one or more categories. [Learn more about bar charts](https://support.google.com/docs/answer/9142829).

**Related charts**: Stacked bar chart, 100% stacked bar chart

## Pie chart   Pie

Use a pie chart, also known as a pie graph, to show data as "slices of pie," or proportions of a whole. [Learn more about pie charts](https://support.google.com/docs/answer/9143036).

**Related chart**: Doughnut chart

## Scatter chart   Scatter

Use a scatter chart to show numeric coordinates along the horizontal (X) and vertical (Y) axes and to look for trends and patterns between two variables. [Learn more about scatter charts](https://support.google.com/docs/answer/9143294).

**Related charts**: Bubble chart

## Histogram   Histogram

Use a histogram chart to show the distribution of a data set across different buckets. [Learn more about histogram charts](https://support.google.com/docs/answer/9146867).

**Note:** You can find histogram charts under the "Statistical" chart category in Google Sheets.

#### Box & whisker

Use a box and whisker chart to show the distribution of values in a data set, including medians, quartiles, and outliers. [Learn more about box and whisker charts](https://support.google.com/docs/answer/18779572).

**Note:** You can find box and whisker charts under the "Statistical" chart category in Google Sheets.

## Candlestick chart   Stock

Use a stock chart to visualize stock price movements or other time-series data. Google Sheets now supports two main types:

- High-low-close (HLC) charts, which show the highest, lowest, and closing prices for a period.
- Open-high-low-close (OHLC) charts, which show the opening, highest, lowest, and closing prices for a period.

[Learn more about stock charts](https://support.google.com/docs/answer/9146870).

## Organizational   Organizational

Use an organizational chart, also called an org chart, to show the relationship between members of a company, group of people, or family tree. [Learn more about organizational charts](https://support.google.com/docs/answer/9146871).

## Tree map chart   Tree map

Use a tree map to show a data tree, where objects are organized into parent-child hierarchies. [Learn more about tree map charts](https://support.google.com/docs/answer/9146947).

##  Geo

Use a geo chart to show a map of a country, continent, or region. The values for each location will be shown with colors. [Learn more about geo charts](https://support.google.com/docs/answer/9143071).

##  Waterfall

Use a waterfall chart to show how later values add or subtract from a starting value. [Learn more about waterfall charts](https://support.google.com/docs/answer/9146779).

##  Radar

Use a radar chart to show one or more variables in a two-dimensional graph, with one spoke for each variable. [Learn more about radar charts](https://support.google.com/docs/answer/9146868).

##  Gauges

Use gauges to show numeric values or measurements within a range. Each value produces a gauge, so you can compare and contrast measurements. [Learn more about gauge charts](https://support.google.com/docs/answer/9146869).

##  Annotated timeline

Use an annotated timeline to show an interactive time series line chart with the option to add notes. [Learn more about timeline charts](https://support.google.com/docs/answer/9146783).

##  Table

Use a table chart to turn your spreadsheet table into a chart that can be sorted and paged. Table charts are often used to create a dashboard in Google Sheets or [embed a chart in a website](https://support.google.com/docs/answer/1047436). [Learn more about table charts](https://support.google.com/docs/answer/9146787).
