# CODE

Returns the numeric Unicode map value of the first character in the string provided.

### Sample Usage

`CODE("a")`

`CODE(A1)`

### Syntax

`CODE(string)`

- `string` - The string whose first character's Unicode map value will be returned.

### Notes

- Only the first character in `string` will be evaluated; others will be ignored.

### See Also

[`CHAR`](https://support.google.com/docs/answer/3094120): Convert a number into a character according to the current Unicode table.
