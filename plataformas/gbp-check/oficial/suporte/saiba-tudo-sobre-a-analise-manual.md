# Introdução Rápida

Ferramenta **complementar** que funciona como um **Checklist manual** de itens que são importantes, que ainda não são possíveis serem executados de forma automática e que fazem parte de um bom trabalho de **otimização e gestão de negócios locais**.

De forma simplificada, a **Análise Manual** é um conjunto de **boas práticas** a serem revisadas para itens que tem que podem ou não serem ajustados no perfil, dependendo do caso.

## Pré Requisitos para o uso

1. Possuir acesso como **Administrador** ou **Proprietário** ao perfil.

2. O perfil deve **Aparecer** e estar com o status **Confirmado** quando você acessar [business.google.com](https://business.google.com/)

3. Alguns dados do perfil podem precisar de **Aceite**, caso não sejam aceitos, podem haver divergências nos resultados, [saiba mais clicando aqui](https://help.gbpcheck.com/pt-br/article/analise-completa-apresentando-diferencas-comparadas-ao-google-1ms3g2d/).

- Caso o perfil não seja exibido em [**business.google.com**](https://business.google.com/), ou seja exibido e esteja com qualquer status diferente de **Confirmado**, é preciso **verificar o perfil** para garantir que a gestão será apropriada e os passos seguidos na análise manual tenham efeito.

### Principais Funcionalidades

##### a. Gráfico do status de revisão

Acompanhe de forma gráfica os itens que foram revisados no perfil

##### b. Checklist manual

Revise os itens do checklist para garantir que você seguiu as melhores práticas para aquele perfil

#### Como Utilizar a Análise Manual

1. Clique no menu **Análise Manual**,
2. **Selecione um local** que você já tem acesso como **Administrador** ou **Proprietário** na barra superior, [saiba mais aqui](https://help.gbpcheck.com/pt-br/article/como-adicionar-negocios-na-barra-superior-na-analise-completa-wtppz1/)
3. Após selecionar o local, clique em cada item para abrir a caixinha, faça a revisão daquele item e responda a pergunta se Sim ou não
4. Acompanhe o gráfico se você **revisou** todos os itens

##### Perguntas Frequentes

**\- A Análise Manual é um item obrigatório para otimização de perfis ?**

Ela não é um item obrigatório, e pode ser substituida por outro checklist ou planilha manual que você tenha. O importante é ter em mente estes itens que precisam ser revisados para maximizar as chances de uma entrega de excelência

**\- Existe limite de Análises Manuais que podem ser executadas ?**

Não há limites para o uso da análise manual. Saiba mais sobre limites da ferramenta [clicando aqui](https://help.gbpcheck.com/pt-br/article/quais-os-limites-da-ferramenta-gig79w/).
