# Saiba como obter o Place ID

O **Place ID** é uma identificação única para cada negócio cadastrado no **Google Maps**

Para obter o Place ID, o método mais simples é via **extensão do GBP Check:**

Uma vez com a extensão instalada:

1. Acesse [**https://maps.google.com**](https://maps.google.com/)
2. Pesquise pelo **nome do local**
3. Clique no **menu verde** do GBP Check a direita
4. Copie o **Place ID**
