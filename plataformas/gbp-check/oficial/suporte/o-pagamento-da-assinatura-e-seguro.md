# O pagamento da assinatura é seguro ?

Sim, o pagamento via cartão é seguro:

Utilizamos a plataforma do [Stripe](https://www.stripe.com/), segundo maior gateway de pagamento na Internet após o Paypal. Os dados são todos geridos de forma segura pelo Stripe.
