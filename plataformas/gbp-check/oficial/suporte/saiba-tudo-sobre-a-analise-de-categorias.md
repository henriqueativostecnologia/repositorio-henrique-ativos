# Introdução Rápida

Ferramenta para **Analisar Categorias** de negócios locais, o que possibilita lhe ajudar a escolher a melhor categoria para aquele negócio local, bem como explorar as melhores categorias adicionais para aquele segmento. É possível analisar utilizando tanto **um negócio local como base**, e sua respectiva categoria ; bem como **pesquisar por uma palavra-chave** e identificar quais as categorias de negócios locais tem mais relação com a palavra-chave pesquisada.

## Pré Requisitos para o uso

1. Possuir a **extensão do GBP Check instalada no Google Chrome**. Em caso de dúvidas, [siga este roteiro](https://help.gbpcheck.com/pt-br/article/como-instalar-a-extensao-do-gbp-check-no-google-chrome-3any79/).
2. Caso você seja o **Administrador** ou **Proprietário** do perfil, é preciso **alternar sua conta**, [seguindo este roteiro](https://help.gbpcheck.com/pt-br/article/conceitos-basicos-da-pre-analise-xpg1t2/), para que funcione.
3. O Perfil precisa ter uma **Categoria Principal**.

- Caso o perfil não possua uma categoria principal, é preciso primeiro configurar uma categoria principal no perfil ou analisar outro local do mesmo segmento para que a análise seja possível.

### Principais Funcionalidades

##### a. Analisar Locais que você ainda não tem acesso:

Efetue análises de todo tipo de perfil que você ainda não tem acesso como **Administrador** ou **Proprietário**

##### b. Efetue Análise por Categoria ou por Palavra-chave

Através da tela do Google Maps é possível efetuar uma análise por **Categoria** ou por **Palavra-chave**. Saiba mais na opção 3 em Como Utilizar a Análise de Categorias.

##### c. Diversas análises:

- Análise de Categoria Principal
- Análise de Categoria Adicional
- Análise de Categorias Relacionadas
- Resumo de Localizações Analisadas

#### Como Utilizar a Análise de Categorias

## Opção 1. Análise de categoria pela página de pesquisa do Google:

1. No Google Chrome, **abra uma nova aba** e pesquise pelo **negócio desejado**
2. Clique no botão verde **Ferramentas**, ao lado de Pré Análise
3. Clique em **Análise de Categorias**
4. Aguarde a **conclusão e o redirecionamento para o App** para a tela de resultado

## Opção 2. Análise de categoria pela página do Google Maps:

1. No Google Chrome, **abra uma nova aba** e acesse [maps.google.com](https://maps.google.com/)
2. Pesquise pelo nome do local e clique no perfil
3. A extrema direita, **clique no menu verde que possui o logo do GBP Check** para abrir o **menu retrátil**
4. Aguarde a **conclusão e o redirecionamento para o App** para a tela de resultado

## Opção 3. Análise de palavra-chave pela página do Google Maps:

1. No Google Chrome, **abra uma nova aba** e acesse [maps.google.com](https://maps.google.com/)
2. Pesquise por uma **palavra-chave**, por exemplo **hamburgueria**
3. A extrema direita, **clique no menu verde que possui o logo do GBP Check** para abrir o **menu retrátil**
4. Clique em Analisar palavra-chave e aguarde a **conclusão e o redirecionamento para o App** para a tela de resultado
