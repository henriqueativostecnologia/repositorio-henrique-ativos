# Introdução Rápida

Esta é uma ferramenta para **Analisar Palavras-Chave** de negócios locais que você efetua a gestão como Administrador ou Proprietário.

## Pré Requisitos para o uso

1. Possuir acesso como Administrador ou Proprietário do perfil.

### Principais Funcionalidades

##### a. Apresentar as palavras chave que acionaram o perfil

Descubra quais palavras-chave acionaram o perfil deste negócio no Google nos últimos 18 meses ou caso seja um novo negócio, peplo período que o negócio existe.

##### b. Pesquise por palavras-chave em uma lista

Faça filtros de palavras através do campo de busca.

##### c. Compare palavras-chave

Veja um comparativo de palavras pré selecionadas para descobrir como foi sua evolução ao longo do tempo.

##### d. Obtenha dados históricos para cada palavra-chave

Descubra quando uma palavra foi encontrada pela primeira e última vez, qual mês teve maior valor, o total de vezes em que foi encontrada e sua frequência.

##### e. Filtre resultados por período

Escolha os períodos em que deseja visualizar as palavras-chave.

##### f. Efetue download dos resultados em PDF ou CSV

Utilize o menu Ações > Download PDF / Download CSV para efetuar o download de relatórios de palavras-chave.

#### Como Utilizar Palavras-Chave

## Acesse o menu de palavras-chave utilizando o App

1. Em [app.gbpcheck.com](https://app.gbpcheck.com/), clique no menu Palavras-chave.
2. No menu superior, escolha o negócio que você deseja visualizar as palavras-chave.
3. Clique no botão atualizar ao lado direito da tela para carregar as últimas atualizações de palavras do Google.
4. Aguarde a conclusão para visualizar os resultados.

**Caso esteja visualizando uma quantidade pequena palavras-chave, pode ser que não existam palavras-chave com quantidade suficientes para métricas e estas podem ter sido ocultadas. Para apresentá-las, clique no menu Opções e desative "Ignorar palavras com dados insuficientes"**

Para comparar palavras-chave, clique no símbolo de Check a esquerda de cada palavra e será exibido um botão azul Comparar.

Clique em Comparar para visualizar a tela do comparativo.

- Para obter dados históricos por palavras-chave, clique sob cada palavra-chave e visualize o histórico de cada um.

##### Perguntas Frequentes

**\- Qual a frequência com que palavras-chave são atualizadas ?**

O Google fornece dados de palavras-chave mensalmente.

**\- Como incluir uma palavra-chave na lista ?**

É preciso efetuar um trabalho de Local SEO para que uma nova palavra passe a ativar o perfil. Recomendamos cursos de mentores para conhecer as técnicas que permitem com que perfis de negócios locais sejam acionados com novas palavras-chave.
