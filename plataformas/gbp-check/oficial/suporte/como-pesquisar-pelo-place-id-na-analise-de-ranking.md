# Como Pesquisar pelo Place ID na Análise de Ranking

Caso você não encontre um negócio na lista de pesquisa você pode utilizar o Place ID para pesquisar por um local, para isso siga os passos abaixo:

1. Abra o **Google Maps** e pesquise pelo local
2. Clique no **menu verde** a direita no **símbolo do Check**
3. Clique no **símbolo de copiar** para **Copiar o Place ID**
4. **Cole** o Place ID no campo de pesquisa do Ranking e **clique em OK**
