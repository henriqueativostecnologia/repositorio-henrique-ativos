# Como definir o idioma de respostas de avaliações ?

O idioma **padrão** para gerar respostas por **Inteligência Artificial** no GBP Check é o **Português**.

Agora, é possível escolher até **3 idiomas** para gerar respostas de avaliações por IA:

- 🇧🇷 Português
- 🇺🇸 Inglês
- 🇪🇸 Espanhol

## Como configurar um idioma específico:

1. Acesse o **Gerenciador de Avaliações**
2. Clique em **Ações**
3. Clique em **Definir Idioma de Resposta**

(Animação "Definir Idioma da Resposta" no artigo original.)

## A configuração reflete para todos os negócios ou é individual por negócio ?

A configuração do idioma é individual, para cada negócio.

Você pode tanto alterar a configuração de um negócio específico, como pode alterar para todos os locais que gerencia;

## Para alterar a configuração de idioma para todos os locais que gerencia:

1. Acesse o **Gerenciador de Avaliações**
2. Clique em **Ações**
3. Clique em **Definir Idioma de Resposta**
4. Selecione a opção: **Utilizar este idioma para todas as localizações**.
