# Introdução Rápida

Ferramenta para **explorar negócios** de um determinado segmento através do **Google Maps**.

## Pré Requisitos para o uso

1. Possuir uma assinatura ativa no GBP Check
2. Possuir a extensão do GBP Check instalada no Google Chrome. Para instalar a extensão [siga este roteiro](https://help.gbpcheck.com/pt-br/article/como-instalar-a-extensao-do-gbp-check-no-google-chrome-3any79/).

## Principais Funcionalidades

##### a. Apresentar negócios de determinado segmento para prospecção

Explore todos os negócios listados no resultado da análise, através de uma palavra chave ou categoria

##### b. Filtros avançados para sua Planilha de Leads:

- Telefone
- Website
- Status de verificação
- Área de serviço
- Categorias adicionais
- Avaliações
- Posts recentes
- Nome
- Endereço
- Telefone

#### Como Utilizar o Explorar Negócios

A Análise inicia-se pelo **Google Maps** :

1. No **Google Maps**, pesquise por uma **categoria** ou **palavra-chave**
2. Clique na aba lateral verde
3. Clique em **Explorar Negócios**
4. Para **salvar** essa análise no **APP**, clique em **Salvar**
5. Para consultar as **análises salvas**, dentro do **APP**, acesse o menu **Explorar Negócios**
6. Para **baixar** a análise direto pelo maps, clique em **exportar CSV**
7. Para **baixar** a análise depois dentro do **APP**, clique no botão **ações**, **exportar CSV**
8. Para selecionar filtros para sua planilha, clique no item desejado, como por exemplo: possui telefone / não possui telefone

Para abrir os dados de **leads de forma organizada**, recomendamos utilizar o **Google Planilhas**, para isso:

1. Faça o download do arquivo CSV dos leads gerados clicando em Download Planilha;
2. Acesse Google Planilhas;
3. Clique em Arquivo;
4. Clique em importar;
5. Fazer upload;
6. Procure o arquivo que você baixou em downloads e clique sobre ele;
7. Clique em importar dados (a planilha está pronta);
8. Renomeie a planilha com a lista de leads gerada.

##### Perguntas Frequentes

**\- Existe limite de análises do recurso Explorar Negócios que podem ser executadas ?**

Não há limites para o uso do explorar negócios. Saiba mais sobre limites da ferramenta [clicando aqui](https://help.gbpcheck.com/pt-br/article/quais-os-limites-da-ferramenta-gig79w/).
