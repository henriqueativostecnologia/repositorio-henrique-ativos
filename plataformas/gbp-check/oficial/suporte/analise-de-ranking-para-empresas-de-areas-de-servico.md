# Análise de Ranking para Empresas de Áreas de Serviço

A Análise de Ranking para [Empresas de Área de Serviço](https://support.google.com/business/answer/9157481?hl=pt), ou seja, **empresas que não possuem um endereço físico** ainda não está disponível no **GBP Check**.

Empresas de Áreas de Serviço **não são suportadas oficialmente pela API do Google** e requerem uma implementação diferenciada para que seja possível a análise.

Caso você considere muito importante este recurso, por favor nos envie uma mensagem via **chat de suporte** com este pedido. Estamos coletando informações de pessoas interessadas e assim podemos priorizar a implementação com o projeto.

Atualizado em: 28/01/2024

> Nota da cópia: o artigo é de 28/01/2024; o artigo "O que é SAB ?" (atualizado em 25/04/2025) indica que análises de ranking para locais SAB passaram a ser possíveis via "Busca Avançada".
