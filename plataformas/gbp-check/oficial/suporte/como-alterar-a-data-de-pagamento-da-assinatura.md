# Como alterar a data de pagamento da assinatura ?

Para alterar a data de pagamento da assinatura, precisamos que entre em contato na data em questão para que a alteração seja efetuada.

Por exemplo, se deseja alterar para o dia 20 de cada mês. Entre em contato via chat no dia 20 solicitando a alteração para que possamos efetivar o pedido.
