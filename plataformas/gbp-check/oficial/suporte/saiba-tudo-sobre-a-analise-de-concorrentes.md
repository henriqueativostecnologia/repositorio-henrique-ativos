# Introdução Rápida

Ferramenta para comparar os concorrentes de um determinado negócio ou analisar concorrentes entre si.

## Pré Requisitos para o uso

1. Possuir uma assinatura ativa no GBP Check
2. Possuir a extensão do GBP Check instalada no Google Chrome. Para instalar a extensão [siga este roteiro](https://help.gbpcheck.com/pt-br/article/como-instalar-a-extensao-do-gbp-check-no-google-chrome-3any79/).

## Principais Funcionalidades

##### a. Trazer os concorrentes de determinado negócio e comparar concorrentes entre si

Compare concorrentes de negócios que gostaria de prospectar, através de uma palavra chave para aquele segmento

##### b. Métricas de Reputação e Atributos:

- Estatísticas de Avaliações
- Ranking por Quantidade de Avaliações
- Distribuição por Quantidade de Avaliações
- Distribuição por Avaliação Média
- Distribuição por Quantidade de Categorias
- Distribuição por Categoria
- Atributos
- Opções de serviço
- Acessibilidade
- Planejamento
- Comodidades
- Opções no menu
- Estacionamento
- Público
- Da empresa
- Crianças

#### Como Utilizar a Análise de Concorrentes

A Análise inicia-se pelo **Google Maps** :

1. No **Google Maps**, pesquise por uma **categoria** ou **palavra-chave**
2. Clique no botão verde **Comparar**
3. Aguarde a **conclusão** da análise
4. Para **salvar** essa análise no **APP**, clique em **Salvar**
5. Para consultar as **análises salvas**, dentro do **APP**, acesse o menu **Análise de Concorrentes**

##### Perguntas Frequentes

**\- Existe limite de Análises de Concorrentes que podem ser executadas ?**

Não há limites para o uso da análise de concorrentes. Saiba mais sobre limites da ferramenta [clicando aqui](https://help.gbpcheck.com/pt-br/article/quais-os-limites-da-ferramenta-gig79w/).
