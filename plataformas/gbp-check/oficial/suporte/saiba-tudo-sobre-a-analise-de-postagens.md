# Introdução Rápida

Ferramenta para **Analisar Postagens** preferencialmente de perfis que você não possui acesso como **Administrador** ou **Proprietário**, com o intuito de venda. Caso possua acesso, ou seja, caso sua tela de pesquisa exiba o **Gerenciador de Perfis**, é preciso [seguir este roteiro](https://help.gbpcheck.com/pt-br/article/conceitos-basicos-da-pre-analise-xpg1t2/) para que a **análise funcione**, pois segue o mesmo conceito básico da **Pré Análise**.

## Pré Requisitos para o uso

1. Possuir a **extensão do GBP Check instalada no Google Chrome**. Em caso de dúvidas, [siga este roteiro](https://help.gbpcheck.com/pt-br/article/como-instalar-a-extensao-do-gbp-check-no-google-chrome-3any79/).
2. Caso você seja o **Administrador** ou **Proprietário** do perfil, é preciso **alternar sua conta**, [seguindo este roteiro](https://help.gbpcheck.com/pt-br/article/conceitos-basicos-da-pre-analise-xpg1t2/), para que funcione.
3. O Perfil pode ter até **40 postagens** publicadas;

- Caso o perfil possua mais de **40 postagens**, serão analisadas e apresentadas as **40 postagens mais recentes do perfil**. Para obter dados estatísticos de perfis que possuem mais de 40 postagens, procure obter o acesso como **Administrador** ou **Proprietário**. Uma vez com o acesso, entre no **Relatório Avançado,** aba **Postagens**.

### Principais Funcionalidades

##### a. Analisar Locais que você ainda não tem acesso:

Efetue análises de todo tipo de perfil que você ainda não tem acesso como **Administrador** ou **Proprietário**

##### b. Diversas análises:

- Dashboard da Análise de Postagens
- Evolução das Postagens
- Chamada Para Ação em Postagens
- Últimas Postagens

#### Como Utilizar a Análise de Postagens

A Análise inicia-se pela página de pesquisa do Google:

1. No Google Chrome, **abra uma nova aba** e pesquise pelo **negócio desejado**
2. Clique no botão verde **Ferramentas**, ao lado de Pré Análise
3. Clique em **Análise de Postagens**
4. Aguarde a **conclusão e o redirecionamento para o App** para a tela de resultado

##### Perguntas Frequentes

**\- Existe limite de Análises de Postagens que podem ser executadas ?**

Não há limites para o uso da análise de postagens. Saiba mais sobre limites da ferramenta [clicando aqui](https://help.gbpcheck.com/pt-br/article/quais-os-limites-da-ferramenta-gig79w/).
