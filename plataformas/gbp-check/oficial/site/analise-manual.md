# Análise de Saúde Manual

Até os melhores especialistas podem contar com um **checklist** para concluir ótimos trabalhos.

A **Análise Manual** atua como um checklist guiado para lhe ajudar a lembrar os principais itens de otimização do perfil que precisam ser executados manualmente

## Itens detalhados

Cada item do Checklist apresenta **informações detalhadas** sobre a importância daquele item.

Após selecionado, cada item reflete automaticamente no gráfico principal conforme acima e pode ser exportado em PDF.

É possível checar **múltiplos itens** ao mesmo tempo, caso já tenham sido revisados.
